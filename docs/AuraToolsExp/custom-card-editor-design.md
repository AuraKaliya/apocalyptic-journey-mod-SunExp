AuraToolsExp 自建卡牌编辑器

状态：2026-09-19，作品文档 v4、节点版本 2、生成运行库修订 5。当前操作与连接规范见 [节点指南](custom-card-node-guide.md) 和 [生产节点目录](custom-card-node-catalog.md)。当前界面、原生预览边界和验证记录见 [工坊界面改版](custom-card-workshop-ui-2026-09.md)；此前的运行修复与安装记录见 [运行兼容性与界面修复记录](custom-card-runtime4-repair.md)。实际游戏验收独立于自动化检查。

一个蓝图对应一张卡牌。蓝图只由本牌的抽到、使用、丢弃三个原生时点启动，每次执行有界流程。同一张牌可以在下一次原生触发时重新执行；原生额外使用次数仍由宿主决定。读取数据节点不监控状态变化。

允许读取、施加、移除游戏已有状态；状态自身的持续行为由原状态系统负责。新卡不生成使用后受伤、回合开始、回合结束或生命跨阈值监听，不提供 BUFF 或被动技能编辑。

入口为妙妙工具 → 游戏体验 → 卡牌工坊。模块是按需打开的编辑工具，没有决定成品能否执行的总开关。三个编辑板块为效果蓝图、卡牌属性、卡面；作品库与内置模板使用同一页面。主窗口切页保持尺寸稳定，画板直接嵌入卡面页，原生图鉴预览通过侧栏或放大窗口查看。导入、导出、副本、脚本和节点指南归入作品菜单。

蓝图使用执行线和数据线。数值、条件、单个角色和角色集合端口彼此区分；每个输入最多一个来源，数据输出可以复用。普通执行输出只有一个后续。条件有成立、不成立及完成出口，有限重复和遍历有执行体及完成出口；子流程末端返回控制节点，根流程末端完成本次执行。显式结束节点结束整个入口。

默认值直接在节点中编辑，动态数据通过端口连接。连接类型正确的未完成条件可以接入流程，完整检查仍会阻止未完成稿制作。接线、重接和插入使用同一语义检查规则；失败不删除原连接。执行环、数据环、跨入口共享、失效的捕获及越界遍历对象会被拒绝。没有效果的流程不能制作。

数值使用同一套含义与格式契约：普通数值允许整数、小数；比例使用规范值（50% = 0.5），显示可选百分比或比例小数。比较、加减和限定范围要求两侧含义一致；普通数值乘比例得到普通数量。显式转换分别支持数值转比例、比例转小数、百分比转数值；严格相等与有明确容差的约等于分开。空白输入可跟随连线来源，已有值不自动改换含义。

旧蓝图以 0～100 数值使用生命百分比。v3 读取迁移为 v4 时，常规坐标按原相对位置拉开间距以容纳新节点，并在既有百分比输出路径加入明确的“百分比转数值”，保留原来比较、乘除和取整的数值结果。为此保留转换节点容量，转换不消耗原有语义复杂度预算。已有成品保留其自带的旧标度脚本；新制作成品使用运行库修订 5。作品库集合容器格式仍为 3，条目文档写 v4。

输入框使用统一聚焦背景、金色描边、光标与选区。输入时保留完整精度，未修改的编辑不回写；无效输入就地提示并阻止保存、切页和制作。单行输入提交与 Esc 取消使用 TMP 原生编辑事件，多行输入保留换行。草稿可保留尚未填写的节点参数，但不能把输入缓冲中的非法文字伪装成已提交的值。

默认在步骤需要参数时读取数据；记住数值或对象节点显式捕获结果。随机选择有执行入口，抽样一次后可以复用结果。遍历使用进入时的对象集合，执行时检查对象仍有效。变量限于本次执行及合法子作用域。

画布支持标题拖动、多选、框选、中键/空格平移、滚轮缩放、适配、整理、缩略导航、复制粘贴、删除、撤销重做、组合折叠、节点搜索、从端口创建兼容节点及向连线插入节点。参数和状态选择器可以在窄窗口独立打开。节点移动只更新位置与关联连线；选择和未变化的节点视图复用现有对象。空闲时不全图轮询。

蓝图库模板来自生产清单，包含直接伤害、半血强化、护盾后攻击、群体攻击、三段攻击、抽牌后护盾、已有状态条件、弃牌时护盾、选牌后继续、抽到时能量、随机敌人与空目标分支、从友方集合随机给予护盾。常用组合以独立片段插入。模板与片段不建立运行时外部依赖；复制时重映射内部节点、组合和变量身份。部分选择不复制外部连线或隐式绑定外部捕获。

状态选择使用真实已加载资源，展示说明及登记来源。未单独登记 MOD 来源时明确显示这一事实。缺失状态资源阻止制作，目标没有某个已存在状态时才读取零层。移除状态目前表示移除整个指定状态。

试算页面、基础数值模拟器、场景模型和蓝图执行轨迹已移除。保留制作前的结构、参数和单位检查；开发验证直接执行生成的 Lua，不保留第二套解释器。

v4 文档以 Graph 为唯一可编辑逻辑，规则块只作为编译后的执行表示。节点目录、校验器、Lua 生成、说明沿同一执行表示工作。布局不影响生成代码。节点 ID 贯穿文档、错误、生成脚本。

草稿结构上限为 1024 个可视节点、4096 根连线和 128 个组合；可制作流程仍检查 256 个执行节点/展开表达式、12 层深度、64 次重复、单次 64 张牌堆操作。一次连锁共享 4096 步预算，数据求值同样计数，纯表示转换不额外占用语义预算；含转换的求值结构仍限制为 64 层；额外限制 128 次入口和 64 层同步重入。同步原生调用传递当前预算，抽牌等待将预算传给入手引起的新入口；回调继续也使用同一个预算。

选牌回调只能推进一次。抽牌等待向原生 EventCenter 注册独立 owner，完成后明确移除；战斗结束由原生 OnFightEnd 清理。运行时共享链引用为弱引用，不留下卡牌常驻业务监听。恢复 ScriptExecutor 的 Object、status、Target，避免一次效果或选牌初始化污染后续原生执行。错误停止相关流程，不宣称回滚已经结算的原生效果。

旧稿与成品分开处理。

| 存量内容 | 行为 |
| --- | --- |
| v1 直接规则 | 转为图，保留属性、卡面、规则顺序、条件、逐对象筛选及内部引用；默认恒真规则不额外制造冗余条件节点 |
| 多组同入口规则且前组存在异步操作 | 保留原稿并提示时序变化，明确确认或修订后才允许制作 |
| 旧持续监听 | 保留不可执行的待修订节点及原稿，必须重写或明确删除；不伪装为使用时判断 |
| 随机求值差异 | 提示检查抽样位置，使用明确的选择并记住节点 |
| 缺少资源或参数的草稿 | 可导入、保存和修订，不能制作 |
| 未知较新文档或节点版本 | 拒绝猜测读取，不覆盖原文件 |
| v1 原生成品 | 保留独立 RawData/脚本，继续识别卡面版本；不改写存档内成品 |

读取明确的 v1/v2/v3 文档时单向迁移。原文分别保存在 LegacyBackup/BlueprintV2Backup；首次覆盖旧库条目之前另存整库备份。真正的旧随机节点迁为成功/空目标分支并要求检查；原先带外部对象线的伪随机节点迁为记住对象，保留实际行为。使用者专属能力只自动清理明确的使用者来源，其他错误连线保留为修订项。提交仍通过共享配置存储及修订检查，成功保存的稿件只写 v4。原生 RawData 卡面格式未改变，标记仍为 2；旧成品继续识别 1/2。存量成品自带脚本可能含旧监听，这是明确的已有存档兼容例外，新编辑器不再生成同类脚本。

设计稿与成品独立：编辑或删除稿件不会修改成品。导出携带图、布局、组合与像素卡面，引用资源使用逻辑标识；导入生成独立作品身份。文件上限为 2 MB，并检查结构深度、身份、坐标及文本边界。像素画布继续支持 32/64/128，生成 256×256 PNG；原生成品识别 v1 和 v2 标记。

原生依据为 `开发参考资料/反编译文件夹v1.0.24831968`，本轮重新确认 Managed 的 Witch.dll SHA256 为 `CD829F84F5A52A6B53973C676BF3DF4618A15F479A23BBA35B82E6802C6CDC83`，Witch.Core.dll 为 `EDE56686110573070F9E062C8EFC51AC9D60E2AFD9B436590A028B72FDC06295`。

- CommonCardItem / AttackCardItem 的 DrawEffect 调用 DrawScript；不能只根据“抽到”这个名称排除其他原生入手流程。
- UseScript 在 TryUse 成功后运行；原生额外使用次数可以多次调用。LateThrow 设置影响弃牌动作发生在使用脚本之前还是之后。
- InternalThrow 将非焚毁卡加入弃牌堆，并在战斗中调用 DropScript。因此用牌后的原生弃牌也可能触发丢弃入口。
- GetDeckUIToAction 的选择结果异步返回；ChooseCardToAction 会设置 Self 对象上下文，调用方需要恢复原有上下文。
- EventCenter 提供按 owner 移除监听及 OnFightEnd 清理。临时等待与作者可配置的被动触发器不同。
