## 修复边界

| 用户反馈 | 根因与最终处理 | 证据 |
| --- | --- | --- |
| 全局与局部按钮混在一起 | 工坊导航、作品栏、编辑工作区和画布工具分别承载对应操作；导出／副本／脚本归属当前作品 | 四档窗口的生产 UI 场景 |
| 节点底板与画布混为一体 | 原主题 Panel/Row 相同；改用生产自有视觉定义，标题、说明、执行、数据、状态分区 | 场景断言实际画布颜色、节点底板；全尺寸截图 |
| 注释添加报错 | Unity 已销毁对象仍有托管引用，原来的 `?.` 检查无效；显式检查 Unity 存活状态，销毁前只解除本窗口拥有的焦点 | 复现失效的 EventSystem 选中对象；添加、关闭、删除、撤销、重开测试 |
| 双参数面板覆盖注释 | 旧面板用过期文字覆盖当前模型；同步两面板，只提交实际修改 | 宽屏侧栏与弹窗同步断言，多行编辑后关闭不丢失 |
| 随机敌人能连接使用者 | 原实现是可被对象线覆盖的 CaptureObject；拆分固定敌人、固定友方、集合随机与显式对象捕获 | 接口、输入类型、成功／空目标作用域、实际 Lua 执行、v2 实际行为迁移 |
| 固定节点可被参数改成另一功能 | 系统名独立于备注；对象源、读取项和效果类型固定；单体／群体效果分别入库 | 72 项目录身份／说明／端口检查；能量与牌堆能力无对象口 |

生产 UI 使用自有按钮状态与节点图形，避免共享工具箱按钮的主题状态机在悬停后覆盖工坊配色。预览直接编译这些源文件；只适配宿主资源、音效、存储、通用窗口服务等无法在隔离场景中运行的部分。

## 自动化

- `dotnet run --project AuraToolsExp-Dev.Tests -c Release -- --suite custom-cards`：544 项断言通过。覆盖 72 项目录、数值与比较、全部读取字段和效果族的基础数值约定、对象类型、跨作用域、空集合、随机复用与重复、状态资源、取消／重复回调、有限执行预算、v1/v2 迁移、复制序列化及像素数据。生成 Lua 的可执行验证使用最小原生 API 假宿主，不能替代真实战斗。
- `tools/Test-AuraToolsExp.ps1 -SkipBuild -SkipModelIntegration`：2113 项模块断言及工具内容检查通过。本轮不涉及训练实现，未运行模型集成维护。
- `tools/Test-CustomCardUnity.ps1`：1600×1000、1280×900、960×720、760×640 共 48 个截图场景与配套交互通过。覆盖拖动／撤销、指针连线、失败重接保留、插入、剪贴板身份、组合、轨迹、像素画板、注释双入口／多行／尺寸／关闭／撤销／重开、销毁对象焦点、外部焦点保留、选中与错误并存、游戏内目录指南。

UI 明细、生命周期布尔结果和 50／128／256 节点打开耗时保存在 `output/unity/custom-cards/captures/report.json`；对应生产源哈希为 `output/unity/custom-cards/production-source-hashes.json`。这些是本机隔离预览数据，不能解释为实战帧率或所有机器的性能保证。
