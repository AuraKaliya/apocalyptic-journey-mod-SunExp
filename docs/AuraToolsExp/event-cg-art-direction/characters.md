## A01 · 卡洛琳

参考：[卡洛琳.png](<D:/Project/Apocalypic-journey-mods-creator/Mod的素材参考/角色立绘/卡洛琳.png>)。

固定特征：金色头发、蓝色眼睛、前垂长辫和红色发饰；大面积红色披风；灰黑与白色内层服装；白色尖瓣胸饰、腰带与原图服装结构。

构图：披风向身体外侧展开，脸和胸饰保持清楚；保留编辫的原有一侧。

身份检查：不添加参考里没有的剑或盾；不替换为异色形象的银发与烛台。

设定依据：原版文本快照：猎杀魔女；技能含保护与消除攻击意图。性格细节未提供，动作中的克制与警戒为美术提案。

身份绑定状态：目录候选，发布前核对实际加载身份。

| 事件 | 动作提案 |
| --- | --- |
| 战斗开场 | 侧身迎向来处，近胸的一手轻收披风，另一手低位向外展开，目光警戒。 |
| 普通胜利 | 肩部放松，一手收住披风胸前边缘，另一手降低，嘴角轻扬并向队伍中心回望。 |
| 点金手胜利 | 掌心向上承接一枚场景金币，另一手护住披风，神情审视；金币作为独立效果层。 |
| 仪式胜利 | 双手前后错开，掌心相对引导保护性的仪式光，保持站姿稳定。 |
| 诅咒胜利 | 抬掌压住将散的暗色符痕，目光坚定；符痕独立于人物。 |
| 战斗失败 | 微垂头，以一手扶住另一侧上臂，肩部略收拢；疲惫但保持清醒，披风完整。 |
| 冒险结算 | 轻收披风并回头看向远方，表情松弛，衣角顺着旅途的风轻扬。 |
