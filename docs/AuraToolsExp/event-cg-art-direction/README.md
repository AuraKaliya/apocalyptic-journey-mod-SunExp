## 已确定的方向

- 只为用户参考目录中的15套形象制作本版素材，普通与异色分别建档。
- 统一成细腻的日式幻想插画，保留角色脸型、服装、配色及标志性物件。
- 按事件选择姿势立绘，辅以少量镜头、前景和光效运动。
- 根据实际队伍组合一张群像海报，所有参与者面部清楚，视觉位置不代表伤害排名。
- 首先以四人普通胜利验证独立素材拼接；脸、手势、帽檐、翅膀和光轮都参与构图。

## 1. 美术统一标准

### 身份与画风

身份固定：眼睛与脸型、发型发色、体型与年龄观感、服装结构和配色、标志性饰品。普通与异色的参考不能交叉借用。画风统一：清楚而细腻的面部刻画，柔和的体积上色，受控的服装细节密度，干净的外轮廓与自然衣褶。

本轮动作全部是待审阅的美术提案。原版设定依据为仓库内的2026-07-29导出文本，不能作为当前游戏运行状态的证明；Terrias角色使用当前Data/Text与源码。没有设定支持的性格只描述为本画面的情绪，不补写人物生平。

参考中未出现的下半身、背面服装或武器结构不由模型自由扩写。以腰部以上为主，必要时延伸到原图已经说明的大腿区域；必须保留头顶、手与手持道具所需空间。

### 输出与裁切

- 角色原图：建议1536×2048，透明PNG，主动作位于中央区域，头饰、持物与手指四周保留至少约6%的余量；宽翼或大帽檐角色可改用2048×1536。画布尺寸是制作建议，面部占幅需要逐张检查。
- 背景与全幅前景：建议2560×1440，逻辑构图基准1920×1080；为最终镜头预留约5%的外缘，不在需要补画的边缘做推拉。
- 前景和角色附属效果使用独立透明PNG，保留来源图与放置锚点。与手发生真实接触的书、烛台、武器先与角色同层，避免持握错位。
- 附属效果如乌娜光轮，第一轮可随角色同图保持轮廓；需要独立运动时再做严格对齐的拆层。首轮不要求为每根发丝或每片羽毛拆层。
- 文案由排版层加入。角色图、背景图和前景图不包含事件标题、姓名、边框、徽章或水印。
- 在深蓝、浅灰和实际背景三种底色上检查透明边缘，确认没有实底、棋盘格、白边、残留场景或抠掉的发丝。

### 光照

角色使用温和、近似正面的中性主光，保留局部固有色；胜利场景由左上方暖光提供统一方向。金色只占少量光边与尘埃，不把白发、白翼或白衣染成金色。避免每个人自带不同方向的强烈投影。人物在画面里的明暗与附属光效分开调整。

## 2. 四人普通胜利构图

主题提案：**晨光中的战后收势**。画面情绪是紧张散去、旅途继续。人物保持各自姿态，通过朝向和留白形成联系。背景为柔和晨空、远处道路及低对比的石质遗迹轮廓；这些是本主题的场景提案，不是新增游戏剧情地点。

左前：卡洛琳；左后：可可；右前：乌娜；右后：阿米莉娅。此顺序只用于样张美术验证。正式队伍的SeatIndex和玩家顺序需要保持原有权威合同，通过布局槽位适配。

顶部左侧`x=0.055,y=0.065,w=0.27,h=0.13`留作标题区，主文案建议“胜利”；副文案“旅途仍在继续”为可选提案。底部约12%由低对比雾与轻薄前景连接人物裁切，姓名作为小型署名，不设置个人姓名牌。

面部保留区之间不允许其他人的羽翼、帽檐、手、光轮或文字穿过。手势区保留完整手指和关键持物；可遮挡衣摆、羽翼尖端和不承担动作意义的发尾。四人脸部显示尺度接近，前后差异主要来自躯干位置和遮挡。

示意图使用纯几何标记保留区和轮廓走向，仅供构图审核。原图也仅作为形象参考，不能把审阅页当作完成的CG。

### 镜头节奏提案

基准5秒：约0.35秒柔和显现；约3.9秒稳定阅读，整体镜头由1.00轻推到1.025；约0.75秒淡出。背景位移小于画布宽度0.6%，前景位移小于1.2%，不对角色整体做呼吸形变，不对称摇摆，不闪白。玩家时长设置继续优先生效。减少动态模式保持稳定构图，仅淡入淡出。

## 3. 首轮验证包

| 编号 | 形象与事件 | 具体动作 | 主要检查 |
| --- | --- | --- | --- |
| P01 | 卡洛琳·普通胜利 | 收披风、放松肩部、向内回望 | 红披风、辫子、胸饰保真；脸与手分离 |
| P02 | 可可·普通胜利 | 指尖勾画后的收势、半收羽翼 | 白发与白翼区分；2B发夹；翼端不压邻脸 |
| P03 | 阿米莉娅·普通胜利 | 半合书本、扶帽檐、轻松微笑 | 大帽檐与书手同时可读；保持随性的情绪 |
| P04 | 乌娜·普通胜利 | 掌上白金火焰收小、放松肩部 | 光轮与衣袖占幅；细腻上色与原版形象协调 |
| P05 | 卡洛琳·战斗失败 | 一手扶另一上臂、垂眸收肩 | 同一人物在情绪改变后仍有辨识度 |
| P06 | 可可·仪式胜利 | 双手相向画弧，引导小型仪式中心 | 双手语义清楚；白翼、光环和场景阵式分层 |

建议顺序：先P01、P02成对验证身份、细腻画风和透明边缘；形成可用风格样张后完成P03、P04并组装四人图；随后P05、P06检查同一身份跨事件的一致性。首轮六张都使用正式素材规格，能通过的素材直接留作正式资产。

每次出图输入当前角色的原始参考。选定风格样张只提供线条、材质和光照参考，不提供别人的脸或服装。每次修订只调整一个明确问题，同时重复身份约束；不能仅拿前一次生成图继续链式改绘。

## 4. 生产规模与归档

完整基础规模是15×7=105张角色姿势图、7套事件主题背景与所需装饰层。不同队伍组合复用这些素材。候选图、透明清理修订和拆层输出不计入105张正式姿势的数量。

建议候选归档到`output/imagegen/event-cg/<art-id>/<event-id>/`，记录源参考SHA-256、请求模型、实际工具/可确认模型、最终提示词、生成文件、选定版本和修订理由。正式资源通过后再放入AuraToolsExp拥有的共享资源目录，并建立owner-qualified逻辑ID。不得让游戏运行时依赖本机参考目录的绝对路径。

本包的短ID和候选RoleId仅为制作管理信息，没有注册到游戏。异色与形态的具体绑定必须结合真实加载资源核对；尤其不能用一张人形参考暗中替代未提供的巨兽形态。

## 5. 与现有系统的接入边界

绘制包完成后，接入需要把角色素材入口从Idle动画扩展为事件姿势选择，在同一共享规划器和渲染器内支持附属效果、前景及面部/动作锚点。沿用现有真实队伍快照、预览/正式播放共用链路、联机身份验证、缓存租约和清理机制。

届时一起更新受影响的注册、设置读取与写入、布局、文档和包资源；迁移已支持的玩家背景/时长覆盖。新增资源层或网络字段需要按真实协议变化评估，不能把本设计稿中的坐标直接塞进现行协议。本轮不修改这些运行合同。

## 6. 验收与当前证据

绘制验收：角色身份、手指与持握、原有饰件、真实透明边缘、动作语义；组成四人图后检查所有脸部保留区、动作区、视线、光源和标题。暂停画面仍应成立。

运行验收属于后续接入阶段：1—8人、宽窄画面、当前皮肤、异色/形态绑定、设置页与正式播放一致、连续播放与模块关闭后的释放。不以文档检查或概念图代替真实游戏画面。

本次结构检查通过：15张参考、15套形象、7类事件、105条动作、6条角色提示词、3条场景素材提示词、84处本地链接；构图SVG可以解析，四个脸部保留区与手势区有界且互不交叠。

浏览器工具的URL安全策略阻止了本地HTML预览，因此没有完成该页面的浏览器渲染检查。首轮输出PNG与视频中间帧已直接查看，六张主姿势的真实RGBA与视频规格另外记录在输出目录。美术取舍等待看图反馈，Unity中的最终效果尚未运行验证。
