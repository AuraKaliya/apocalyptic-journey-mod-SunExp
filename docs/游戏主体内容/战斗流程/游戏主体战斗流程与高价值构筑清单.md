# 游戏主体战斗流程与高价值构筑清单

本文与[游戏主体卡牌总表](../卡牌内容/游戏主体卡牌总表.md)、[游戏主体遗物总表](../遗物内容/AuraToolsExp-training-relic-catalog.md)、[游戏主体 BUFF 总表](../BUFF内容/游戏主体BUFF总表.md)配套使用。

- 口径：游戏构建 `1.0.23816797`。
- “体系核心”指决定资源闭环、区域流转、重复触发或胜利条件的构筑轴。
- “高价值”指不依赖完整流派，也能明显改善当场战斗的牌或遗物。
- “流派组件”依赖特定词条、BUFF、卡包或队伍条件，离开对应体系后价值会明显下降。
- “牌堆循环”指抽牌堆不足时把弃牌堆洗回并继续抽牌；卡面上的“循环”只称为“循环词条”。
- “有限连打”会持续消耗魔能、生命、状态或一次性过牌；“无限闭环”要求重复所需的资源状态复现，伤害、护盾和状态成长等单调收益另行计算。
- 这不是全卡牌强度榜；未列出的牌不等于低价值。风险、Boss 机制、多人目标和牌组厚度都可能改变结论。

## 一、战斗流程与价值窗口

### 1. 战斗开始

1. 由冒险牌组建立战斗抽牌堆并洗牌。
2. 初始化角色、敌人、卡牌、BUFF 与遗物监听。
3. 触发战斗开始效果；初始抽牌、初始魔能、临时属性、敌方负面状态和复活资源都在这一窗口进入战斗。

高价值重点：

- 战斗开始立即给牌或魔能的遗物能降低首回合事故率。
- “战斗开始获得循环 BUFF／元素／神启／重生”的遗物通常是对应流派的启动器。
- 首回合爆发体系优先评价即时资源，不应把需要数回合成长的收益等价计算。

### 2. 玩家回合开始

稳定顺序可概括为：

1. 若当前魔能低于魔能上限，则恢复到上限；高于上限的溢出魔能不会在此步骤被主动截断。
2. 保留已有护盾；只有伤害、腐朽或明确的清盾效果会减少或移除护盾。
3. 触发 `StartRound` 类效果，包括灼烧、自愈、敏锐、回合开始遗物及部分仪式。
4. 刷新状态并按本回合抽牌数抽牌。若抽牌堆不足，会先抽完剩余卡牌，再把弃牌堆洗回并继续满足同一次抽牌请求。
5. 抽牌时逐张执行卡牌初始化和抽到效果，并在实际洗回时触发洗牌事件。
6. 进入可出牌窗口。

高价值重点：

- 回合开始额外魔能、额外抽牌、手牌减费、生成牌优先于普通数值增益。
- 护盾是可跨回合储存的生存资源，超过当前敌方意图的护盾不应直接视为浪费。
- 灼烧在回合开始结算，能在敌人行动前完成击杀；流血通常在“行动”时结算，两者时序不同。
- 手牌上限会限制额外抽牌的兑现率；跨回合保留的牌会占据抽牌槽，因此大量抽牌必须配合减费、打出、焚毁、弃牌或扩大手牌上限。

### 3. 打出卡牌

主体流程为：

1. 检查目标、当前回合、卡牌可用性与费用。
2. 计算费用：基础费用经全局费用倍率处理后，上限为 4，再叠加永久、临时和单次费用修正，最终不低于 0。
3. 非循环词条牌先离开手牌；具有循环词条的牌在本次行动窗口留在手中，可以再次打出。
4. 触发出牌事件，然后扣除魔能；实际发生耗能时触发耗能事件，魔能不大于 0 时还会触发无魔能事件。
5. 扣减 `ReducePerUse` 类型状态层数。
6. 执行卡牌预使用脚本，再按当前 `UseCount` 重复执行卡牌效果。
7. 触发行动后事件；非循环词条牌进入弃牌堆或按“焚毁／虚无”等词条离场，并执行对应区域事件。

高价值重点：

- 出牌事件发生在扣费之前，因此“出牌时回魔”可以直接抵消本次费用。
- “额外生效一次”放大的是卡牌使用脚本，不等同于复制一张牌。
- 循环词条只是手内重复载体，不等于牌堆循环或无限；它仍会占据手牌槽，并受魔能、生命、状态层数和使用次数等有限资源约束。
- 无限闭环必须同时复现魔能、牌区、手牌槽和必需状态，之后再判断每轮能否单调增加伤害、护盾或其他收益。

### 4. 回合结束

1. 触发回合结束效果。
2. 处理未被保留的手牌；未打出的循环词条牌也会在此进入弃牌堆，只有保留词条或额外保留名额能跨回合保存。
3. 扣减 `ReducePerTurn` 类型状态层数。
4. 进入其他友方或敌方行动；敌人完成行动后同样结算其回合结束效果。

高价值重点：

- 时之笼、毒素、鬼化、仪式、复还、保留和部分遗物都依赖回合结束窗口。
- 保留能够保存组合技组件，但被锁在手中的牌不会进入本轮弃牌堆，也会压缩下一回合的实际抽牌空间。
- 需要在回合结束时保有魔能或手牌的体系，与“消耗剩余魔能”“焚毁全部手牌”类效果存在直接冲突。

### 5. 洗牌、受击、死亡与战斗结束

- 抽牌堆不足以满足当前抽牌请求时，弃牌堆洗回抽牌堆并继续抽牌；这一次牌堆循环会触发洗牌事件，`循环` BUFF 在此回魔。
- 弃牌堆为空或手牌已经达到上限时，剩余抽牌无法兑现。牌组越薄、被保留锁住的牌越少，关键牌重新进入手牌的速度通常越快。
- 普通伤害、真实伤害、异常伤害的减免与触发条件不同，不能只按最终伤害数字评估。
- 死亡会先检查重生、遗物复活、Boss 阶段或专属特性；“立即获胜”类仪式也可能绕过常规伤害终结。
- 战斗结束后的金币、永久属性、遗物奖励和牌组改造属于跨战斗价值，不应与单场输出混为一类。

## 七、牌堆循环、手内重复与无限闭环

### 1. 闭环判断模型

不要用“某张牌能反复打出”直接判定无限。应先检查重复动作所需的资源状态能否复现：

1. 魔能不低于重复前，且费用减免、回魔次数等没有被永久消耗。
2. 关键牌回到相同的可访问牌区；依靠抽牌的闭环还要考虑弃牌堆洗回、实际抽牌槽和洗牌后的顺序。
3. 手牌占位不恶化；循环词条牌和保留牌不能把后续抽牌锁死。
4. 生命、神启、复还、重生、仪式次数等有限资源不持续下降。
5. 概率回魔或概率重复不能作为确定性资源来源。

资源状态复现后，再单独计算每轮单调收益。伤害、护盾、元素、灼烧、蓄势、金币或其他状态持续增长，都可以成为闭环的转化出口；它们不应被混入资源复现条件，反过来阻止闭环识别。

### 2. 已能闭合的确定性无限

#### 破损表盘 + 瞬念

- `relic_24` 破损表盘：每次出牌时获得 1 魔能。
- `counterattackcard_4` 瞬念：基础费用 1，具有循环词条，打出后仍留在当前手牌中。
- 当前出牌顺序是“先触发出牌事件，再扣除费用”，所以每次打出瞬念时先回 1 魔能，再支付 1 魔能，净魔能变化为 0。
- 瞬念在当前行动窗口不会进入弃牌堆，也没有自身次数上限，因此手内重复载体和魔能资源都能复现。

这套核心本身无限叠加蓄势；加入以下任一“每次出牌／行动”收益后即可把无限行动转成实际终结：

| `ritualcard_8` 刀与盾 | 启动后记录实际伤害，回合结束时转为持久护盾；面对单次限伤 Boss，重复攻击仍能累计总伤害并建立高额生存储备 |

## 八、构筑判断顺序

实际选牌或自动战斗评估时，建议按以下顺序判断：

1. 能否在敌人威胁生效前存活。
2. 当前手牌是否有足够魔能启动。
3. 牌组中可洗回的有效牌数是否足够小，关键牌能否在需要的窗口重新抽到。
4. 手牌上限扣除保留牌和其他锁定牌后，是否还有足够的实际抽牌槽。
5. 重复结构是否满足“回魔 ≥ 费用”且关键牌能回到相同可访问牌区。
6. 生命、神启、复还、重生、仪式次数等有限资源是否持续下降。
7. 焚毁、时停、诅咒、概率效果或 Boss 特性是否会中断资源复现。
8. 资源闭合后，每轮能否单调增加伤害、持久护盾、状态、特殊胜利进度或战斗外收益。
9. 若不是确定性闭环，则按失败概率和失败后果重新评价，而不是只看平均收益。
