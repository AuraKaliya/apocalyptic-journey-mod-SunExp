## 维护口径

- 主体配置与 MOD 内容通过完整运行时 ID 分离；本目录不混入 `Terrias_` 等扩展行。
- 原始 `*` 标记与运行时 ID 分开保存：运行时 ID 用于关联，原始 ID 用于判断内部／特殊来源。
- 发生游戏更新时，先刷新 `combat-knowledge/table-exports` 快照，再重新生成内容总表；控制台文档还需重新核对同构建的 `ConsoleLogic.cs`、`Commands.cs` 与输入绑定。
