# 游戏主体角色技能与使魔祝福总表

- 口径：游戏构建 `1.0.24605918`；源数据为安装目录 Addressables 表重建（派生关键词沿用上一份运行时导出模板） `witch-tables-20260807-134623.json`（2026-08-07）。
- 主体与 MOD 通过完整运行时 ID 分离：角色仅收录 `career_*`，使魔仅收录 `Partner_*`，不包含 `Terrias_*` 等扩展内容。
- 共归纳 12 名可选角色、1 个战斗形态与 5 只主体使魔。角色技能说明保留当前游戏显示口径；动态计算仍以实战脚本为准。
- `career_4` 是奈奈的【灾厄化身】，不是独立可选角色；技能牌 ID 中的 `*` 表示内部技能牌，不代表该角色技能不可用。

## 构筑定位

| 内容 | 更适合的方向 | 使用提醒 |
|---|---|---|
| 阿米莉娅 | 稳定检索、坚毅、元素与超凡 | 技能冷却短，适合作为泛用构筑基底。 |
| 奈奈／灾厄化身 | 负面状态吞噬、厄运魔能、形态切换 | SAN 上限较低，需把吞噬与变身节奏一起规划。 |
| 阿黛拉 | 焚毁、灵魂、黑耀棋子 | 灵魂既决定长期成长，也决定回合开始生成的棋子质量。 |
| 卡洛琳 | 护盾、反击、意图破坏 | 伤害随护盾与反击层数成长，偏防守转输出。 |
| 厄米娅 | 混沌标记、随机波动、高生命 | 上下限差距大，技能用于重掷而非消除随机性。 |
| 可可 | Buff 摹写、湮灭、漫画祝福 | 目标选择与被湮灭卡的消耗／等阶决定收益。 |
| 薇薇安 | 流血、鬼化、全场层数爆发 | 适合让多单位共同堆叠流血后集中结算。 |
| 失心躯壳 | 临时复制、永久强化单卡、多次生效 | 【深渊鸣唤】冷却极长，适合围绕关键单卡建立冒险级成长。 |
| 五只主体使魔 | 全场追伤、复活、负面增幅、开局牌或随机行动牌 | 使魔祝福是随使魔绑定的战斗被动，不等同于普通祝福池中的自由选择。 |
