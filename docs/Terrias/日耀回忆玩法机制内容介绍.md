# 日耀回忆：玩法、机制与内容介绍

## 1. 玩法定位

【日耀回忆】是 SunExp 中围绕乌娜与特瑞厄斯旧事展开的专属回忆玩法。它不是普通地图随机推进的冒险，而是带有固定剧情节点、专属整备流程和 Boss 连战结构的独立模式。

模式在选关界面中以「日耀回忆」显示，说明为「乌娜的专属回忆」，副标题为「Boss连战」。底层存档仍使用游戏原生 Normal 流程承载，但会写入 `SunExp_SolarMemoryMode=1` 等专用变量，由 SunExp 运行时接管开局整备、地图节点、剧情推进和结算逻辑。

整体体验可以概括为：

- 开局先进行高度可控的战前整备。
- 地图由三层回忆构成，每层有固定剧情节点和战斗节点。
- 常规战斗之间会穿插六个专属剧情事件。
- 后段以白曜镜阵、无慈第二日轮、白曜圣女·乌娜为核心 Boss 链。
- 最终路线会根据关键卡牌【炽冕崩落】进入不同结局分支。

## 2. 入口与运行形态

【日耀回忆】通过模式入口注册到原生模式选择列表中，排序位于官方模式之后。进入时会创建一份普通模式存档，但专用变量会标记当前存档属于日耀回忆。

重要运行变量包括：

- `SunExp_SolarMemoryMode=1`：标记当前 run 为日耀回忆。
- `SunExp_SolarMemorySelectedPacks`：记录开局允许使用的卡包。
- `SunExp_SolarMemoryOriginPoints=50`：记录本源加点总点数。
- `SunExp_SolarMemoryBlessPickCount`：记录祝福选择状态。
- `SunExp_SolarMemoryPrepStep`：记录整备步骤。
- `SunExp_SolarMemorySetupFinished`：标记整备是否完成。

多人环境中，日耀回忆的开局启动与关键推进由主机负责。整备结束后会提交最终角色状态，避免客户端之间的卡组、本源、祝福结果不同步。

## 3. 开局整备流程

日耀回忆在正式进入地图前会执行三段整备流程：

1. 初始套卡选择
2. 本源加点
3. 祝福选择

整备完成后，玩法才会真正放行地图推进。

### 3.1 初始套卡选择

初始套卡界面标题为「日耀回忆·初始套卡」。玩家需要从启用卡包中选择 11 张卡，形成专属开局卡组。

规则要点：

- 候选卡来自进入模式时选择的卡包。
- 事件牌会被过滤，不进入可选池。
- 支持自动填充、清空、保留官方默认卡组、确认使用当前卡组等操作。
- 确认后会清理备用池，并标记日耀回忆开局卡组已应用。

这一步让日耀回忆从普通开局的固定构筑，转变为玩家主动规划 Boss 连战资源曲线的模式。

### 3.2 本源加点

本源界面标题为「日耀回忆·本源加点」。玩家拥有 50 点本源点数，可以分配到四项属性：

| 属性 | 显示含义 |
| --- | --- |
| Strength | 魔力 |
| Lucky | 精神 |
| Perceive | 感知 |
| Wisdom | 幸运 |

界面提供单点加点、十点加点、重置和确认。每项属性仍受模式内部上限规则约束，玩家需要在输出、生存、资源与判定能力之间做取舍。

### 3.3 祝福选择

祝福选择阶段会按阶级提供固定数量的选择额度，总计 15 个祝福：

| 祝福阶级 | 可选数量 |
| --- | ---: |
| 4 阶 | 2 |
| 3 阶 | 3 |
| 2 阶 | 5 |
| 1 阶 | 5 |

系统会过滤锁定、技术性或不适合直接选择的祝福。玩家必须按阶级完成对应数量的选择，确认后所有选择的祝福会直接授予角色。

## 4. 地图结构

日耀回忆的地图由三层组成：

| 层数 | 层名 | 主题 |
| --- | --- | --- |
| 第一层 | 特瑞厄斯 | 黑日之后的城市与第二日轮的出现 |
| 第二层 | 白曜圣庭 | 乌娜成为圣女后的日常与异变 |
| 第三层 | 圣轮 | 被污染的祈愿、姓名与最终圣冕 |

每层使用 6 个主要节点槽位。日耀回忆会覆盖原生地图生成结果，将关键槽位替换为固定剧情或固定 Boss。其余槽位从 Boss 候选池或普通节点池中补齐。

固定节点结构如下：

| 层数 | 槽位 | 节点 | 类型 | 说明 |
| --- | ---: | --- | --- | --- |
| 第一层 | 0 | 黑日之后 | 剧情事件 | 日耀回忆开端，描述黑日后的特瑞厄斯 |
| 第一层 | 5 | 第二日轮 | 剧情事件 | 白曜圣庭制造第二太阳的叙事节点 |
| 第二层 | 0 | 圣女的日常 | 剧情事件 | 乌娜作为圣女的日常与信仰秩序 |
| 第二层 | 3 | 被污染的光 | 剧情事件 | 城区失色、记忆与亲缘被污染 |
| 第二层 | 5 | 白曜镜阵 | Boss 战 | 第一场专属 Boss |
| 第三层 | 0 | 心哀与挣扎 | 剧情事件 | 被焚烧的姓名与乌娜内心挣扎 |
| 第三层 | 3 | 圣轮之上 | 剧情事件 | 乌娜戴上日冕，承接污染光与祈愿 |
| 第三层 | 4 | 无慈第二日轮 | Boss 战 | 关键分支 Boss |
| 第三层 | 5 | 白曜圣女·乌娜 | 隐藏 Boss 战 | 由【炽冕崩落】分支触发进入 |

第三层末尾需要特别注意：地图层面保留了白曜圣女·乌娜的固定槽语义，但实战进入由击败无慈第二日轮后的分支逻辑驱动。若角色卡组中拥有关键卡牌【炽冕崩落】，运行时会进入白曜圣女前置对白，并创建或切换到白曜圣女·乌娜的 Boss 节点；若没有该卡，则直接进入第二日轮结局并结算。

## 5. 剧情内容

日耀回忆当前保留 6 个地图可见剧情事件，全部使用 `Sub_` 专属事件行，与普通随机事件池隔离。

### 5.1 黑日之后

第一层开端事件。剧情描述黑日之后的特瑞厄斯，城市没有真正的黎明，旧时代的灾厄余波仍停留在街道与记忆里。

### 5.2 第二日轮

第一层末尾事件。白曜圣庭试图制造第二太阳，以人工秩序和圣光压过灾后的黑暗。这一节点将日耀回忆的核心矛盾从城市灾后状态引向白曜信仰体系。

### 5.3 圣女的日常

第二层开端事件。乌娜作为圣女被置于祈祷、注视与职责中，表面是安定的圣庭日常，实际逐渐显露出个人意志被信仰机制吞没的风险。

### 5.4 被污染的光

第二层中段事件。剧情提到失去颜色的城区、记忆被污染、母亲忘记孩子等异变，说明白曜之光不再只是净化力量，也开始侵蚀名字、关系和人的存在感。

### 5.5 心哀与挣扎

第三层开端事件。姓名被无声焚烧，乌娜的行动与痛苦开始直接绑定。它为后续「姓名」「圣冕」「污染光」机制做叙事铺垫。

### 5.6 圣轮之上

第三层中段事件。乌娜戴上日冕，吸收污染之光与祈愿。该事件将回忆推向最终 Boss 链，也解释了白曜圣女·乌娜为何成为终局敌人。

## 6. 对白与结局分支

日耀回忆除地图事件外，还有若干专用对白流程：

| 对白流程 | 触发时机 | 作用 |
| --- | --- | --- |
| 开场对白 | 整备完成后 | 正式开启乌娜的回忆 |
| 第二日轮结局对白 | 击败无慈第二日轮且未触发隐藏分支 | 进入普通结算 |
| 白曜圣女前置对白 | 击败无慈第二日轮且拥有【炽冕崩落】 | 引导进入隐藏 Boss |
| 白曜圣女结局对白 | 击败白曜圣女·乌娜后 | 完成隐藏结局并结算 |

关键分支条件是角色卡组是否拥有【炽冕崩落】。

- 没有【炽冕崩落】：击败无慈第二日轮后播放第二日轮结局对白，随后进入结算。
- 拥有【炽冕崩落】：击败无慈第二日轮后播放白曜圣女前置对白，随后挑战白曜圣女·乌娜。胜利后播放白曜圣女结局对白，再进入结算。

## 7. 战斗与奖励规则

日耀回忆中的敌人会在初始化后统一获得生命值放大。当前实现会将日耀回忆内敌人的最大生命值和当前生命值放大为 3 倍，并确保同一敌人不会被重复缩放。

战斗奖励方面，日耀回忆会在每场战斗奖励中追加一件随机遗物奖励。特殊隐藏遗物默认会被排除，避免过早破坏模式平衡。

## 8. 专属 Boss 机制

### 8.1 白曜镜阵

基础属性：

| 项目 | 数值 |
| --- | ---: |
| 生命 | 180 |
| 攻击 | 12 |
| 防御 | 8 |
| 行动次数 | 2 |

核心机制是「镜阵」与烧伤循环。

机制要点：

- 敌方回合开始时，全体目标获得 2 层烧伤。
- 白曜镜阵会根据队伍当前烧伤总层数获得护盾。
- 若场上无人处于烧伤压力，镜阵会重新校准光照。
- 若目标已有烧伤，部分行动会额外触发一次烧伤结算。

主要敌方卡：

| 卡牌 | 效果概述 |
| --- | --- |
| 校准光照 | 全体获得烧伤，Boss 获得护盾 |
| 环日折射 | 造成伤害并施加烧伤；若目标已有烧伤，则触发烧伤 |

白曜镜阵考验的是玩家在持续烧伤压力下维持生命、控制负面状态与抢节奏的能力。

### 8.2 无慈第二日轮

基础属性：

| 项目 | 数值 |
| --- | ---: |
| 生命 | 360 |
| 攻击 | 16 |
| 防御 | 12 |
| 行动次数 | 2 |

无慈第二日轮的核心机制是「终日」与姓名焚烧。

机制要点：

- 敌方回合开始时，如果队伍总烧伤层数达到 8 层或以上，会尝试焚烧 1 个已保存姓名。
- 如果没有可焚烧的已保存姓名，则全体玩家获得 10 层身体烧伤。
- Boss 行动会持续提高烧伤压力，并在高烧伤目标身上追加虚弱与残废。

主要敌方卡：

| 卡牌 | 效果概述 |
| --- | --- |
| 晨祷校准 | 全体获得烧伤，Boss 获得聚焰 |
| 正午断脊 | 造成高额伤害；若目标烧伤达到阈值，则触发烧伤并追加虚弱、残废 |

无慈第二日轮是日耀回忆的关键分歧点。击败它后，系统会检查角色是否拥有【炽冕崩落】，并据此决定是否进入白曜圣女·乌娜路线。

### 8.3 白曜圣女·乌娜

基础属性：

| 项目 | 数值 |
| --- | ---: |
| 生命 | 320 |
| 攻击 | 14 |
| 防御 | 14 |
| 行动次数 | 2 |

白曜圣女·乌娜的核心机制是「圣祷」「圣辉」与「圣冕显化」。

机制要点：

- 敌方回合开始时，如果 Boss 自身没有身体烧伤，会焚烧 1 个已保存姓名。
- 焚烧姓名后，Boss 获得圣辉与基于最大生命值的护盾。
- 圣辉达到 12 层后，进入「圣冕显化·白曜」阶段。
- 部分行动会清除玩家正面状态，或把已保存姓名转化为无名。
- 如果没有可转化姓名，Boss 会改为获得大量圣辉。

主要敌方卡：

| 卡牌 | 效果概述 |
| --- | --- |
| 圣女净祷 | 造成伤害，施加身体烧伤，移除目标正面状态，Boss 获得圣辉 |
| 刻名归庭 | 造成伤害，将 1 个已保存姓名转为无名；若无可转化姓名，Boss 获得圣辉 |
| 白曜敕令 | 圣冕阶段的追加行动，效果接近圣女净祷 |

「圣冕显化·白曜」最多提升到 5 阶，每回合提高一阶：

| 阶段 | 效果 |
| ---: | --- |
| 1 阶 | 清理 Boss 负面状态并转化为余烬压力 |
| 2 阶 | Boss 获得额外行动 |
| 3 阶 | 触发全体玩家烧伤 |
| 4 阶 | 每回合湮灭 3 张随机玩家卡牌 |
| 5 阶 | Boss 每次行动后，对全体玩家造成等同最大生命值的真实伤害 |

白曜圣女·乌娜是隐藏路线的终局战。战斗会同时压迫卡组、姓名、正面状态、烧伤承受能力和爆发窗口。

## 9. 内容隔离与稳定性设计

日耀回忆为了避免污染普通模式，采用了较多隔离策略：

- 专属事件使用 `Sub_` 事件行，不进入普通随机事件池。
- 专属地图节点使用隐藏稀有度与专用地图 ID。
- 固定剧情节点由日耀回忆地图运行时强制替换。
- 开局卡组选择会过滤事件牌。
- Boss 节点与剧情对白通过专用变量记录，避免重复触发。
- 旧版终幕事件链已废弃，当前结局主要由 Boss 胜利后的对白和结算流程承载。

## 10. 设计总结

【日耀回忆】的玩法重点不是无限成长，而是一次经过预构筑、预加点、预祝福后的高压 Boss 旅程。它通过三层固定回忆，把乌娜、白曜圣庭、第二日轮、圣冕和姓名机制串成一条叙事线；再通过烧伤、姓名焚烧、圣辉、圣冕阶段等战斗机制，把剧情主题转化为实际压力。

对玩家而言，核心策略是：

- 开局卡组要能承受持续烧伤和高血量 Boss。
- 本源加点需要在爆发、续航、判定和容错之间平衡。
- 祝福选择要服务于 Boss 连战，而不是单场爆发。
- 是否携带并保留【炽冕崩落】，决定能否进入隐藏终局。
