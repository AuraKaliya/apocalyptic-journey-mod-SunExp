# 日耀卡包机制与内容介绍

本文整理特瑞厄斯内容中三个日耀卡包：【日耀：星火】、【日耀：烬冠】、【日耀：天幕】。数据主要来自 `SunExp/Data/Card/sunexp.csv`、`SunExp/Text/Card/sunexp.csv`、`SunExp/Data/CardPack/sunexp.csv`、`SunExp/Text/CardPack/sunexp.csv`、`SunExp/Data/Relic/sunexp.csv`、`SunExp/Text/Relic/sunexp.csv`，机制以 `SunExp-Dev/Scripting/CardScripts.cs`、`SunExp-Dev/Scripting/RelicScripts.cs`、`SunExp-Dev/Scripting/BuffScripts.cs`、`SunExp-Dev/Mechanics/SolarRadianceService.cs` 和 `SunExp-Dev/GameApi/SolarCombatApi.cs` 为准。

## 总览

日耀体系以灼烧为外部压力，以日耀、聚焰和圣冕显化为内部资源。整体循环是：通过白曜牌和少量基础牌积累日耀，用日耀系数放大伤害或护盾；通过自身灼烧、敌方灼烧和回收牌积累聚焰；在日耀层数足够时进入圣冕显化，改为通过白曜牌触发圣冕等阶效果，再用炽冕崩落等高稀有牌结算爆发。

三个卡包的定位如下。

| 卡包 | 运行时 ID | 内容数量 | 主题定位 |
| --- | --- | ---: | --- |
| 【日耀：星火】 | `SunExp_sunexp_cardpack_radiant_spark` | 13 张牌，5 件遗物 | 基础启动包，提供日耀、白曜、烬衣、圣冕入口和低复杂度灼烧转换。 |
| 【日耀：烬冠】 | `SunExp_sunexp_cardpack_ember_crown` | 9 张牌，4 件遗物 | 聚焰与自燃压力包，把自身灼烧或敌方灼烧回收成聚焰，再以圣冕和聚焰爆发。 |
| 【日耀：天幕】 | `SunExp_sunexp_cardpack_solar_canopy` | 8 张牌，4 件遗物 | 场地与扩散包，围绕灼热天幕、全体灼烧、负面 Buff 和持续扩散。 |

## 共通机制

### 白曜与日耀

带有 `白曜` 标签的卡牌在打出后进入统一的行动后结算。若玩家没有 `圣冕显化`，就按本次实际费用获得等量 `日耀`；若已经拥有 `圣冕显化`，则不再加日耀，而是触发一次圣冕等阶效果。`炽冕崩落`是特殊处理：它跳过普通白曜监听，在自身脚本中按 3 费手动触发日耀或圣冕。

`日耀`本身每次行动会给自身 `5 * 日耀层数` 的超凡。普通角色日耀上限为 12，乌娜相关运行时会把上限扩展到 15。

### 日耀系数

日耀系数用于部分日耀牌的伤害或护盾显示和结算：

`日耀系数 = 日耀层数 * 2 + 聚焰层数 / 3 + 目标灼烧层数 / 2`

拥有 `圣冕显化` 时，整个日耀系数再乘以 2。因此日耀牌的爆发并不只来自日耀层数，也会吃到聚焰积累和目标身上的灼烧。

### 圣冕显化

获得 `圣冕显化` 时，会按当前日耀层数确定 `圣冕等阶`：

| 日耀层数 | 圣冕等阶 |
| ---: | ---: |
| 1-3 | 1 |
| 4-7 | 2 |
| 8-11 | 3 |
| 12-14 | 4 |
| 15+ | 5 |

圣冕持续期间会让日耀系数翻倍。之后打出白曜牌会触发圣冕，不再按费用获得日耀。圣冕触发时按等阶依次获得最多 5 个效果：1 阶把自身负面 Buff 清除并转化为等量灼烧；2 阶抽 1 张牌；3 阶获得 1 点魔能；4 阶把自身灼烧清除并转化为等量聚焰；5 阶让敌方全体获得 5 层灼烧并立即触发一次。

圣冕清除时会消耗 `2 * 圣冕等阶` 层日耀，并移除圣冕等阶。

### 聚焰、自燃与灼热天幕

`聚焰`是高上限资源。回合开始时，聚焰会让自己获得等量灼烧，并获得 `10 * 聚焰层数` 的超凡。它既是输出资源，也是自燃压力来源。

`灼热天幕`是场地能力。天幕存在时，每轮回合开始全体获得等同天幕层数的灼烧。天幕还会把任何目标获得灼烧时超过灼烧上限的部分转换为等量 `焚身`。`焚身`在回合开始按每层 `最大生命值 1% + 1` 造成真实伤害，然后移除。

## 【日耀：星火】

### 卡包定位

星火是日耀体系的基础包。它提供最稳定的日耀启动、白曜牌密度、早期圣冕入口和自保工具。星火的复杂度最低，适合作为日耀构筑的底盘：先攒日耀，再用日耀系数牌获得稳定收益，最后通过 `日耀：授冕` 或相关遗物打开圣冕循环。

### 主要循环

1. 用 `星火`、`太阳圣祷`、`日耀：回转`、白曜牌行动后结算来积累日耀。
2. 用 `耀焰斩`、`晨光壁垒`吃日耀系数，获得伤害或护盾。
3. 用 `烬衣`和 `太阳圣祷`处理自身灼烧压力。
4. 用 `日耀：授冕`进入圣冕显化，并让后续白曜牌触发圣冕等阶。
5. 用 `圣庭净裁`把敌方非灼烧 Buff 清成灼烧，给天幕或烬冠路线提供燃料。

## 【日耀：烬冠】

### 卡包定位

烬冠是日耀体系的高压资源包。它通过灼烧、聚焰、余烬和圣冕把战斗推向爆发，但代价是自己也会被灼烧反噬。烬冠牌往往先把灼烧回收成聚焰，再把聚焰转为伤害、护盾或敌方全体灼烧。

### 主要循环

1. 用 `引炎`、`灼流回收`从任意目标或敌人身上拿走灼烧，转化为聚焰。
2. 用 `凝烬成塔`把自身灼烧转为聚焰，或者用 `聚炎轮转`让后续自身灼烧自动补聚焰。
3. 用 `燃星之咒`、`燃冠誓言`、`炎轮再临`把聚焰和敌方灼烧转为爆发。
4. 用 `聚炎护盾`把聚焰转为防御。
5. 用 `炽冕崩落`在圣冕等阶足够时结算全体爆发。

## 【日耀：天幕】

### 卡包定位

天幕是日耀体系的场地和持续扩散包。它通过灼热天幕让全场持续获得灼烧，并利用敌方灼烧、腐朽、虚弱和正面 Buff 清除来制造长期压力。天幕存在时，灼烧溢出会转为焚身，使灼烧上限不再是收益天花板。

### 主要循环

1. 用 `灼热天幕`、`天幕再临`建立或提高天幕层数。
2. 用 `冠冕威光`、`日蚀`、`燃灾`、`蚀天之咒`提高敌方灼烧与负面状态。
3. 用 `太阳瓶`、`燃灾风带`等遗物持续触发或扩散敌方灼烧。
4. 用 `焚污除秽`把自身负面状态转为灼烧，再配合烬冠或星火工具处理。

## 组合建议

星火适合搭配任何日耀路线，尤其是需要稳定白曜触发和圣冕入口的构筑。烬冠适合已有自燃、防护或日耀系数支撑的构筑，爆发更高但需要处理灼烧反噬。天幕适合敌方数量较多、需要持续压制的战斗，和烬冠的灼烧回收、星火的圣冕触发都有明显联动。

如果要把三包放进同一构筑，推荐主线是：星火提供启动和授冕，天幕制造全体灼烧环境，烬冠把灼烧回收为聚焰并用炽冕崩落收束。
