# 无尽之渊：玩法、机制与内容介绍

## 1. 玩法定位

【无尽之渊】是 SunExp 中的长线挑战玩法，核心目标是在不断加深的楼层中规划开局主题、布置地图节点、承受深渊震荡，并尽可能推进到更高层数。

代码中仍保留了大量历史命名「无尽之海之塔」与 `EndlessSea`，但当前玩家侧标题、入口视觉和配置均指向【无尽之渊】。因此在内容整理中统一使用「无尽之渊」，仅在实现来源处保留原始文件名。

无尽之渊的体验可以概括为：

- 开局选择一个主题卡包，组成固定基础牌加主题牌的初始卡组。
- 每层地图有 6 个节点，首尾固定，中间 4 个节点由玩家拖拽节点卡规划。
- 1 至 6 层为潜行模式，难度逐层提升，并每层承受一次深渊震荡。
- 第 7 层起进入无尽模式，没有终点，每场战斗后都会触发深渊震荡。
- 注视等级会提高震荡必选数量，也会提高敌人生命成长。
- 战斗奖励、里程碑奖励、焚毁与绝灭机制共同构成长期资源压力。

## 2. 入口、存档与继续挑战

无尽之渊通过模式入口注册到模式选择界面，排序位于日耀回忆之后。入口标题为「无尽之渊」，说明为「无尽之战」，使用专属标题图。

进入时，系统会检查是否存在未完成的无尽之渊存档：

- 如果存在未完成 run，会弹出继续挑战或重新开始的确认窗口。
- 如果选择继续挑战，则恢复最新未完成存档。
- 如果选择重新开始，则清理未完成 run 并创建新 run。

底层存档同样使用原生 Normal 模式承载，依靠专用变量识别玩法状态。新 run 初始化时会写入：

- 当前楼层为 1。
- 已生成楼层为 0。
- 开局引导未完成。
- 主题卡组未应用。
- 注视等级初始化。
- 当前阶段为 Intro。
- 运行版本、随机种子、楼层规划、震荡记录等账本信息。

多人环境中，开局启动和关键推进由主机负责。

## 3. 运行阶段

无尽之渊内部把一次 run 划分为多个阶段：

| 阶段 | 含义 |
| --- | --- |
| Intro | 开局说明与主题卡组选择 |
| MapPlanning | 地图规划阶段 |
| InBattle | 战斗阶段 |
| Reward | 战斗奖励阶段 |
| BetweenFloors | 楼层切换阶段 |
| Ended | run 结束 |

这些阶段用于控制地图面板、奖励面板、深渊震荡、楼层推进和存档恢复。

## 4. 开局主题卡组

无尽之渊开局会让玩家选择一个主题卡包。最终初始卡组固定为 15 张：

- 11 张固定基础牌。
- 4 张主题牌。

固定基础牌组成如下：

| 卡牌 ID | 数量 |
| --- | ---: |
| `card_1` | 3 |
| `card_2` | 4 |
| `card_3` | 2 |
| `card_4` | 1 |
| `burningcard_1` | 1 |

主题卡包会根据当前启用内容动态出现。默认的「学院必修」始终可用，其余主题随对应卡包启用而开放，例如教廷防卫、时空奇旅、黑色巫术、蛇影、奥尔德林神谕、混沌乐团、血鬼谱系、元素、法术序列、超位仪式等。

主题选择界面会展示每个主题对应的 4 张主题牌，方便玩家提前判断开局方向。

## 5. 地图结构与节点规划

无尽之渊每层地图固定为 6 个主要节点：

| 槽位 | 类型 | 说明 |
| ---: | --- | --- |
| 0 | 固定怪物节点 | 每层起始战斗 |
| 1 | 玩家规划节点 | 由节点卡填入 |
| 2 | 玩家规划节点 | 由节点卡填入 |
| 3 | 玩家规划节点 | 由节点卡填入 |
| 4 | 玩家规划节点 | 由节点卡填入 |
| 5 | 固定 Boss 节点 | 1 至 6 层为 Boss，第 7 层起为无尽 Boss |

中间 4 个节点不会直接随机生成，而是由玩家从手牌中的节点卡拖拽填入。每轮可选节点卡数量为 8 张，基础结构为：

- 1 张休息节点。
- 1 张建筑节点。
- 若干精英节点。
- 剩余位置为普通怪物节点。

精英节点数量随阶段变化：

| 楼层 | 精英节点数量 |
| ---: | ---: |
| 1 至 2 层 | 0 |
| 3 至 6 层 | 1 |
| 7 层及以上 | 2 |

节点池会过滤不适合无尽之渊的内容，例如隐藏稀有度节点、事件节点、被禁用节点、锁定节点等。Boss 候选会根据楼层选择普通 Boss、特殊 Boss 或无尽 Boss。

当原生地图推进完 6 个节点后，系统会将楼层加 1，重置本层地图进度，并生成下一层计划。

## 6. 潜行模式与无尽模式

### 6.1 潜行模式

第 1 至 6 层属于「潜行模式」。

潜行模式的特点：

- 每层都会在地图场景中触发一次深渊震荡。
- 敌人强度和奖励随楼层提高。
- 玩家需要在较低资源压力下完成卡组和遗物雏形。
- 第 6 层结束后进入第 7 层，即正式进入无尽模式。

### 6.2 无尽模式

第 7 层及以后属于「无尽模式」。

无尽模式的特点：

- 没有固定终点。
- 每场战斗后都会排队一次深渊震荡。
- 第 7 层起注视等级至少会被校正到 5。
- 固定末尾节点变为无尽 Boss。
- 战斗中会注入额外敌人，显著增加压力。

在无尽模式中，玩家的主要目标不再是通关，而是在资源不断被压缩的情况下尽可能推进更高楼层。

## 7. 注视等级

注视等级是无尽之渊的核心难度计量。

配置要点：

| 项目 | 当前值 |
| --- | ---: |
| 初始注视等级 | 1 |
| 进入无尽模式时的最低注视等级 | 5 |
| 震荡必选数量增长步长 | 每 3 级 |
| 最大震荡必选数量 | 3 |
| 注视每级提供的敌人生命成长 | 8% |

深渊震荡需要选择的选项数量由注视等级决定：

| 注视等级 | 必选数量 |
| ---: | ---: |
| 1 至 3 | 1 |
| 4 至 6 | 2 |
| 7 及以上 | 3 |

计算公式为：

```text
必选数量 = clamp(1 + floor((注视等级 - 1) / 3), 1, 3)
```

第 7 层及以后，每次无尽战斗后的震荡结算还会额外使注视等级被动增加 1。也就是说，即使玩家不主动选择「注视加深」，无尽阶段的注视等级仍会持续升高。

## 8. 深渊震荡

深渊震荡是无尽之渊的核心代价机制。震荡会在两种情况下产生：

- 潜行模式中，每层触发一次。
- 无尽模式中，每场战斗后触发一次。

震荡面板标题为「深渊震荡」，会显示当前注视等级和本次必须选择的选项数量。玩家必须选择刚好指定数量的震荡选项，才能点击「承受」继续。

当前震荡选项如下：

| 选项 | 效果 | 失败回退 |
| --- | --- | --- |
| 遗物坠落 | 随机销毁 1 件已装备遗物 | 如果没有可销毁遗物，则注视等级 +1 |
| 湮灭浸染 | 给当前卡组内随机 3 张卡添加湮灭 | 如果没有可处理卡牌，则注视等级 +1 |
| 注视加深 | 注视等级 +1 | 无 |

震荡使用账本记录已触发和已承受的震荡，避免同一楼层或同一战斗重复触发。

## 9. 敌人强度成长

无尽之渊会在敌人初始化后，根据楼层与注视等级放大敌方生命值。

当前生命倍率公式为：

```text
生命倍率 = min(
  20,
  1
  + 0.12 * (当前楼层 - 1)
  + 0.03 * max(0, 当前楼层 - 10)
  + 0.08 * (注视等级 - 1)
)
```

含义如下：

- 每提升 1 层，敌人生命至少增加 12%。
- 第 11 层起，每层额外再增加 3%。
- 注视等级每提高 1 级，敌人生命额外增加 8%。
- 最终倍率上限为 20 倍。

如果只看注视等级为 1 时的楼层成长，大致为：

| 楼层 | 生命倍率 |
| ---: | ---: |
| 1 | 1.00 |
| 2 | 1.12 |
| 5 | 1.48 |
| 10 | 2.08 |
| 20 | 3.58 |
| 50 | 8.08 |
| 100 | 15.58 |
| 约 130 层以后 | 达到 20 倍上限 |

进入第 7 层时，注视等级至少为 5，因此敌人会在楼层成长之外额外获得 32% 生命倍率。

## 10. 无尽阶段额外敌人

第 7 层及以后，无尽之渊会根据当前节点类型向战斗中加入额外敌人：

| 节点类型 | 额外敌人 |
| --- | --- |
| 普通怪物 | 额外加入 1 个普通 Boss 敌人 |
| 精英 | 额外加入 1 个普通 Boss 敌人 |
| Boss | 额外加入 1 个特殊 Boss 敌人 |
| 无尽 Boss | 额外加入 1 个特殊 Boss 敌人和 1 个普通 Boss 敌人 |

这使无尽模式不只是数值膨胀，也会通过敌人组合提高行动压力、目标选择压力和资源消耗速度。

## 11. 战斗奖励

无尽之渊会替换原生战斗奖励，并根据楼层和节点类型发放奖励。

当前奖励结构如下：

| 楼层/节点 | 卡牌选择 | 祝福 | 遗物奖励 |
| --- | ---: | ---: | --- |
| 1 至 2 层 | 2 | 1 | 1 件 1 阶遗物 |
| 3 至 4 层 | 2 | 1 | 1 件 2 阶遗物 |
| 5 至 6 层普通节点 | 3 | 1 | 两组 1 至 3 阶遗物 |
| 5 至 6 层 Boss 节点 | 5 | 1 | 一组 3 至 4 阶遗物 |
| 7 层及以上普通节点 | 5 | 0 | 一组 1 至 4 阶遗物和一组 2 至 4 阶遗物 |
| 7 层及以上 Boss 或无尽 Boss | 5 | 1 | 一组 3 至 4 阶遗物 |

第 7 层以后，普通战斗不再稳定提供祝福，但给出更高数量的卡牌选择和遗物组。Boss 与无尽 Boss 仍会提供祝福。

## 12. 卡牌焚毁规则

无尽之渊中，玩家通过各种渠道获得或生成的卡牌默认会带有原生「焚毁」标记。开局主题卡组的基础牌不作为这个规则的主要惩罚对象，后续从奖励、商店、卡包、仓库、保险箱等渠道获得或展示的卡都会经过焚毁标记处理。

这个机制的目的有两个：

- 限制玩家无限扩展卡组的稳定性。
- 让里程碑奖励中的「清除焚毁」成为长期资源选择，而不是边缘选项。

## 13. 里程碑奖励

从第 2 层开始，每层都可以领取一次里程碑奖励。每层只能领取一次，领取状态由账本记录。

当前里程碑奖励提供四类选择：

| 奖励 | 内容 |
| --- | --- |
| 遗物选择 | 从 1、2、3 阶遗物中任选 1 件 |
| 异次元卡 | 随机获得 1 张异次元卡 |
| 清除焚毁 | 选择当前卡组中 1 张拥有焚毁的卡，移除焚毁 |
| 添加绝灭 | 选择当前卡组中 1 张尚未拥有绝灭的卡，添加绝灭 |

异次元卡优先来自 `SunExp_sunexp_cardpack_more_dimensions` 卡包。如果卡包池不可用，会回退到预设卡牌，例如【变形术】、【魔女投影】、【心变】等。

里程碑奖励是无尽之渊中少数可以主动修正卡组长期缺陷的机制。玩家需要在补遗物、拿特殊卡、清除焚毁、主动添加绝灭之间取舍。

## 14. 本源上限与满值效果

无尽之渊会把四项本源上限提高到 50。达到 50 后会获得额外效果。

| 本源 | 满 50 效果 |
| --- | --- |
| 魔力 | 战斗开始时获得 2 张带有焚毁、破碎和绝灭火漆的不稳定思绪 |
| 精神 | 战斗开始时最大法力值增加 3 |
| 幸运 | 骰子和数值骰额外 +50；若结果达到 150，效果可额外触发 2 次 |
| 感知 | 战斗结束后，将生命和理智恢复到上限 |

这些满值效果为无尽模式提供了长期构筑方向：

- 魔力偏向爆发与高风险临时资源。
- 精神偏向费用上限与回合容量。
- 幸运偏向判定、骰值和高阈值收益。
- 感知偏向战后恢复和续航。

## 15. 策略重点

无尽之渊的核心不是单场强度，而是长期资源规划。

玩家需要同时处理：

- 主题卡组能否支撑前 6 层发育。
- 地图中间 4 个节点如何安排战斗、休息和建筑。
- 是否值得主动选择更高收益但更高风险的节点。
- 震荡选项如何分摊遗物损失、卡牌湮灭和注视提升。
- 里程碑奖励是补强遗物、拿特殊卡，还是修复焚毁牌。
- 第 7 层后每战震荡和额外 Boss 敌人带来的资源坍缩。

越到后期，玩家越需要把每个资源都视为会被深渊吞掉的消耗品，而不是永久资产。

## 16. 设计总结

【无尽之渊】是一个由楼层、节点规划、注视等级、深渊震荡、卡牌焚毁和里程碑奖励共同驱动的无尽挑战模式。

它的压力来源不是单一的敌人变强，而是多条曲线同时推进：

- 楼层提高让敌人生命自然增长。
- 注视等级提高让震荡更苛刻，也让敌人更耐打。
- 潜行模式每层震荡，无尽模式每战震荡。
- 卡牌获得默认焚毁，长期卡组稳定性降低。
- 湮灭、遗物销毁和额外 Boss 敌人不断消耗玩家积累。

因此，无尽之渊的核心乐趣在于「带着会持续损坏的构筑前进」。玩家并不是追求一次完美构筑，而是在不断付出代价后，尽量让卡组、遗物、本源和路线规划仍能维持到下一层。
