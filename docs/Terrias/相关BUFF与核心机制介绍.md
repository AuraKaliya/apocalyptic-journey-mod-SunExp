# 相关 BUFF 与核心机制介绍

本文整理日耀、晨星、异次元相关 Buff、关键词、圣冕显化机制和星辰序曲机制。数据主要来自 `SunExp/Data/Buff/sunexp.csv`、`SunExp/Text/Buff/sunexp.csv`、`SunExp/Text/KeyWordsDic/sunexp.csv`、`SunExp/Text/EnchTag/sunexp.csv`，机制以 `SunExp-Dev/Scripting/BuffScripts.cs`、`SunExp-Dev/Mechanics/SolarRadianceService.cs`、`SunExp-Dev/GameApi/SolarCombatApi.cs`、`SunExp-Dev/Mechanics/StarScoreService.cs`、`SunExp-Dev/Mechanics/MorningStarOvertureService.cs` 和相关运行时 Hook 为准。

## 圣冕显化机制

### 进入圣冕

获得 `圣冕显化`时，会立即按当前日耀层数计算圣冕等阶：

| 当前日耀 | 等阶 |
| ---: | ---: |
| 1-3 | 1 |
| 4-7 | 2 |
| 8-11 | 3 |
| 12-14 | 4 |
| 15+ | 5 |

等阶确定后不会因为后续日耀变化自动重算。想获得更高等阶，需要在进入圣冕前先堆高日耀。

### 圣冕期间

圣冕期间，日耀系数翻倍。白曜牌打出后不再按费用加日耀，而是触发圣冕效果。圣冕效果按等阶从低到高累积：

| 等阶 | 追加效果 |
| ---: | --- |
| 1 | 清除自身所有负面 Buff，并转化为等量灼烧。 |
| 2 | 抽 1 张牌。 |
| 3 | 获得 1 点魔能。 |
| 4 | 清除自身所有灼烧，并获得等量聚焰。 |
| 5 | 敌方全体获得 5 层灼烧，并立即触发敌方全体灼烧一次。 |

由于 4 阶会把自身灼烧转成聚焰，而聚焰在回合开始又会重新给自己灼烧，圣冕高阶适合与烬衣、引炎、凝烬成塔、聚炎护盾等牌一起使用。

### 圣冕结束

`圣冕显化`自身有回合衰减。清除圣冕时会消耗 `2 * 圣冕等阶` 层日耀，并移除圣冕等阶。`炽冕崩落`也会主动结束圣冕，并额外消耗全部聚焰、把消耗聚焰的一半变成自身灼烧。

## 星辰序曲机制

### 四种序曲

| 序曲 | 音 | 单卡效果 |
| --- | --- | --- |
| 星辰序曲·启 | 启 | 抽 2 张牌。 |
| 星辰序曲·承 | 承 | 获得 10 护盾，并使自身所有正面 Buff +1。 |
| 星辰序曲·转 | 转 | 给目标 2 层易伤。 |
| 星辰序曲·合 | 合 | 造成 `10 + 自身 Buff 种类数 + 目标 Buff 种类数` 伤害。 |

每张序曲打出后都会推进星谱。星谱记录最近 3 音，满 3 音时结算谱句。

### 记录与保留

星谱满 3 音后，会先记录完成谱句，再触发谱句效果。之后星谱保留最后一音作为下一段谱句起点。因此序曲构筑的节奏会自然串联，玩家可以通过最后一音决定下一段谱句的起手方向。

例如“启承转”触发调律后，当前星谱会保留“转”。下一张如果打“承”，星谱就变为“转承”，再打“启”就能触发“回时”。

### 谱句效果

| 谱句 | 名称 | 效果 |
| --- | --- | --- |
| 启启启 | 急板 | 友方全体余音 +1，友方全体抽 2 张。 |
| 承承承 | 长音 | 友方全体护盾翻倍，友方全体正面 Buff +2。 |
| 转转转 | 失调 | 敌方全体所有负面 Buff 层数翻倍。 |
| 合合合 | 终止式 | 敌方全体受到 `1 + 友方全体 Buff 种类总数 * 敌方全体 Buff 种类总数` 伤害。 |
| 启承转 | 调律 | 自身余音 +1，友方全体余音 +1。 |
| 承转合 | 合奏 | 自身获得友方全体 Buff 种类总数层超凡。 |
| 转承启 | 回时 | 友方全体获得 30 层重生。 |
| 其它 | 三声和弦 | 友方全体抽 1 张。 |

### 与星辰祝福的联动

星辰祝福只影响非星辰序曲牌。它会把下一张非序曲牌费用减半，并在打出后随机给 1 张启、承或转。启明星则会按实际支付费用返还星辰祝福。

这使晨星体系有两个节奏目标：一是通过星辰祝福降低关键非序曲牌的费用，二是通过序曲牌推进星谱并触发谱句。`星图`、`晨星：复奏`和`谱曲`是把这两个目标接起来的主要入口。

## 灼热天幕与焚身溢出

灼热天幕是共享场地状态。它在每轮回合开始给全体添加等同天幕层数的灼烧。只要天幕存在，任何目标新获得灼烧时，如果超过当前灼烧上限，超过部分会转成焚身。若目标拥有烬衣保护，则不会发生这次溢出转换。

这个机制让天幕包可以突破普通灼烧上限，并把多余灼烧变成真实伤害倒计时。它也解释了为什么烬衣、聚焰回收和负面清理在日耀体系里很重要：天幕越厚，自身也越容易被灼烧和焚身压垮。
