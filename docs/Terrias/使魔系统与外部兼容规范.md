# 使魔系统与外部兼容规范

## 系统边界

- 玩家在原生 Partner 选择界面选择的 Partner，就是当前生效的使魔本体。
- 使魔档案只负责查看、改名、选择祝福和重生，不维护额外的随行槽位。
- 每个完整 Partner ID 只保存一个本体档案；使魔不生成投影、精灵或其它战斗单位。
- 冒险开始时固化使魔等级、资质和祝福快照。档案内的后续变化从下一轮冒险开始生效。
- 只有 `Fight_Win.ResetStates` 的胜利路径结算经验和胜利祝福效果；失败、逃跑和战斗重开不结算。

## 成长与重生

| 等级 | 结果 |
| --- | --- |
| Lv.2 | 从通用成长祝福池选择一个祝福 |
| Lv.4 | 从通用成长祝福池选择一个祝福 |
| Lv.6 | 从通用成长祝福池选择一个祝福 |
| Lv.8 | 从最终祝福候选中选择一个祝福 |
| Lv.10 | 解锁重生，不额外生成祝福 |

资质低于 70 时生成 2 个候选，资质达到 70 时生成 3 个候选。成长祝福同时受节点等级和资质阶级上限约束。

最终祝福的候选槽位规则：

- 完整或标签兼容的使魔：至少 1 个专属候选和 1 个通用候选；三选一时，第三项从两池并集加权抽取。
- 零配置兼容的使魔：只从通用最终祝福池抽取。

重生要求 Lv.10 且所有祝福选择已经完成。重生保留 Partner 身份、名称和重生次数，重置等级、经验、资质、成长祝福、最终祝福和待选项。资质保底为 `min(70, 30 + 重生次数 * 5)`。

## 档案存储

档案保存在 `ModsData/Terrias/FamiliarGrowthProfiles/<profile>.json`，写入采用临时文件替换并保留 `.bak`。旧版 `Terrias/FamiliarGrowthProfiles` 档案会在读取后迁移；同种使魔的旧本体和化身会合并为完整 Partner ID 对应的单一本体。

## 外部 MOD 兼容

外部 MOD 可在其顶层目录提供 `familiar.blessing.registry.json`。Terrias 会扫描已加载的 MOD 目录并合并注册表；不支持的效果类型会被拒绝，不影响其它条目。

### 一级：完整专属池

为 Partner 注册明确的最终祝福 ID：

```json
{
  "schemaVersion": 2,
  "ownerModId": "ExampleMod",
  "speciesProfiles": [
    {
      "fullSpeciesId": "ExampleMod_example_partner",
      "speciesId": "partner",
      "tags": ["shield"],
      "finalBlessingIds": ["*example_partner_final_a", "*example_partner_final_b"]
    }
  ],
  "blessings": [
    {
      "id": "*example_partner_final_a",
      "name": "专属最终祝福",
      "description": "战斗开始时，获得20点护盾。",
      "category": "final-species",
      "tier": 5,
      "requiredLevel": 8,
      "allowedSpecies": ["ExampleMod_example_partner"],
      "effects": [{ "kind": "CombatStartShield", "amount": 20 }]
    }
  ]
}
```

### 二级：标签池

只注册 `speciesProfiles.tags`，不填写 `finalBlessingIds`。系统会从 `final-tag` 条目中匹配任一 `requiredTags`，并将匹配结果作为专属候选池。

### 三级：零配置

不提供注册表。Partner 仍会获得本体档案、等级、资质、Lv.2/4/6 通用成长祝福以及重生功能；Lv.8 仅使用通用最终祝福池。

## 支持的效果

当前白名单包括：`BattleWinGold`、`BattleRewardExtraChoice`、`BeforeLethalStarClayBody`、`BurnStackToEmber`、`BurnTriggeredEmber`、`CombatStartBuff`、`CombatStartDraw`、`CombatStartEnemyBuffRandom`、`CombatStartField`、`CombatStartHeal`、`CombatStartResource`、`CombatStartShield`、`EmberOffsetBurnTransfer`、`FirstActionResource`、`FirstDamageTargetBuff`、`FirstStarScoreExtraBlessing`、`RunDiceBonus`。
