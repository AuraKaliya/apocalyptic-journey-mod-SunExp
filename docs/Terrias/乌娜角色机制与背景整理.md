乌娜是特瑞厄斯第二日轮的旧日圣女。她不是奥尔德林本土角色，而是来自另一个已注销世界的魔女，用来展示“当救赎系统本身腐坏时，魔女如何执行毁灭职责”。

当前游戏内职业描述为：特瑞厄斯毁灭之后残存的火焰，白曜圣庭旧日圣女，灾难与灰烬的魔女。

## 背景故事

“特瑞厄斯”毁灭于黑日之灾，至少魔女的档案室里是这么写的。

在那个没有真正太阳的时代里，为了让国家继续拥有昼夜、历法和礼拜，白曜圣庭制造了“第二日轮”。

那轮人造太阳悬在天幕下，照亮王都、边境，照亮每一处受到天幕笼罩的角落。

晨钟照常响起，人们在日轮的光辉下生存，与灾厄之前并没有什么不同。病人在圣祷的光辉下等待痊愈，孩子们将第二日轮画成真正太阳的样子，城中人看见乌娜走过白曜圣庭的长廊，便相信明天仍会有日出。

直到某一天，一处街区失去了颜色。

一个人失去了存在。

空荡荡的房间里，只剩下两副还未被清理的餐具，以及一个茫然的母亲。翻过半页的账单摆在书桌上，但上面的名字像是被某种看不见的火烧尽，只剩无法辨认的白痕。

日轮的光，被天幕污染了。

白曜圣庭不愿承认这件事。对特瑞厄斯的人来说，第二日轮是国家仍能继续运转的证明，是灾厄之后被造出来的明天。承认日轮被污染，就等于承认他们赖以生存的白昼本身已经成为灾厄的通道。

乌娜站在日轮之前，终于下定了决心。

她将所有的灾厄、祈祷和被污染的光辉收入曜日冠冕。

“若是光已无法再赐予众生，那便由我献上最后的祷告。”

日轮的光辉刺破了天幕，但苍穹之外是更加漆黑的灾厄。

冠冕破碎，圣座倾毁。乌娜的存在被烧得干净。圣庭记录中记载她名字的那一页被贯穿，镜阵里属于她的痕迹被抹除，连曾经向她祈祷的人，也只记得某个站在日轮前的白色身影。

人们不知道发生了什么。

他们只记得那一天，太阳落幕了。

于是特瑞厄斯被注销。

漫长沉寂之后，魔女屋的展厅里出现了一次异动。一幅早已封存的空白画框自行发亮，框边浮出一串早已注销的旧编号。

主天使认可这簇残存的火焰的本质，于是向其发出了一份特殊的邀请。

于是曜日的魔女醒来。

毁灭与救赎在乌娜身上纠缠成同一种职责。

崩落之后，一定有什么必须随着日轮一同落幕；余烬之后，一定有什么会随着星火留下。

## 战斗定位

乌娜是高风险日耀角色。她不是单纯叠灼烧，而是把战场上的灼烧记录为长期资源“余烬”，再用余烬换取伤害加成、恢复、最大生命成长、灼烧抵消和全场爆发。

当前基础循环：

1. 通过日耀卡、白曜标签、天幕、遗物或技能给敌方施加灼烧。
2. 每回合一次，当敌方灼烧总层数增加时，乌娜获得 1 层日耀。
3. 回合开始时，统计敌方灼烧总量与自身灼烧层数，获得总量一半的余烬。
4. 余烬每层提供 1% 伤害加成，并会在自身灼烧结算前抵消同等灼烧。
5. 余烬被消耗时，乌娜按消耗层数百分比恢复最大生命，并增加等同消耗层数的最大生命。
6. 余烬大于 30 后，可使用圣庭墓曲消耗全部余烬，把余烬转化为全体灼烧与立即结算。
7. 白曜与圣冕显化提供中后期爆发窗口。

## 职业技能

### 被动：于灰烬中重生

游戏文本：每回合一次，当乌娜使敌方获得灼烧时，获得 1 层日耀，日耀上限扩展至 15 层。回合开始时，获得全体灼烧总层数一半的余烬。当消耗余烬时，恢复消耗的余烬层数百分比的最大血量，并提高余烬层数等量的血量上限。

当前实现细节：

- 初始化职业时写入 `SunExpWunaActive=1`，并重置两个职业技能冷却。
- 战斗开始时恢复持久化余烬，重置本回合日耀触发标记，并记录敌方灼烧总量。
- 回合开始时，两个职业技能冷却各减少 1。
- 回合开始时获得 `(敌方灼烧总量 + 自身灼烧层数) / 2` 的余烬。
- 敌方灼烧总量增加时，如果本回合尚未触发过，则获得 1 层日耀。
- 胜利或逃跑时保存余烬并清理职业 Hook。
- 余烬持久化保存在 `SunExpWunaPersistentEmber`，当前夹在 0 到 99。

| 项目 | 内容 |
| --- | --- |
| 卡牌 Id | `*wuna_white_sun_prayer` |
| 完整 Id | `SunExp_wuna_wuna_white_sun_prayer` |

当前实现细节：

- 使用前会检查乌娜是否仍是当前有效角色；若被百变化身覆盖，会提示技能已被当前化身覆盖。
- 若冷却未结束，会提示“白曜圣祷尚未冷却”。
- 成功时播放乌娜技能音频与环身火焰视觉。

玩法意义：白曜圣祷是乌娜稳定进入圣冕窗口的按钮。它把当前手牌临时接入日耀系统，像圣女把旧白曜权限短暂授予整只队伍。

### 主动二：圣庭墓曲

| 项目 | 内容 |
| --- | --- |
| 卡牌 Id | `*wuna_grave_song` |
| 完整 Id | `SunExp_wuna_wuna_grave_song` |
| 冷却 | 4 回合 |
| 条件 | 余烬大于 30 |
| 游戏文本 | 消耗所有余烬，使全体获得余烬/2 层数的灼烧，自身获得 1 层烬衣，然后立刻触发一次灼烧。 |

当前实现细节：

- 若冷却未结束，会提示“圣庭墓曲尚未冷却”。
- 若余烬小于等于 30，会提示“余烬不足”。
- 消耗前清除余烬提供的动态伤害加成。
- 移除全部余烬，并触发余烬消耗后的回血与最大生命成长。
- 将持久化余烬写回 0。
- 全体战斗单位获得 `余烬 / 2` 层灼烧。
- 乌娜获得 1 层烬衣。
- 立即触发一次灼烧结算。

玩法意义：圣庭墓曲是乌娜把“保存下来的火”一次性归还给战场的终结技。烬衣则负责让乌娜从这次自焚式爆发中活下来。

### 白曜标签

标签名：`白曜`。

白曜牌使用后会在行动后进入日耀触发逻辑：

- 若乌娜没有圣冕，按本次实际费用获得等量日耀。
- 若乌娜已有圣冕，则不再获得日耀，而是触发圣冕等阶效果。
- 临时白曜带有锁定字段，确保同一张临时白曜牌只解析一次。
- `炽冕崩落`作为特殊终结牌会走自己的结算路径。

### 圣冕触发效果

当白曜牌在圣冕期间触发时，根据圣冕等阶执行：

| 等阶 | 效果 |
| --- | --- |
| 1 | 清除自身所有负面 Buff，并转化为等量灼烧。 |
| 2 | 抽 1 张牌。 |
| 3 | 获得 1 点魔能。 |
| 4 | 清除自身所有灼烧，获得等量聚焰。 |
| 5 | 敌方全体获得 5 层灼烧，并立即触发敌方全体灼烧一次。 |

## 专属剧情：日耀回忆

乌娜当前拥有完整度较高的专属剧情玩法“日耀回忆”。它不是普通事件，而是地图节点、套卡整备、Boss 连战、终章名册与分支结局的组合。

回忆节点主线：

1. 黑日之后：特瑞厄斯失去真正黎明。
2. 第二日轮：白曜圣庭制造人造太阳。
3. 圣女的日常：乌娜作为光辉圣女行走于长廊与医祷院。
4. 被污染的光：颜色消失，名字被抹去，第二日轮成为灾厄通道。
5. 心哀与挣扎：圣庭沉默，乌娜意识到灾厄披上了光辉形态。
6. 圣轮之上：乌娜戴冠，将污染光辉、灾厄、祈祷和被遗忘者痕迹收入体内。

终章名册共有 8 个可被呼唤的名字。剧情中名字可被保存、焚毁，或写回白曜名册成为无名白曜。隐藏 Boss 与真结局大致依赖“保存名字足够且焚毁名字较少”的方向。

结局方向：

| 结局 | 方向 | 含义 |
| --- | --- | --- |
| 群星终幕 | 保存多数名字并完成星名回响 | 特瑞厄斯不再请求太阳回来，但被白昼抹去的人重新以名字和星火被记住。 |
| 白曜空城 | 名字不足或被净化为无名白曜 | 城市得救了，却再也想不起自己失去了谁。 |
| 终日魔女 | 焚毁多数名字并让炽冠圣心过载 | 第二日轮坠落，但乌娜升成新的白昼。 |

叙事定位：白曜圣女不是新的灾厄，而是过去那个仍相信净化秩序的乌娜。她没有恨意，只是温柔地认为痛苦应被净化，偏离应被校准，名字应被写回圣庭。

当前 Boss 机制：

- 白曜圣女特性：敌方回合开始时，若自身没有焚身，则焚毁 1 个保存名字，获得 6 日耀与 10% 最大生命值护盾。自身日耀不少于 12 时，进入“圣冕显化·白曜”。
- 圣女净祷：造成 20 伤害，目标获得 3 焚身，移除目标所有正面状态，首领获得 1 日耀。
- 刻名归庭：造成 18 伤害，将 1 个保存名字转为无名；若没有保存名字，首领获得 6 日耀。
- 白曜敕令：白曜圣冕 2 阶后可追加的额外行动，效果同圣女净祷。

圣冕显化·白曜：

| 等阶 | 效果 |
| --- | --- |
| 基础 | 初始 1 阶，每回合 +1，最高 5。回合开始获得 `阶层*8` 超凡，玩家全体获得等同阶层的灼烧。 |
| 1 阶 | 清除首领自身负面状态并转为等量余烬。 |
| 2 阶 | 增加 1 个行动意图：白曜敕令。 |
| 3 阶 | 触发玩家全体灼烧。 |
| 4 阶 | 每回合随机湮灭 3 张玩家卡牌。 |
| 5 阶 | 每次首领行动后，对玩家全体造成 100% 最大生命值的真实伤害。 |

这个 Boss 的核心压力不是单纯高攻击，而是“清除痛苦也清除记忆”。玩家需要在灼烧、焚身、保存名字和白曜圣冕进阶之间做取舍。

## 写作与口径

推荐关键词：

- 白曜圣庭
- 第二日轮
- 曜日冠冕
- 炽冠圣心
- 日轮落幕
- 被污染的光
- 保存名字
- 余烬会记住名字

乌娜适合被写成安静、礼貌、克制的人。她不是享受焚烧的火焰狂人，而是曾经负责神圣仪式的人。她的危险感来自稳定判断：当某个东西已经无法被拯救，她会平静地让它结束。

不建议写成：

- 单纯享受焚烧。
- 自称真正太阳。
- 承诺让特瑞厄斯恢复原状。
- 直接解释奥尔德林主线真相。
- 用外放狂气替代克制的悲剧感。
