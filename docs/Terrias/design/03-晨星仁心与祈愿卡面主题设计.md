# 晨星：仁心与晨星：祈愿卡面主题设计

> 状态：视觉初稿，尚未绘制  
> 整理日期：2026-07-23  
> 设计范围：`晨星：仁心`、`晨星：祈愿`各 8 张候选卡牌  
> 参考基线：现有“晨星：序曲”卡包、洛奈尔角色立绘与“晨星祈愿”CG  
> 本文只定义卡面主题和后续绘制约束。卡牌名称、数值与效果仍可在机制评审后调整。

## 1. 视觉目标

这两组卡牌不是脱离“晨星：序曲”的新世界观，而是对同一套星谱语言的横向展开：

- **晨星：序曲**表现洛奈尔如何编写、修改和复奏星谱；
- **晨星：仁心**表现一段谱句如何被他人接住，并转化为守护、治疗和赠予；
- **晨星：祈愿**表现演奏前对末音作出的期待，以及群星是否回应这份期待。

三者应当一眼属于同一系列，但不能只靠“蓝色、金色、星星、圆环”维持关系。新卡面要继承晨星的光色和笔触，同时减少仪表盘式星轨、规整圆环和对称法阵，改用更有生命感的物体、手势、织物、花瓣、火种和流动笔触建立可辨识轮廓。

卡面最终仍遵循项目现行美术规范：

1. 画面为 `1:1`，最终尺寸 `256x256`；
2. 背景必须为纯黑 `#000000`，不绘制卡框、UI、文字和费用标识；
3. 主体由粗粝的手绘色块构成，最终前景控制在 3-5 个可辨识颜色；
4. 主体必须拥有清楚、有机、仅看外轮廓也能辨认的剪影；
5. 不以圆环、直线、规则多边形或细密星图作为主要结构；
6. 稀有度不改变画面复杂度。所有卡牌使用相近的主体数量、色块尺度、笔触密度和细节水平。

## 2. 系列共同语言

### 2.1 共享母题

| 机制概念 | 卡面转译 |
| --- | --- |
| 星谱 | 被光照亮的深蓝织带、翻卷谱页或连续的粗笔触，不画标准五线谱 |
| 伏谱 | 沉入主体背面、衣褶下方或黑暗下缘的半隐藏笔触 |
| 启 | 向上舒展的单瓣星焰 |
| 承 | 横向展开、像双手托举的双瓣光痕 |
| 转 | 回折、偏转的钩形流光 |
| 合 | 向内收束的花萼形星火 |
| 余音 | 与主体分离但仍被牵引的微小光片，通常保留 1-3 枚 |
| 星辰祝福 | 温暖的象牙白星核外包一层旧金光，不使用奖章式图标 |
| 完成谱句 | 三段彼此呼应的笔触汇合成一个明亮焦点，而非完整圆阵 |

这些形状只是一套绘画语汇，不应在画面中变成可阅读的UI符号。玩家首先应看到一个叙事瞬间，其次才从光痕的走向联想到机制。

### 2.2 洛奈尔的使用原则

洛奈尔应作为系列身份的一部分，但不宜让 16 张牌全部成为她的不同姿势。

- 完整或半身剪影主要留给《无声拥抱》《晨星：仁心》《晨星：祈愿》；
- 其他卡牌优先使用她的手、袖口、长发、薄纱和星表作为身份提示；
- “援助他人”可以通过第二道较暗的火种、手掌或斗篷剪影表现，不需要绘制具体队友；
- 洛奈尔的浅紫长发与薄纱应被压缩成大块淡色轮廓，不追求立绘级发丝和服装纹样。

### 2.3 与现有晨星卡面的关系

现有晨星卡面以深蓝、旧金、少量绯红构成，具有强烈的星盘和轨道感。两组扩展继续使用这套基础色，但做如下分化：

| 系列 | 主色比例建议 | 形态倾向 | 情绪 |
| --- | --- | --- | --- |
| 仁心 | 深群青 35%、暖象牙白 30%、旧金 25%、珊瑚粉 10% | 托举、包裹、相接、下落后被接住 | 温柔但不脆弱，像黎明前主动伸出的手 |
| 祈愿 | 深群青 45%、月白 20%、旧金 20%、星紫或绯红 15% | 抬升、选取、偏转、悬停、回返 | 安静的期待，以及结果到来前的张力 |

纯黑背景不计入前景颜色。进入第二、三阶段绘制后，可将相近的白色和金色继续合并，确保最终不超过 5 个前景色组。

### 2.4 两组卡面的辨识锚点

**仁心的锚点：**

- 暖白色光核位于画面中下部，像被保护的人或尚未熄灭的声音；
- 深蓝色主体多从上方或侧面形成遮蔽、托举和环抱；
- 珊瑚粉只用于伤口、虚弱火种或被治愈的瞬间；
- 光的方向通常由强者流向弱者，强调“替他人承担”。

**祈愿的锚点：**

- 画面保留一块清楚的上方黑色负空间，让愿望有“投向远处”的方向；
- 被选择的末音使用旧金或月白，未选择的可能性退为深蓝；
- 星紫或绯红用于尚未兑现的愿望，不用于已经完成的祝福；
- 光的方向通常先离开主体，再从远处折返，强调“提出愿望并等待回应”。

## 3. 晨星：仁心

### 3.1 晨露小调

> 效果基线：获得 1 层仁心，将“承”写入伏谱。

**主题瞬间：** 黎明前，一滴晨露从弯曲的蓝色叶片滑落，却没有坠入黑暗，而是被下方一片像双手般展开的暖白花瓣接住。

**构图与剪影：** 主体呈上窄下宽的花苞形。上方是一片倾斜叶片和一滴大露珠，下方是双瓣托举结构；露珠的下落轨迹在花瓣背面继续，暗示“承”进入伏谱。

**光色与笔触：** 深群青叶片占主要面积，露珠为月白，接住它的花瓣用旧金和暖白；接触点出现极少量珊瑚粉。笔触保持湿润、柔软，但边缘不可过度光滑。

**效果对应：** 露珠是新获得的仁心；托举姿态是“承”；被花瓣遮住的下半截光痕是伏谱。

**避免误读：** 不画成普通植物插画，不使用写实水滴摄影感，也不把“承”直接写成汉字。

### 3.2 慈悲和弦

> 效果基线：获得 8 点护盾；当前星谱含“承”时，获得 1 层仁心。

**主题瞬间：** 两片宽大的蓝色衣袖从左右合拢，护住一枚表面已有裂痕、仍在发光的小星核。衣袖并未完全闭合，暖光从中央向外照亮双手。

**构图与剪影：** 以“两侧包裹中央”的三块大色块构成。外轮廓像一朵尚未合拢的花，也像两个人共同弯身挡住冲击；中央星核偏下，避免形成徽章式正中构图。

**光色与笔触：** 深群青负责外部护盾，旧金描出受力边缘，暖白形成内部生命感，裂痕保留一笔珊瑚粉。

**效果对应：** 合拢的衣袖直接表达护盾；左右共同托举形成“承”的双瓣结构；裂痕仍发光说明慈悲不是消除伤害，而是接住受伤者。

**避免误读：** 不使用爱心、十字、天使翅膀等通用治疗符号；护盾也不画成规则球壳。

**基准图建议：** 本卡最适合作为“晨星：仁心”系列的首张基准图。它同时包含守护、受伤火种、双瓣“承”和完整四色比例，且主体剪影在 256 像素下容易验证。

### 3.3 温柔休止

> 效果基线：清空星谱，每清除 1 音获得 4 点护盾；若清除过“承”，治疗生命最低的友方 5 点。

**主题瞬间：** 一条正在演奏的蓝色光带被轻轻按住，原本连续的声音碎成数枚光片；光片没有消失，而是在下方叠成柔软的遮蔽层，其中一枚暖白光片落向受伤的珊瑚色火种。

**构图与剪影：** 左上至右下的光带在中央被一只手或一片垂落薄纱截断。下方由碎片形成不规则的巢状轮廓，表现清空后转化为防御。

**光色与笔触：** 深蓝是被终止的谱句，旧金描出停下的瞬间，暖白碎片构成护盾，珊瑚粉只保留在被治疗目标上。

**效果对应：** 被截断的光带是“休止”；每一枚落下的光片都转化为一层保护；双瓣形碎片触及伤者时对应清除“承”后的治疗。

**避免误读：** 不画标准暂停键，不让碎片像玻璃爆炸，也不表现为暴力打断。

### 3.4 替你续唱

> 效果基线：生命最低的友方获得 12 点护盾；目标不是自己时获得 1 层余音，单人时改为抽 1 张牌。

**主题瞬间：** 一簇微弱的珊瑚色声焰在中途断裂，另一条从侧后方伸来的蓝白光带接上它未完成的轮廓，并继续向前展开成遮蔽伤者的披风。

**构图与剪影：** 画面由一枚低矮、将熄的火种和一条跨越画面的长弧构成。接续点偏左下，右上方保留一枚从主光带脱落的小光片作为余音。

**光色与笔触：** 伤者为小面积珊瑚粉，接唱者为深群青，续上的声音由暖白过渡到旧金。长弧必须由有厚度的粗笔触形成，而非细线。

**效果对应：** 主光带跨过距离说明目标不是自己；披风式结尾表达护盾；脱落但未消散的小光片表达余音。

**避免误读：** 不画成两人争抢麦克风，不出现现代舞台设备，也不要让余音比受保护目标更醒目。

### 3.5 余音相赠

> 效果基线：消耗至多 3 层余音；每层使全体获得 3 点护盾，并治疗生命最低的友方 2 点。

**主题瞬间：** 三枚原本围绕独唱者漂浮的余音光片被依次送出，沿三条不同的布带流向远处；它们抵达后化成共同覆盖全场的蓝色薄幕，并把最暗的一枚火种重新点亮。

**构图与剪影：** 中央是张开的手掌或散开的袖口，三枚大小一致的光片由近到远形成节奏。外层薄幕只表现为两三块宽阔色面，不画成圆形结界。

**光色与笔触：** 三枚余音使用旧金，赠予轨迹为深群青，护幕为月白蓝，最低生命目标以一小笔珊瑚粉转暖白。

**效果对应：** 明确保留三枚可计数光片；光片扩散至不同方向对应全体护盾；其中一枚继续向最暗火种下沉，对应集中治疗。

**避免误读：** 不将三层资源画成三个规则金币或UI计数点，不让画面变成平均分割的三向图标。

### 3.6 长音留驻

> 效果基线：获得一张“承”，并使生命最低友方的所有正面 Buff 层数 +1。

**主题瞬间：** 一条几乎要消散的长音被两只手从两端托住，蓝白织带因此重新绷起；织带下方，一株低垂的星花在持续光照中重新抬头，花瓣上的数道微光同时加深。

**构图与剪影：** 横向长织带是主要外轮廓，但要有自然下垂、折叠和破损边缘。下方星花偏向一侧，避免画成横线加中心图标。

**光色与笔触：** 织带为深群青和暖白，托举处使用旧金，低垂花苞以珊瑚粉起笔、暖白收尾。

**效果对应：** 两端托住构成“承”；持续不散的织带是长音；花瓣上同时增强的多处亮色对应所有正面 Buff 层数提升。

**避免误读：** 不使用音量波形、加号、层数箭头；“留驻”应是被温柔维持，而非被锁链束缚。

### 3.7 无声拥抱

> 效果基线：获得 3 层仁心，并立即结算一次仁心且不消耗层数。

**主题瞬间：** 洛奈尔俯身抱住一位只剩暗淡轮廓的同伴。她的长发和薄纱从背后包拢两人，怀中没有爆发性光效，只有三枚安静的暖白星芽；其中一枚已贴近同伴胸口并开始发亮。

**构图与剪影：** 两个人物合成一个紧凑、向内收拢的单体剪影。洛奈尔的长发形成外侧遮蔽，同伴只保留肩背和低垂头部，不展开复杂服装。

**光色与笔触：** 深群青承担大部分人物轮廓，暖白和旧金集中在怀抱内部，伤者保留少量珊瑚粉。光线不向外爆炸，而是向内沉降。

**效果对应：** 三枚星芽对应 3 层仁心；贴近伤者并已经绽放的一枚表达“立即结算但没有从三枚中消失”；拥抱本身同时表达治疗与护盾。

**避免误读：** 不画成恋爱接吻，不使用圣母像式宗教构图，不让人物细节超过其他卡牌的复杂度。

### 3.8 晨星：仁心

> 效果基线：获得 2 层仁心；本场战斗中，每回合第一次完成具名谱句时，免费结算一次仁心。

**主题瞬间：** 洛奈尔掀起宽大的星纱，像为数枚弱小星火撑开一片黎明。她一只手托着两枚尚未使用的暖白星芽，另一只手将刚完成的三段谱句引向最暗的火种；谱句抵达时自然化为一道不消耗星芽的守护光。

**构图与剪影：** 洛奈尔只取侧身上半段，星纱从左上覆盖到右下，形成清楚的庇护轮廓。两枚星芽位于手心，完成的谱句位于另一侧，两组信息彼此分开。

**光色与笔触：** 深群青星纱约占一半画面，暖白用于被守护者和晨光，旧金用于完成谱句，珊瑚粉只提示原本虚弱的目标。

**效果对应：** 两枚星芽对应获得 2 层仁心；三段光痕完成后直接化为守护，而手中星芽数量不变，对应免费结算；星纱持续覆盖暗示整场战斗的常驻效果。

**避免误读：** 不画王座、神像或宏大法阵；这张牌的力量来自主动照顾他人，而不是洛奈尔接受膜拜。

## 4. 晨星：祈愿

### 4.1 掌心星愿

> 效果基线：从“启、承、转、合”中选择一个，设为星愿。

**主题瞬间：** 一双合拢又微微张开的手中悬着四枚形态不同的星种。三枚仍沉在深蓝阴影里，只有一枚正被指尖轻触，并从星紫转为旧金。

**构图与剪影：** 手掌和袖口形成不对称的贝壳形主体，四枚星种沿掌纹自然散布，不能排成规则四象限。上方留出一块黑色空间，让被选择的星种拥有上升方向。

**光色与笔触：** 袖口为深群青，未选星种为月白蓝，愿望状态为星紫或绯红，被选中的结果为旧金。

**效果对应：** 四枚不同形态的星种对应四种末音；指尖接触表现选择；颜色变化表示星愿已经被设定但尚未兑现。

**避免误读：** 不画成四个UI按钮、元素宝石或占卜转盘，也不让四枚星种完全对称。

**基准图建议：** 本卡适合作为“晨星：祈愿”系列基准图。它包含选择、未兑现愿望、手势和上方负空间，能够确立整组卡牌的方向感与四色比例。

### 4.2 向星取音

> 效果基线：从“启、承、转”中选择一张写入伏谱；若与当前星愿相同，抽 1 张牌。

**主题瞬间：** 洛奈尔的手从三道下落的星光中摘取一枚。被选中的星音没有停留在掌中，而是顺着袖口滑入下方半掩的深蓝谱页；远处的愿星若与它同形，便回赠一片月白光页。

**构图与剪影：** 三道星光以不等长、不平行的自然弧线落下，手掌横切其中一道。谱页只露出下缘折角，回赠光页位于相反方向，形成取与回的节奏。

**光色与笔触：** 三个候选以深蓝和月白区分，被选音使用旧金；愿星保留星紫，匹配后的回赠转为暖白。

**效果对应：** 三道光对应三个可选音；光滑入遮蔽处表示伏谱；相同形态的远星和回赠光页表达匹配后抽牌。

**避免误读：** 不画抓取星星的可爱童话场面，不使用三张整齐排列的卡牌，也不把伏谱画成口袋。

### 4.3 愿笺改写

> 效果基线：选择将最后一音向前或向后改写一次。

**主题瞬间：** 一张没有文字的愿笺在风中翻卷，末端原本的星形笔触被一支羽笔轻轻拨动。旧笔触向一侧褪去，新笔触从另一侧重新长出，像一句话在落笔前改变了最后一个词。

**构图与剪影：** 愿笺是一条有破边、弯折明显的厚色带，羽笔斜向切入。末端保留两个方向相反的残影，但它们不能画成标准箭头。

**光色与笔触：** 深群青愿笺、月白羽笔、旧金新末音、星紫旧末音。颜色在末端交替，不形成圆形循环图。

**效果对应：** 只改动愿笺最末端，明确“最后一音”；两种相反残影表达向前或向后的选择；旧色褪去、新色长出表达改写而非新增。

**避免误读：** 不出现文字、撤销图标、双向箭头或齿轮；重点是诗意的临笔修改。

### 4.4 未竟祷词

> 效果基线：复制当前最后一音到伏谱，并获得 1 层余音。

**主题瞬间：** 一条祷词光带在黑暗中戛然而止，最后一枚发光的音节分裂出一道较暗的双生痕迹。原音留在断口，复制品沉入折叠谱页背后，另有一小片光屑停在空中迟迟不散。

**构图与剪影：** 断裂光带形成明显的开放式末端。双生痕迹向下潜入黑暗，余音光屑向上漂浮，三者方向不同但共享同一个起点。

**光色与笔触：** 祷词主体为深群青，最后一音为旧金，复制痕迹为月白蓝，余音保留星紫。

**效果对应：** 同源的两枚末音表达复制；沉到背后的那一枚是伏谱；停留的小碎片是获得的余音；开放断口说明祷词尚未完成。

**避免误读：** 不画复印纸、镜像图标或省略号；“未竟”应表现为仍有去向，而不是失败或死亡。

### 4.5 星落之前

> 效果基线：获得当前星愿对应的序曲牌；若没有星愿，改为抽 1 张牌。

**主题瞬间：** 一枚承载愿望的星种正从高处坠落，却在触及下方黑暗前被一片翻卷的蓝色谱页接住。星尾在接触前已经长成与愿望同形的序曲笔触，像答案先于星落抵达。

**构图与剪影：** 上方保留较大的黑色空间，坠星斜向下落；下方谱页像被风吹起的手掌，二者尚未完全接触，保留“之前”的紧张间隙。

**光色与笔触：** 深群青谱页，星紫愿星，旧金序曲尾迹，接住它的边缘为月白。无须同时表现“没有星愿”的备用效果。

**效果对应：** 愿星的形态决定星尾长出的序曲；谱页接住星尾表达获得卡牌；未落地的间隙强化即时取牌的时机感。

**避免误读：** 不画陨石灾难、地平线爆炸或许愿流星风景；主体必须是“结果正在成形”。

### 4.6 回应祈愿

> 效果基线：将最后一音改为星愿对应音；星谱为空时，改为将该音写入伏谱。

**主题瞬间：** 一条即将偏离目标的谱句被远处返回的星光轻轻托转，末端由原本的深蓝钩痕蜕变为旧金星种。若前方没有谱句，这枚返回的星种便直接沉入下方折叠的黑蓝织物。

**构图与剪影：** 主要轮廓是一条有厚度、正在转向的光带和一枚远处回应的星种。下方织物只作为第二阅读层，不与主光带争夺焦点。

**光色与笔触：** 原末音为深群青，尚未兑现的回应为星紫，改写完成处为旧金，伏谱入口用月白边缘提示。

**效果对应：** 返回的光改变末端而非增加新段，表达改写；末端与愿星同形，表达对应音；下沉支路涵盖空谱时写入伏谱的备用情况。

**避免误读：** 不画成攻击弹道自动追踪，不使用靶心、箭头或圆形轨道。

### 4.7 群星垂听

> 效果基线：下一次星愿兑现时，额外复奏刚完成的谱句一次。

**主题瞬间：** 一枚孤独的祈愿火种向上发出三段光痕，黑暗中的群星没有坠落，而是像花朵般微微俯首。第一道回应落下后，整段谱句又以更淡但完整的第二层笔触沿原路回响。

**构图与剪影：** 下方是一枚向上倾斜的祈愿火种，上方由数块不规则星光色面形成“倾听”的穹顶。复奏使用错开少许的第二层粗笔触，不做精确镜像。

**光色与笔触：** 祈愿火种为星紫，第一次回应为旧金，复奏为月白，群星轮廓沉在深群青中。上方黑色负空间仍需保留，不填满星点。

**效果对应：** 完整出现两遍的三段光痕表达一次额外复奏；群星的共同倾向表达愿望被听见；第二遍更淡说明它是回声而非新施放。

**避免误读：** 不画巨大眼睛、神明、教堂或合唱团；“垂听”是宇宙给予回应，不是宗教审判。

### 4.8 晨星：祈愿

> 效果基线：选择一个具名谱句，将其前两音写入伏谱，并把末音设为星愿。

**主题瞬间：** 洛奈尔闭目合掌，但真正的焦点位于双手下方：一卷半掩在薄纱后的星谱已经写入两枚连续音痕，第三枚末音仍悬在她的指尖上方，保持星紫色，等待群星确认。

**构图与剪影：** 只取洛奈尔的双手、部分面部和从两侧垂落的长发薄纱。人物形成向内收束的三角形有机轮廓，谱页藏在下半部，未落笔的末音位于上方黑色负空间。

**光色与笔触：** 长发和薄纱用深群青与月白合并成大块，已写入的前两音为旧金，末音愿望为星紫。人物肤色不单独扩展颜色，可并入暖月白。

**效果对应：** 薄纱后的两枚音痕明确表示伏谱中的前两音；悬而未落的第三音表示被设为星愿的末音；合掌动作呼应既有“晨星祈愿”角色形象。

**避免误读：** 不直接缩小现有CG，不堆叠星盘、光环和服装细节；画面重点是“已经写下两步，只把最后一步交给群星”。

## 5. 统一制作约束

### 5.1 复杂度

所有 16 张卡牌采用同一复杂度标准：

- 1 个主要有机剪影；
- 2-4 块主要色彩质量块；
- 少量用于机制阅读的光片或星种；
- 最多 1 个主要人物片段，或 2 个合并为单一剪影的人物；
- 不因为稀有度增加粒子、法阵、角色数量和精细纹样。

稀有牌的特殊感来自主题瞬间更具决定性，而不是画得更满。

### 5.2 黑色负空间

- 主体不铺满画布，四周需保留纯黑边缘；
- 仁心系列可在上方或侧面留黑，让保护结构向内合拢；
- 祈愿系列优先在上方留黑，让愿望有明确的投射方向；
- 黑色空间必须参与剪影塑造，不能只作为抠图后的空背景。

### 5.3 小尺寸阅读

在 `256x256` 下，每张卡首先要能读出一个动词：

| 卡牌 | 第一眼动词 |
| --- | --- |
| 晨露小调 | 接住 |
| 慈悲和弦 | 护住 |
| 温柔休止 | 停下并收拢 |
| 替你续唱 | 接续 |
| 余音相赠 | 分赠 |
| 长音留驻 | 托住 |
| 无声拥抱 | 拥抱 |
| 晨星：仁心 | 庇护 |
| 掌心星愿 | 选择 |
| 向星取音 | 摘取 |
| 愿笺改写 | 拨改 |
| 未竟祷词 | 复制并藏起 |
| 星落之前 | 接取 |
| 回应祈愿 | 引回 |
| 群星垂听 | 回响 |
| 晨星：祈愿 | 预写并等待 |

如果缩略图只能读成“发光的星星”或“蓝金色法阵”，则主题设计尚未成立。

## 6. 后续绘制顺序

两组卡牌必须分别经过系列基准图审批，不能一次性绘制整组。

1. 先绘制《慈悲和弦》的四个阶段，作为“晨星：仁心”候选基准；
2. 依据轮廓、色彩、笔触、负空间和小尺寸阅读完成逆向分析与评分；
3. 获得明确批准后，再按本文逐张绘制其余仁心卡牌；
4. 以同样流程绘制《掌心星愿》，作为“晨星：祈愿”候选基准；
5. 两张基准图都通过后，才开始制作对应系列的其余卡牌。

每张卡牌的绘制阶段为：

1. 完整主题图：先把叙事瞬间、主体和构图画清楚；
2. 手绘简化：编辑原图，将前景压缩到 4-6 个颜色；
3. 粗笔触定稿：继续编辑，将前景压缩到 3-5 个颜色；
4. 等比缩放：不重绘、不裁切，输出 `256x256` 最终图。

## 7. 评审问题

在开始首张基准图之前，建议优先确认以下方向：

1. “仁心”是否保持现在的暖白、旧金和少量珊瑚色，还是希望更偏冷色的月光疗愈；
2. “祈愿”是否接受星紫作为未兑现愿望的专属颜色，以便与兑现后的旧金形成状态差；
3. 洛奈尔是否只在三张核心牌中出现，还是希望两组各增加一张带角色局部的卡面；
4. 四种音符是否继续沿用现有星谱图形，还是接受本文提出的“星焰、双瓣、钩痕、花萼”有机化转译；
5. 《慈悲和弦》与《掌心星愿》是否适合作为两组卡牌的首张基准图。
