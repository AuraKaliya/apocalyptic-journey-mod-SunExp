# 精灵养成能力维护规则

> 状态：当前维护入口
> 更新日期：2026-08-18

## 权威来源

- 生成器：`tools/Generate-SpiritTrainingRegistry.ps1`
- 交付注册表：`Terrias/spirit.training.registry.json`，schema 2
- 运行时表：`09-精灵养成能力运行时表.csv`
- 固有意图表：`10-精灵固有意图魔能冷却表.csv`
- 行为实现：`SpiritTrainingService`、`SpiritPassiveMechanicRegistry`、`SpiritTrainingBattleRuntime`

CSV 和 JSON 生成物不手工修改。改变能力、处理器或默认装配后必须重新运行生成器。

## 内容合同

- 通用意图固定为基础、战术、高级各 5 个；
- 通用被动固定为核心 8 个、高级 4 个；
- 每个正式 `speciesId` 恰好拥有一个种族被动；
- 每个正式 `profileId` 拥有 1 至 3 个默认固有意图；
- 外部 profile 使用一个登记的兼容被动和三意图兼容套装；
- 种族被动禁止恢复 `type-resonance` 占位模板；
- 51 个种族被动必须具有不同的处理器参数签名。

## 处理器合同

新增种族被动优先复用现有 12 类处理器。确需新处理器时，必须同时提供：

1. 参数边界校验；
2. 主机权威触发入口；
3. 有界战斗状态；
4. Hover 状态描述；
5. 可触发性测试；
6. 失败隔离与网络快照上限。

处理器不得直接复用敌人脚本，不得单独注册每个精灵的宿主事件监听器。数值效果统一通过 `CompanionEffectCommitService`。

## 成长计划

五阶段等级区间保持 `6–10 / 14–18 / 23–28 / 32–38 / 42–47`。计划版本 2 增加：

- 通用被动可触发性筛选；
- 三个固定通用意图的类型多样性修复；
- 旧成长计划能力的确定性移除和重新解锁。
