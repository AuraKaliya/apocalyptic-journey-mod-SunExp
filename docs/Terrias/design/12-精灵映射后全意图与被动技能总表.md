# 精灵映射后全意图与被动技能总表

> 数据基线：2026-08-12 当前代码与交付注册表。

> 种族固有能力的下一版机制设计见 [13-精灵种族固有机制重设计评审稿](13-精灵种族固有机制重设计评审稿.md)。该文档仍处于评审阶段，尚未修改本文记录的当前运行时事实。

## 1. 表格口径

| 分类 | 当前含义 |
| --- | --- |
| 精灵种族固有意图 | 来源于敌人 PVE 意图映射，按 `profileId` 装配；捕获该形态时全部学会 |
| 精灵种族固有被动 | 按 `speciesId` 唯一映射；捕获时学会并默认装备；多形态共享 |
| 通用意图 | 所有精灵的成长计划候选池；单只精灵只会抽取其中一部分 |
| 通用被动 | 所有精灵的成长计划候选池；与种族固有被动共用 1 个装备槽 |

类型枚举：`Attack`=攻击，`Defense`=防御，`Interference`=干扰，`Support`=辅助，`Recovery`=恢复。

当前总数：

- 精灵种族固有：54 个不同意图，51 个种族被动；
- 通用：15 个意图，12 个被动；
- 合计：69 个不同意图定义，63 个被动定义。

形态的固有池、默认装备和类型构成见 [11-精灵养成意图池与被动技能池分析](11-精灵养成意图池与被动技能池分析.md)。

## 4. 读取结论

1. 捕获精灵时，不是从 54 个固有意图里随机抽取，而是学会该 `profileId` 已映射的全部固有意图。
2. 固有意图和通用意图进入同一个已学会库，最终只能装备 3 个。
3. 固有被动和通用被动进入同一个已学会被动库，最终只能装备 1 个。
4. 51 个种族固有被动目前是稳定 ID 下的统一模板，不是 51 种不同处理机制。
5. 8 个 `Interference` 种族被动当前没有可触发的直接数值意图，表中已逐项标注。
6. 表内名称、数值、魔能和冷却来自当前注册表；后续修改应更新生成器与注册表，不手工修改运行时 CSV 快照。
