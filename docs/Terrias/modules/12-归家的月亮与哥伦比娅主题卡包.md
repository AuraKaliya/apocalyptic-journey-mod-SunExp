## 1. 卡包与取得方式

显示名为【归家的月亮】，完整卡包 ID 为 `Terrias_terrias_cardpack_moon_homecoming`，类型为 `Normal`。
十张牌全部归属这个卡包，没有隐藏 ID；三篇纪闻均可进入稀有度 3 的正常奖励池。
所有玩家角色均可使用；哥伦比娅通过原有月反应强化、行动后涟漪和获牌减冷却与其配合。

## 2. 已确认的持续范围

- 月髓与纪闻其二增加的生命上限持续本次冒险，可以跨战斗积累。
- 增加生命上限通过 `PlayerMaxHpApi.TrySetNativeMaxHp(..., persistRole: true)` 完成。原生 setter 同步增加等量当前生命并写回 `RoleTable.MaxSan`，因此不再额外调用治疗。
- 纪闻其一增加的是战斗内魔能上限；原生 setter 同步补充等量当前魔能，不重复加魔能。
- 战斗结算、结束、重开、重新初始化时移除本卡包记录的临时魔能上限。重复清理不再扣除；旧角色对象的清理不得修改新战斗角色。
- 其他效果提供的魔能上限不随本卡包一起扣除；扣除后当前魔能最少为0。

## 3. 霜月月髓

完整 Buff ID 为 `Terrias_terrias_frostmoon_marrow`，上限1层，没有行动、受击或回合衰减，重复获得不叠加。Buff 随战斗状态结束，但已增加的生命上限保留。

持有者自己触发感电、绽放、结晶及其月反应版本时，每次增加：

`1 + floor(触发时当前最大生命值 / 100)`

每个实际发生反应的目标各计一次。同一次月反应保留的普通效果、重复的月伤害、额外草原核以及结晶额外计数均不另算反应次数。超绽放、烈绽放不属于此 Buff 的触发条件。

接入点是 `ElementalReactionService.ExecutePostReaction` 的反应后结算；同一路径覆盖直接攻击、纯附着和扩散传播。沿用既有反应效果的顺序，再给予月髓成长。多人中只修改触发者所属客户端的玩家状态，不借用远端角色写入本地冒险。

【花海的月夜】逐目标完成草元素施加及对应反应后，才计算护盾。因此同牌触发的月髓或既有命座成长会计入这次护盾。百分比护盾向下取整。

## 4. 纪闻、归家与供奉

纪闻通过原生 `DrawScript` 在每次实际入手时生效。显示初始化和跨回合保留不重复触发；弃置后再次入手可以再次获益。生成进弃牌堆时不触发，也不加入冒险牌组。

【努昂诺塔】从三篇纪闻等概率随机，允许重复。纪闻不带诅咒标签；可以被弃置或供奉，保留会占用手牌位置。

【月亮回家的夜晚】在已注册的 `AuraCardActionTransactionRouter.NativeStarted` 入口固定纪闻种类，各种最多生效一次：

1. 其一：获得2点魔能，抽1张牌。
2. 其二：获得5层引力涟漪。
3. 其三：下一张卡牌额外生效1次。

不消耗纪闻；同篇多张不重复发奖；效果一抽入的新纪闻不会改变本次行动已经固定的组合。被【重现】等效果重复时，同一行动沿用该组合。下一次独立行动重新读取手牌。

其三使用本体 `UseCount`，按本体【重现】的适用范围、扣费与叠加规则处理。职业技能内部已有的冷却检查保持原生限制；本卡包没有另行提供绕过冷却的职业技能重放。

原生 `CardItem.RunScriptCore` 不会把自身的 `PreUseScript` 交给卡牌执行器，所以本功能使用既有出牌事务入口，不依赖这一字段。组合快照在行动完成或中止后清理。

【供奉】在焚毁之前读取供品的当前费用，成功移出手牌后治疗，0费供品不提供最低治疗。无其他手牌时不可用。额外生效的多次供奉串行选择，后一次根据前一次焚毁后的手牌建立候选；取消、失败、战斗终止与旧回调均不会发放虚假治疗。

【晨雾中的库塔尔】和归家效果二新获得的涟漪可参与本次行动后的既有涟漪结算。例如获得3层后，本次行动后通常剩余2层。

【新月的祝福】每次效果都发放30金币、90账号真理之晶；复制或额外生效不受隐藏的一次性收益限制。

## 6. 验证与实机验收

自动化检查分为：

- `tools/Test-TerriasMoonHomecoming.ps1`：十张牌的奖励池、费用、稀有度、词条、四语言与图片尺寸；运行真实生产脚本、机制、手牌适配器的隔离宿主测试，覆盖成长持久化、重复入手、临时上限清理、组合固定、串行供奉、失败与过期回调、随机生成、重复货币和所有权。
- `tools/Test-TerriasColumbina.ps1`：既有角色回归，以及组合、成长取整与溢出、服务器场地意图的生产程序集检查。
- `tools/Test-TerriasElemental.ps1`：既有附着、月反应与场地同步契约回归。
- `tools/Test-TerriasCSharp.ps1 -SkipBuild`、内容、资源、架构与 DLL 包装检查。

隔离宿主测试不代表 Unity 实机验收。以下项目在游戏中仍需确认：

1. 其他角色与哥伦比娅各使用本包启动、挂水后全体挂草，确认逐目标成长与护盾。
2. 纪闻抽入、保留、弃置重抽、复制、满手牌时的真实入手表现。
3. 集齐不同纪闻后使用归家，再配合重现；观察技能自身冷却限制。
4. 连续供奉、重复供奉、取消选择、战斗结束时仍有选择窗口的退出体验。
5. 连续两场战斗及冒险存档读回：生命成长保留，临时魔能上限清除。
6. 非主机玩家使用霜月的新神，确认全场领域同步，成长与账号货币仍属于自己的角色。
