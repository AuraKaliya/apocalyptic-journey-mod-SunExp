整理范围：`SunExp` 当前数据与 `SunExp-Dev` 当前 C# 实现，并参考 `Loneer` 目录中的角色定稿与旧设计草稿。

## 角色概览

| 项目 | 内容 |
| --- | --- |
| 角色 Id | `loneer` |
| 中文名 | 洛奈尔 |
| 繁中名 | 洛奈爾 |
| 英文名 | Loneer |
| 日文名 | ロネール |
| 职业称号 | 晨星魔女 |
| 英文称号 | Witch of the Morning Star |
| 来源世界 | 已注销世界“特瑞厄斯” |
| 职业 SanMax | 72 |
| 场景短句 | 晨星还亮着 |
| 当前核心机制 | 星石袋、奇迹时钟、指引牌、自然晨星、星辉、星谱、星辰序曲 |

洛奈尔是特瑞厄斯的“星”。她与乌娜来自同一个已注销世界，但没有直接交集：乌娜属于王都、白曜圣庭、第二日轮与公开的白昼秩序；洛奈尔属于边境、晨星台、旧星历、微小愿望与未被圣庭登记的人。

当前游戏内职业描述为：她把奇迹装进一只会慢慢变轻的星石袋里。每一次抽石，都是向黎明借来的一小段时间。

## 背景故事

在第二日轮尚未升起的时候，特瑞厄斯的夜已经很长了。

群山、王都、边境与白曜圣庭的尖塔都沉在同一片冷夜里。黑幕遮住大半天穹，却仍有星辰悬挂。繁星沉默地亮着，为仍苦苦挣扎的人，留下了一点渺茫的光。

迷路的人向北方星祈愿，便会在雪地里看见一盏忽然亮起的灯。病重的孩子向药星祈愿，便会在天亮前熬过最冷的时辰。即将断粮的村庄向谷星祈愿，便会在枯井边发现一小袋不知从何处落下的种子。

一次的偶然，被称作幸运。

十次的偶然，被称作祝福。

当整个特瑞厄斯都在漫长黑夜里靠这些偶然延续，人们便开始称它为奇迹。

后来，天幕继续扩张。

星辰一颗接一颗黯淡，夜路越来越长，祈愿越来越多，回应却越来越少。

这片白曜赐福之地上，黑幕已经遮住最后的星光。

人们终于开始恐惧。

于是，在一场没有黎明的夜里，整个特瑞厄斯向最后仍亮着的晨星许下了同一个愿望。

“请让夜晚结束。”

无数星札在同一夜燃烧，灰烬如倒升的雪飘向天穹。

晨星回应了祈愿。

第二日轮升入天幕。

人们惊讶地发现，天上从来没有那么多星。所谓北方星、药星、谷星，似乎只是人们在不同痛苦里看见的同一颗黯星。

圣庭宣告：“白曜归来。”

于是新的太阳照亮特瑞厄斯。礼拜恢复，钟律重建，王都重新有了白昼。人们的生活慢慢回到正轨，也渐少谈论旧夜里的星光。

奇迹似乎被遗忘了。

可是奇迹的代价不会因此消失。

每一盏灯亮起，都会有一颗星暗淡。每一个病人醒来，都会有一段本该抵达的痛苦被推迟。每一条被星光照出的道路，都会在世界的另一处留下同样深的影子。

等到第二日轮开始被污染，等到白昼本身也成为灾厄的通道，等到旧夜里欠下的无数奇迹的代价终于兑现。

洛奈尔遗下的时钟终于归零。

同一夜，王都的日轮落幕。

......

"要是那时你没有强行回应祈愿......" 

"那这个世界也不会有这一簇星火了。"

## 战斗定位

洛奈尔当前是“稳定复制关键牌 + 星谱节奏构筑”的角色。她不使用乌娜的日耀、余烬、白曜作为核心资源，而是通过星石袋和奇迹时钟把行动后的随机抽石转化为指引牌复制、星辉累积和星辰序曲体系。

当前基础循环：

1. 战斗开始时获得星石袋与 12 层奇迹时钟。
2. 从抽牌堆和弃牌堆中选择一张牌作为指引牌；没有可选牌时，指引为隐藏的“魔女的星谱”。
3. 每次行动后从星石袋抽 1 个星石。
4. 抽中黑石：获得 1 层星辉，奇迹时钟减少 1。
5. 抽中白石：获得等同当前黑石数量的星辉，并触发自然晨星。
6. 自然晨星会复制当前指引牌到手牌，重置星石袋，并要求重新选择指引牌。
7. 奇迹时钟降至 0 时触发“借来的奇迹”：复制指引牌，时钟上限 -1，最低 6；随后重置星石袋与奇迹时钟，并获得等同时钟上限的星辉。

旧设计稿中存在“概率递增的晨星判定”“主动二：拨动奇迹时钟”“晨星事件链与隐藏首领”等构想。当前 shipped 数据中，洛奈尔职业只实装一个主动技能，且晨星判定已落地为星石袋抽石模型。

## 职业技能

### 主动：晨星祈愿

| 项目 | 内容 |
| --- | --- |
| 卡牌 Id | `*loneer_morning_star_prayer` |
| 完整 Id | `SunExp_loneer_loneer_morning_star_prayer` |
| 冷却 | 2 回合 |
| 游戏文本 | 触发【自然晨星】。本场战斗中，【星石袋】黑石上限 -2，最低为 1。 |

当前实现细节：

- 使用前会检查洛奈尔是否仍是当前有效角色；若被百变化身覆盖，会提示技能已被当前化身覆盖。
- 若冷却未结束，会提示“晨星祈愿尚未冷却”。
- 若尚未选定指引牌，会提示并重新打开指引牌选择。
- 成功使用时先触发自然晨星，复制当前指引牌到手牌。
- 随后将星石袋黑石上限减少 2，最低保留 1。
- 技能进入 2 回合冷却；百变共享冷却生效时使用共享冷却逻辑。

玩法意义：晨星祈愿不是直接造成伤害的爆发技，而是主动校准路线。黑石上限下降意味着下一轮星石袋更容易抽到白石，从而更频繁复制指引牌。

### 被动一：奇迹的时钟

游戏文本：战斗开始时，获得 12 层【奇迹时钟】。

当前实现：

- 战斗开始时 `ClockMax=12`，`ClockValue=12`。
- 每次星石袋抽中黑石，奇迹时钟 -1。
- 时钟降至 0 时触发“借来的奇迹”。
- 借来的奇迹会复制指引牌，并使时钟上限 -1，最低为 6。
- 借来的奇迹后，星石袋重置，时钟恢复到当前上限，并获得等同当前上限的星辉。

叙事上，奇迹时钟不是普通倒计时，而是“奇迹债”的计量器。失败越多，时钟越接近归零；归零时奇迹到期，但代价是之后的时钟上限变低。

### 被动二：星石定轨

游戏文本：战斗开始时，获得【星石袋】并从抽牌堆与弃牌堆中选择一张牌作为【指引牌】；若没有可选牌，则指引为隐藏的【魔女的星谱】。当【星石袋】抽中白石，触发【自然晨星】；抽中黑石，则令【奇迹时钟】层数 -1。

当前实现细节：

- 指引牌候选来自抽牌堆与弃牌堆。
- 星辰序曲、魔女的星谱、洛奈尔职业技能、运行时衍生/指引复制牌不会成为普通候选。
- 若选择 UI 不可用或取消，会从候选中随机选一张；若候选为空则回退到魔女的星谱。
- 指引牌复制由 `LoneerCardGrantService` 发到手牌。
- 普通指引牌复制件会被设置为 1 费，并带有 `Burnout`、`Nihility`、`衍生牌`、`指引牌`标记。
- 魔女的星谱作为特殊回退牌，不附加普通指引牌的 1 费、焚毁、虚无处理。

## 星谱与晨星：序曲

`【晨星：序曲】` 是洛奈尔当前最完整的机制卡包，围绕星谱、伏谱、连音、谱曲与启明星展开，强调牌序、费用节奏和谱句复奏。

### 星辰序曲衍生牌

| 牌 | 效果 |
| --- | --- |
| 星辰序曲·启 | 0 费，焚毁，虚无。抽 2 张牌，推进星谱：启。 |
| 星辰序曲·承 | 0 费，焚毁，虚无。获得 10 点护盾，使自身所有正面 Buff +1，推进星谱：承。 |
| 星辰序曲·转 | 0 费，焚毁，虚无。给予目标 2 层易伤，推进星谱：转。 |
| 星辰序曲·合 | 0 费，焚毁，虚无。造成 `10 + 自身 Buff 种类数 + 目标 Buff 种类数` 伤害，推进星谱：合。 |
| 魔女的星谱 | 0 费，焚毁，保留。根据本场战斗已完成的星谱，将对应谱句效果全部再打出一次。 |

星谱每记录 3 个音时结算一次谱句。结算后，当前实现会保留最后一音作为下一段谱句的起点。

### 已命名谱句

| 谱句 | 名称 | 效果 |
| --- | --- | --- |
| 启启启 | 急板 | 友方全体余音 +1；友方全体抽 2 张牌。 |
| 承承承 | 长音 | 友方全体护盾翻倍；友方全体正面 Buff 层数 +2。 |
| 转转转 | 失谐 | 敌方全体所有负面 Buff 层数翻倍。 |
| 合合合 | 终止式 | 对敌方全体造成 `1 + 友方全体 Buff 种类总数 * 敌方全体 Buff 种类总数` 伤害。 |
| 启承转 | 调律 | 自身余音 +1；友方全体余音 +1。 |
| 承转合 | 合奏 | 自身获得等同友方全体 Buff 种类总数的超凡。 |
| 转承启 | 回时 | 友方全体获得 30 层重生。 |
| 其它三音 | 三声和弦 | 友方全体抽 1 张牌。 |

### 卡包牌

| 牌 | 费用/标签 | 作用 |
| --- | --- | --- |
| 星图 | 0 费，焚毁 | 抽 3 张牌并给新抽到的牌附着【启明星】，然后选择 3 张卡牌焚毁。 |
| 空白星谱 | 1 费 | 清空当前星谱，获得 1 层星辰祝福，抽 1 张牌。 |
| 星律重订 | 1 费 | 若星谱不为空，将最后一音按启→承→转→合→启改写。 |
| 星律锚定 | 1 费 | 将星辰序曲·承写入伏谱；若连音条件达成，再写入星辰序曲·转。 |
| 星轨换位 | 1 费 | 清空当前星谱，并获得对应的星辰序曲。 |
| 休止符 | 0 费，焚毁 | 清空当前星谱；每清空 1 音，获得 1 余音并抽 1 张牌。 |
| 晨星：星台 | 2 费，焚毁 | 获得 1 层星台。 |
| 晨星：复奏 | 2 费，焚毁 | 复奏最近一篇完成的谱句，然后谱曲；若尚未完成谱句，获得启、承、转各 1 张。 |

补充机制：

- 【启明星】标签：带有启明星的牌打出后，按本次实际支付费用获得等量星辰祝福。
- 【星辰祝福】：让下一张非星辰序曲牌费用减半；打出后随机给 1 张启/承/转。
- 【余音】：在实际消耗魔能前代替魔能消耗，可用来维持高费用牌节奏。
- 【伏谱】：星律锚定写入的序曲会在下一回合开始时加入手牌。
- 【连音】：当前回合同费用牌已打出至少 2 次时，星律锚定追加星辰序曲·转。
- 【谱曲】：从已启用卡包中寻找名称含“曲”的非衍生候选牌，给一张带启明星的曲牌；若没有候选，则改为星辰祝福 +1。

## 星泥人傀

星泥人傀是洛奈尔故事中的替身，也是当前 SunExp 的使魔/伙伴机制之一。

| 项目 | 内容 |
| --- | --- |
| 伙伴 Id | `star_clay_doll` |
| 伙伴名 | 星泥人傀 |
| 伙伴被动 | 星泥傀身 |
| 机制 Id | `SunExp_sunexp_star_clay_doll_trait` |

当前机制：

- 战斗开始时，如果当前伙伴是星泥人傀，玩家获得星泥人傀特性。
- 特性生效时，玩家获得 1 层星泥傀身。
- 每次行动后，获得 1 层星辉。
- 玩家受到致命伤害后，若拥有星泥傀身且没有原生复生可用，会消耗 1 层星泥傀身，将最大生命减半，并恢复至新的最大生命值。

叙事上，星泥人傀替人承受一次坏运气，但坏运气不会消失，只是被写进奇迹时钟与星辉体系。

## 与乌娜的主题区分

| 维度 | 乌娜 | 洛奈尔 |
| --- | --- | --- |
| 特瑞厄斯象征 | 日 | 星 |
| 空间 | 王都、白曜圣庭、第二日轮核心 | 边境、晨星台、旧星历钟 |
| 主要灾厄 | 被污染的光 | 被透支的奇迹 |
| 战斗体验 | 灼烧、日耀、余烬、圣冕、爆发 | 星石、指引牌、复制、星谱、费用节奏 |
| 温柔的方向 | 痛苦可以停止，但不能被改写成从未发生 | 失败可以迟到，但不能永远不来 |

## 后续设计方向

以下内容来自 `Loneer/归档（不用看）/洛奈尔设计草稿.md`，属于角色方向稿，不等同于当前已实装内容：

- 专属事件链：被白昼淘汰的星历、边境晨祷、迟到的偶然、星泥替身、不再许愿、晨星坠落。
- 隐藏首领：晨星看护人·洛奈尔，代表过去仍相信“只要再多一次奇迹，大家就能撑到天亮”的洛奈尔。
- 结局方向：星辉终幕、无偿奇迹、坠星魔女。
- 旧稿中曾设计“主动二：拨动奇迹时钟”，当前职业数据未实装第二主动技能。

若后续制作《晨星：仁心祈愿》，建议以现行星石袋/奇迹时钟模型为准，把旧稿中的“奇迹债”和“星泥替身”叙事接到当前机制，而不要回退到早期概率判定稿。
