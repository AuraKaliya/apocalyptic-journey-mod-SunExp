# Terrias 架构决策与迁移门禁

> 生效日期：2026-08-26  
> 状态：Accepted / Implemented

## ADR-01：投影与精灵采用服务端权威独立单位模型

投影和精灵是具有召唤归属的独立友方单位，不是远程玩家分身。运行时必须区分：

- semantic owner：召唤者、数量限制和效果归因；
- simulation authority：当前战斗主机/服务端；
- execution route：为适配原生 `ScriptExecutor` locality 而使用的主机玩家 id。

协议 20 开始，权威状态下发 `ExecutionRoutePlayerId`。合成 Partner 的 status 只登记到该
执行路由，不能再登记到远程 semantic owner。原生 `RoleStatusMap` 是执行路由表，不是
Terrias 的语义所有权存储。

投影权威状态与表现事件完全分离。`ProjectionCompanionSnapshot` 是权威状态；
`ProjectionActionFrameSnapshot` 只包含 generation、action sequence、card 和 target，不能
写 HP、攻防、魔力或 BUFF。BUFF 复用修正路由后的宿主 `UpdateBuff` 通道，不建立第二个
补偿快照。

## ADR-02：Application 层和语义架构门禁

目标依赖方向为：

```text
Infrastructure <- GameApi <- Mechanics <- Application <- adapters
```

`Scripting`、`Network`、`Hooks`、`Features` 是 adapters，彼此不得直接依赖；`Entry` 是
唯一组合根。Mechanics 返回决定或领域事件，不能引用 Application port。

`tools/TerriasArchitectureGate` 使用 Roslyn 语义模型检查别名、全限定类型、基类/接口、
成员签名和实际符号引用，并检测最短依赖环。故意违规 fixtures 必须失败。现存遗留边记录在
锁定的 `tools/architecture-boundary-exceptions.json`，每项包含文件、目标层、原因、负责人
和删除里程碑；陈旧项会使门禁失败，数量预算只能减少。

## ADR-03：Network 是纯传输适配器

EndlessSea 的固定提交链为：

```text
RPC DTO + bound sender
-> Application handler
-> Mechanics decision
-> GameApi persistence
-> committed application event
-> Network broadcast / Hooks UI projection
```

`EndlessSeaStateSnapshot` 是无行为 DTO。存档读写由 `EndlessSeaSaveApi` 独占，generation、
hash、幂等和提交顺序由 `EndlessSeaApplicationService` 管理，地图 pending obligation 由
`EndlessSeaStateProjectionRuntime` 管理；传输未接受时由 `EndlessSeaNetworkAdapter` 的
有界 outbox 持有责任，按帧唤醒，直至发送成功或到达明确终态。旧的 `EndlessSeaNetworkSync` 及 Network 内的
Capture/Apply/UI 路径已经删除。本地主机和远程 RPC 进入同一个 Application handler。

## ADR-04：共享 DLL 单写入者和消费者分类

`tools/shared-consumers.json` 是唯一消费者清单。生产消费者固定为 Terrias、AuraToolsExp；
SanGuoShaExp 位于 `TestMods`，保留原 `.modproj`、`ModName`、`ownerModId` 和资源语义 id，
但只允许显式测试构建。

产品 `.csproj` 不再写 `Scripts/Entry.dll` 或 `Scripts/Aura.Shared.dll`。主构建先生成一次
canonical `Aura.Shared.dll`，再编译两个产品消费者。`Publish-MainSharedConsumers.ps1` 暂存
所有文件、校验 hash、逐文件原子替换、失败回滚并进行最终 hash 复核；发布清单写入
`artifacts/shared-release/<Configuration>/shared-package-manifest.json`。

## 完成门禁

- 投影/精灵 semantic owner 与 execution route 可不同，且 host self-BUFF 路径为本地执行；
- 表现事件不包含或写入权威状态；
- EndlessSea Network adapter 不引用存档、Mechanics、Hooks 或 UI；
- Roslyn fixtures 和实际语义边界均通过；
- 生产消费者恰好为两个，SanGuoShaExp 不进入默认构建或 release matrix；
- canonical、Terrias、AuraToolsExp 三份 `Aura.Shared.dll` SHA-256 完全一致。
