# Terrias 与 AuraToolsExp 资源边界

## 最终职责

| 层级 | 负责内容 |
|---|---|
| Terrias 内容 MOD | 卡牌、角色、BUFF、遗物、模式、玩法与机制；稳定角色/卡牌/卡包 id；开场导演动画、乌娜轨道火、星谱反馈等与内容不可分离的表现 |
| AuraToolsExp 工具 MOD | 技能 CG、卡牌使用 CG、一键美餐 CG、角色语音、出牌音效、替换皮肤、卡框主题、可配置卡牌动态效果及其设置界面 |
| Aura 共享层/核心层 | 资源协议、owner-qualified 标识、卡牌展示生命周期、音频信号、CG 播放/黑键/闪屏、缓存、联机权限与去重 |

Terrias 不依赖 AuraToolsExp。AuraToolsExp 也不依赖 Terrias 内部类型；它只使用共享协议、原生数据目录和稳定的 Terrias 内容 id。

`Terrias/SharedResources/aura.registration.json` 是版本化的空退役清单，用于撤销旧版可选媒体注册；`SharedResources/Skins/retire.registration.json` 和 `cg.retire.registry.json` 分别一次性清除旧皮肤包与旧 CG contribution。Terrias 不再包含活动的 `audio.registry.json`、CG registry、替换皮肤包或媒体文件。

## AuraToolsExp 资源入口

- `AuraToolsExp/SharedResources/aura.registration.json`：统一安装 CG、语音、替换皮肤和卡牌视觉资源。
- `AuraToolsExp/SharedResources/cg.registry.json`：技能、卡牌使用和一键美餐 CG。
- `AuraToolsExp/audio.registry.json`：角色语音提供者及信号匹配。
- `AuraToolsExp/SharedResources/Skins/package.json`：全部替换皮肤。
- `AuraToolsExp/card-visual.registry.json`：卡框主题、映射预设与动态效果协议。
- `AuraToolsExp/Config/CardVisualSettings.json`：用户的显式逐卡白名单；出厂为空。

AuraToolsExp 的卡牌使用 CG 管理页可逐项启用、预览、打开资源目录，并覆盖布局、适配、淡入淡出、序列帧间隔、Alpha/黑键参数以及闪屏模式、时刻、帧区间、脉冲和强度。覆盖只写入工具本地配置，不修改注册表源文件。

## 语音信号

音频请求同时携带 `Kind` 和 `Stage`。AuraToolsExp 可按提供者修改信号、阶段、动作 id、资源、增益、冷却和低血量阈值。

| 信号 | 阶段 |
|---|---|
| `CareerSelected` | `Committed` |
| `CardUse` / `SkillVoice` | `PresentationCommitted` |
| `BuffApplied` | `Applied` |
| `VocalState` | `Observed` |
| `LowHealth` | `ThresholdCrossedDown` |
| `BattleCompleted` | `Completed` |

选人语音只在选择提交时触发，不在普通详情预览时触发。卡牌和技能语音使用稳定卡牌 id；低血量使用一次向下穿越阈值的事件。

## 卡牌视觉协议

运行时只读取 `ownerModId:cardId -> skin/effect` 的显式映射，不进行卡包、稀有度、图标前缀、后缀或通配符匹配。

配置界面的“按卡包”和“按稀有度”是批量编辑操作：读取当前原生卡牌目录，把选中的结果一次性写成多个显式卡牌 id。因此后续卡包内容变化不会暗中扩大用户白名单。

主题可以携带版本化 `mappingPreset`。主题首次在原生目录就绪后加载时，将预设展开到该主题的显式映射；此后普通启动不覆盖用户修改。只有用户主动执行“重置主题预设”才重新展开。

Terrias 主题包含：

- `solar` 日耀：预设映射【日耀：烬冠天幕】卡包。
- `morning-star` 晨星：预设映射【晨星：序曲】卡包，以及【星辰序曲】启、承、转、合四张显式卡牌。
- `radiant-moon` 辉月：提供皮肤，不附带默认映射。

## 炽冕崩落

Terrias 只保留【炽冕崩落】卡牌机制和稳定卡牌 id。共享层负责成功卡牌动作信号、播放队列、黑键、闪屏、联机权限和去重；AuraToolsExp 负责序列帧资源、CG manifest、VisualBundle 材质、配置与最终播放配方。

## 迁移

旧的 Terrias CG、卡牌使用 CG、一键美餐 CG、语音和替换皮肤资源已迁入 AuraToolsExp。保留的本机 Skill CG 规则、卡牌使用 CG 开关、一键美餐资源开关和皮肤选择会一次性改写为 `AuraToolsExp` owner-qualified 标识；运行时不保留 Terrias 媒体回退路径。
