# 内容 MOD、工具 MOD 与共享资源边界

## 最终契约

Terrias 是内容 MOD，AuraToolsExp 是工具 MOD，两者都是 Aura 共享层的兄弟消费者。

- Terrias 拥有玩法、稳定内容 id、必需表现，以及 Terrias 自有的可选角色语音和技能/卡牌/美餐 CG 文件与声明。
- AuraToolsExp 拥有已载入内容 MOD 的共享资源发现、玩家本地配置、编辑器、预览和覆盖；替换皮肤、卡框主题、动态卡面效果及工具默认媒体仍由 AuraToolsExp 持有。
- AuraSharedCore、AuraAudioShared、AuraCgShared 等共享层拥有资源存储、注册表、播放、联机权限、去重和生命周期。
- Terrias 不在 `Entry` 中主动安装、注册、配置或播放可选媒体，也不恢复私有 Audio/CG 运行时。

## 固定发现入口

内容 MOD 通过 `SharedResources/aura.discovery.json` 声明贡献：

- `resources`：v4 资源包清单；
- `audio`：Audio Provider registry；
- `cg`：CG registry。

AuraToolsExp 只扫描游戏实际已载入的 MOD，不遍历未加载目录，也不猜测内容 MOD 私有结构。扫描器在文件后台完成哈希和校验，主线程提交共享注册。

物理来源身份来自 MOD 根目录唯一的 `*.modproj` 数字 id；语义身份继续使用 `ownerModId`。同一 `.modproj` id 且共享资源指纹相同只注册一次；同 id 但指纹不同视为冲突并停止该来源注册。

## Terrias 当前贡献

`Terrias/SharedResources` 当前包含：

- `aura.discovery.json`；
- `aura.registration.json`：9 条 Terrias 资源、9 条注册默认；
- `audio.registry.json`：9 个角色语音 Provider；
- `cg.registry.json`：7 个技能/卡牌/美餐 CG；
- 22 个音频文件；
- 43 个 CG 文件。

这些声明的语义 owner 均为 `Terrias`，但其有效开关、表现覆盖和玩家导入资源由 AuraToolsExp 的本地配置层决定。

替换皮肤、卡框主题、通用卡牌音效和动态卡面效果不属于本次回迁，继续保留在 AuraToolsExp。

## 加载与刷新顺序

1. AuraToolsExp 初始化共享 Core 与工具自有资源。
2. 游戏 MOD 加载稳定后，AuraToolsExp 捕获实际已载入目录。
3. 后台读取 `.modproj`、发现清单和完整 `SharedResources` 指纹。
4. 每个来源先完整校验，再依次提交资源包、Audio contribution 和 CG contribution。
5. 扫描代次结束后撤销已消失来源或已删除 contribution。
6. Audio/CG revision 通知消费者刷新派生状态。
7. 应用顺序始终是：注册默认 → 工具发布默认 → 玩家本地覆盖。

工具箱顶部提供“刷新共享资源”操作；普通启动、游戏入口刷新和手动刷新使用同一个幂等流程。

## 配置迁移

曾经由 AuraToolsExp 持有的 Terrias 媒体设置一次迁回：

- `AuraToolsExp:terrias.blazing-crown-collapse` → `Terrias:terrias.blazing-crown-collapse`；
- Terrias 三个 Skill CG、三个美餐 CG 的 owner 恢复为 `Terrias`；
- `AuraToolsExp.Terrias.*` 语音 Provider 恢复为 `Terrias.*`；
- 旧共享语音路径中的 `/Voice/AuraToolsExp/` 改为 `/Voice/Terrias/`。

迁移后只写新身份，不保留永久双读。AuraToolsExp 中的 Terrias 媒体文件和声明、Terrias 空退役清单及旧 `ModResource/Images/CG` 重复副本均已删除。

技能语音另执行一次协议 v8 迁移：旧绑定中的技能 `actionId/cardIds` 按角色 Career 配置的 `Skill1..N` 解析为一基 `skillSlot`，成功取得角色配置后清空旧 `actionId` 并持久化。运行时只匹配技能事务请求的 `SkillSlot`；角色只有一个技能时不能配置序号 2，角色数据尚未就绪时则暂缓迁移并失败关闭，不回退到卡牌触发。

## 联机

资源文件和本地路径不通过 RPC 传输。大厅 MOD 快照包含共享资源指纹；同版本但资源指纹不同会显示不一致。音频和 CG 事件仍只传 owner/provider/CG、动作/session 与有界序列信息，各端从本地注册表解析资源。
