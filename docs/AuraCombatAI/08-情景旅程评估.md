# 情景旅程评估

## 目的

情景旅程评估回答的是“同一世界种子、同一规则集和同一公开信息下，候选策略是否稳定优于底模”，而不是用少量单局结果估计真实玩家胜率。

## 对照设计

每个 seed 同时运行：

- 学习模型策略；
- 规则底模策略。

两者使用相同旅程、难度、规则集和随机种子。结果按 seed 配对，记录：

- 战役是否权威；
- 完成战斗数和最远深度；
- 最终 Boss 是否胜利；
- 无效原因；
- 候选与底模的分歧动作；
- 规则覆盖和终局一致性。

非权威配对不进入正式胜率分母，只进入诊断统计。界面必须把“正式有效样本不足”与“胜率为 0”区分开。

## 难度门禁

候选模型需要分别拥有普通和高级结果：

- 普通验证默认 200 个战役；
- 高级验证默认 500 个战役；
- 每个难度检查最低候选胜率；
- 检查相对底模的最大允许回归；
- 检查无效率、权威覆盖和终局一致性；
- 摘要中的模型 ID 必须与待激活模型一致。

只有一个难度通过不能激活模型。

## 结果文件

每次运行目录保存：

- `summary.json`
- `results.jsonl`
- `status.json`
- 分歧轨迹和检查点目录

当前快捷摘要按 profile、难度和模型 ID 分开写入。读取激活门禁时只接受目标模型对应的普通/高级摘要，不借用其他模型或无模型摘要。

## 指标解释

- `AuthoritativePairs`：可进入正式统计的配对数。
- `CompletedPairs`：已经运行完成的全部配对。
- `InvalidPairs`：规则、终局或运行失败的配对。
- `AuthoritativeCoverage`：正式配对占完成配对比例。
- `LearnedWinRate` / `BaselineWinRate`：只基于权威配对。
- `RawLearnedWinRate` / `RawBaselineWinRate`：探索性原始结果，不用于门禁。
- `MaximumCompletedBattles`：即使没有通关，也能反映旅程推进能力。
- `DivergentPairs`：候选与底模出现策略分歧的配对。

## 防止评估污染

- 训练、调优竞技场、确认竞技场和最终验证使用分离种子区间；
- 最终测试结果不能回流到本轮模型选择；
- 失败种子进入下一轮训练前必须重新划入训练集合；
- 修改规则集、知识包、特征编码或模型后必须重新评估；
- 不允许只挑选成功 seed 生成摘要。
