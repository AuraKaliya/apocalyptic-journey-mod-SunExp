## 文档目标

这套文档用于把自动决策、自动战斗、出牌决策图和后续友方 AI 的开发工作交接到其他机器。它同时回答：

- 当前代码已经实现什么，哪些结论只经过编译或自动化测试；
- 后续每个阶段的进入条件、交付物、退出条件和回退方式；
- 新机器如何准备环境、构建、打包、运行测试并保存证据；
- 如何测试普通动作和会打开额外 UI 的复合动作；
- 内容 MOD、AuraToolsExp、共享层和未来友方 AI 各自负责什么；
- 训练数据、学习模型、模型大小和运行效率如何逐步引入。

## 维护规则

- “代码已实现”“自动化测试通过”“游戏内验证通过”必须分开记录。
- 只有其他机器上的真实对局证据完成后，才能把阶段 1 标记为“运行验证完成”。
- 共享源码变化后必须重新构建所有主要消费者，并验证三个 `Aura.Shared.dll` 副本一致。
- 新的卡牌语义和合法性规则应由内容所有者注册，不能硬编码进 AuraToolsExp。
- 学习模型只能作为规则与效用模型的残差，不能绕过硬合法性规则。
