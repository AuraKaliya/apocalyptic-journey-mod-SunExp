# 风险敏感根抽样 PUCT

## 搜索对象

生产规划器为 `CombatRiskAwareRootSamplingPuctPlanner`。它是面向回合内多步动作的风险敏感 MCTS：

- 根部覆盖全部合法动作；
- PUCT 分配后续模拟；
- 每次模拟执行根抽样；
- 前向模型展开卡牌、技能、状态和机会结果；
- 转置表按公开模拟状态哈希复用节点；
- 达到叶节点后结合规则估值、搜索引导和策略价值网络；
- 输出当前动作及代表性主变化。

## PUCT 选择

对边 `a` 使用：

```text
score(a) = Qrisk(a)
         + c_puct * prior(a) * sqrt(parentVisits) / (1 + visits(a))
```

`prior` 来自三类信号的同尺度组合：

1. 根候选规则分在当前动作集合内做 z-score 标准化，并截断到 `[-3, 3]`；
2. 搜索引导 logit 截断到 `[-4, 4]`；
3. 策略价值网络 logit 截断到 `[-4, 4]`。

随后统一 softmax。这样绝对量级较大的规则分不会淹没学习先验，模型也不能用异常 logit 垄断探索。

## 风险统计

每条根边维护：

- 样本数；
- Welford 在线均值和方差；
- 标准误；
- 死亡风险均值；
- 最多 2048 个回报样本；
- 下尾均值及尾部样本置信度。

下尾均值使用最差 `alpha` 比例回报。尾部样本少于 8 个时，不直接把单个坏样本当成稳定 CVaR，而是向总体均值收缩：

```text
tailConfidence = clamp((tailCount - 1) / 7, 0, 1)
effectiveTail = mean
              + tailConfidence * (rawLowerTailMean - mean)
```

单样本标准误采用保守下限，防止首次幸运样本看起来“零不确定性”。

## 统一风险效用

树内 exploitation、根排序、稳定性检查和主变化都使用同一个效用：

```text
Qrisk = 0.65 * mean
      + 0.35 * effectiveLowerTailMean
      - tailRiskPenalty * meanDeathRisk
      - uncertaintyPenalty * standardError
```

最终选择先应用生存约束：

1. 若存在 `meanDeathRisk <= DeathRiskLimit` 的动作，只在这些动作中排序；
2. 若所有动作都越界，只保留风险不高于最小风险 `+ 0.01` 的动作；
3. 再按 `Qrisk`、访问量、先验和稳定候选 ID 排序。

这避免了“先按原始 CVaR 排序”导致高均值、合理尾部风险的动作被极少尾部样本错误压制。

## 机会节点与代表子节点

一次动作可能产生多个机会结果。边按子状态哈希累计证据，不再用最后一次模拟覆盖 `Child`。主变化选择访问量最多的代表子状态；访问量相同时按稳定哈希决定，因此日志和调试结果可复现。

## 早停

搜索只有同时满足以下条件才提前停止：

- 已达到最小模拟数；
- 根候选覆盖完成；
- 最佳动作至少 2 次访问，第二名至少 1 次；
- 最佳动作保持足够访问领先；
- 风险效用领先超过由双方标准误计算的不确定性阈值；
- 最佳动作和代表图结构在稳定窗口内未变化。

仅有访问量领先但价值仍在误差范围内时，不会早停。

## 动态预算

`CombatSearchBudgetPolicy` 将状态分为：

- `forced`：只有一个合法动作；
- `simple`：低分支、低威胁、无复杂链；
- `normal`：常规战斗；
- `difficult`：Boss、高威胁或高价值分歧；
- `complex`：随机链、生成链、零费循环或假循环风险。

质量档缩放预算：

| 质量档 | 模拟量 | 节点量 | 深度 |
|---|---:|---:|---:|
| `fast` | 0.65 倍 | 0.75 倍 | 基线减 2 |
| `balanced` | 1.0 倍 | 1.0 倍 | 基线 |
| `deep` | 1.75 倍 | 2.0 倍 | 基线加 4 |

强制动作始终只做最小验证。生产不接受手填固定搜索数字；固定模式仅供确定性测试。
