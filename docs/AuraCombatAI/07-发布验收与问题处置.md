# 发布验收与问题处置

## 发布前检查

### 源码

- 决策通用逻辑位于共享层；
- AuraToolsExp 不依赖内容 MOD 内部实现；
- 内容合法性规则没有副作用；
- 未调用 `CommonCardItem.TryUse` 做候选检查；
- 新交互适配器有重复提交保护；
- 自动战斗关闭后可以交还玩家；
- 联机只控制本地行动权对象。

### 游戏内

- 所有 P0 场景通过；
- 目标复杂交互 P1 场景通过；
- 按钮在目标分辨率和语言下可用；
- 没有重复出牌、重复扣费或错误结束回合；
- 关闭自动战斗和异常停止后玩家可以继续；
- 胜利、失败、逃跑和返回主菜单后状态清理；
- 20 局长时测试没有事务超时。

### 打包

- 三个主要消费者均重新构建；
- `Aura.Shared.dll` 哈希一致；
- 交付配置 schema 已升级；
- 文档和测试矩阵已更新；
- 没有把训练样本、日志或本机路径打进 MOD 包。

## Go/No-Go

以下任一情况必须 No-Go：

- 出现重复扣费或重复业务回调；
- 自动战斗操作了错误玩家或远端单位；
- 必选 UI 被关闭且玩家无法继续；
- 战斗结束后仍继续提交动作；
- 共享 DLL 不一致；
- 模型或未知动作可以绕过合法性；
- P0 缺陷没有稳定规避方式；
- 无法获得对应游戏版本和 MOD 清单的复现证据。

## 缺陷分级

| 等级 | 定义 | 示例 |
| --- | --- | --- |
| P0 | 破坏战斗、存档、权限或可继续性 | 重复扣费、控制远端玩家、卡死必选 UI |
| P1 | 主要功能错误但可手动恢复 | 错选目标、复杂交互超时、按钮阻挡确认 |
| P2 | 决策质量或兼容问题 | 某类牌估值差、未知动作过度保守 |
| P3 | 诊断、文档或轻微视觉问题 | 日志缺字段、按钮文本不理想 |

## 责任层判断

| 现象 | 首查层 |
| --- | --- |
| 同一动作执行两次 | AuraTools 控制事务和 GameApi 执行器 |
| 费用或合法性错误 | Witch 预检、内容 preflight rule |
| 选择了错误类型的牌 | 内容语义、InteractionHint、多选规划 |
| UI 重复点击或无法关闭 | Witch 交互适配器 |
| 只有某内容 MOD 出错 | 内容 MOD 语义或规则注册 |
| 三个 MOD 行为不一致 | 共享 DLL 打包和版本 |
| 模型建议异常 | 特征版本、模型校验、残差上限 |
| 联机对象错误 | authority 和本地所有权检查 |

## 事务故障处理

发现自动战斗等待超时时：

1. 停止自动战斗，不自动重试失效动作；
2. 保留当前 UI 给玩家；
3. 记录根动作、候选 id、状态指纹、等待时间和活动 UI；
4. 判断是动画、建牌队列、已知交互还是未知 UI；
5. 只有确认原生流程幂等时才能增加自动恢复；
6. 不通过缩短等待或连续点击掩盖问题。

## 回退

首选回退顺序：

1. 在配置中关闭自动战斗模块；
2. 将未知动作策略改为 `handoff`；
3. 禁用学习残差模型，回到启发式模型；
4. 禁用具体内容语义提供器或 UI 适配器；
5. 回退整个自动战斗版本并重新构建所有共享消费者。

不能只替换某一个 MOD 中的 `Aura.Shared.dll`。
