# 阶段 5：权威战斗知识与规则覆盖

## 目标

阶段 5 不再把卡牌说明文本当作战斗规则。战斗知识由三类证据合并：

1. `AllScripts.cs` 的实际脚本行为；
2. 游戏运行时导出的 `Card / Enemy / EnemyCard / Buff / Level` 等数据表；
3. 对关键机制逐段核验后的人工权威定义。

共享规划器、训练模型和无 UI 模拟器使用同一组定义 ID、来源、版本与权威度。未知定义必须进入覆盖报告，不能静默按零价值处理。

## 已修正的实时观察

- Buff 从 `StatusManager.GetBuffs()` 和 `IBuffItem.buffConfig` 读取，不再误读事件回调 `effectList`。
- 每个 Buff 保存 ID、层数、上限、每回合/每次使用/每次受击衰减和类型。
- 敌人观察保存稳定的 `DefinitionId`。
- 同时采集完整套牌、当前抽牌堆顺序和弃牌堆；覆盖门禁会检查整套牌，而不只检查当前手牌。
- 运行时倍率改为游戏主体实际使用的 `PercentDamage`、`DefaultDamage`、`DefendPercent`、`HealMultiplier`、`AttackedPercentDamage` 和 `AttackedDefaultDamage`。
- 敌方威胁同时经过敌方输出修正和玩家承伤修正。

## 知识包

`CombatKnowledgePackage` 包含：

- 游戏版本和源文件哈希；
- 动作、Buff、敌人、固定遭遇；
- 原始脚本操作、表字段、来源位置；
- `Authoritative / Derived / Approximate / Unsupported` 权威度；
- 动作角色、状态变化和前向规划语义；
- 发现数量、权威数量和未支持脚本数量。

AuraToolsExp 自带的生成清单位于：

- `AuraToolsExp/Config/combat-knowledge.base-game.json`
- `docs/AuraCombatAI/base-game-knowledge-report.json`

本轮对 `1.0.23816797` 的编译结果覆盖 2991 个注册脚本、879 个动作实体、80 个 Buff 和 56 个敌人实体。自动抽取结果默认最高只到 `Derived`；只有人工核验或内容所有者注册的规则能够成为 `Authoritative`。

## 海洋之梦

`elementscard_1` 已作为人工核验的权威动作注册：

- 0 费由实时卡牌成本提供；
- 抽 1；
- 增加 2 层 `buff_elements`；
- 当前 `ActionAfter` 链增加 4 层 `buff_extraordinary`；
- `buff_extraordinary` 每层增加 1% `PercentDamage`；
- 规划语义因此包含 4% 后续伤害倍率和持久铺垫价值。

它会进入“安全零费铺垫”支配检查，因此不会再因为即时伤害分较低而被无意义地排到攻击牌之后。

前向搜索不再把抽牌只处理为 `HandCount + 1`。抽牌堆按游戏中的真实顺序保存，搜索会取出下一张牌，并根据知识包中的伤害、防御、治疗、成长、倍率和资源语义计算“已抽到卡牌潜力”。因此套牌中的关键牌和高价值牌会影响当前抽牌、铺垫与结束回合的比较；未知牌的潜力按零处理并增加覆盖缺口，而不是凭卡名猜测。

## Buff 与模拟器

模拟状态现在支持：

- 状态层数驱动的动态变量；
- 表达式数值，包括来源/目标变量、HP、最大 HP 和 Buff 层数；
- 直扣生命、变量修改、真伤和普通伤害；
- `PercentDamage / DefaultDamage / DefendPercent / HealMultiplier` 等主体公式；
- Buff 每回合、每次出牌、每次受击衰减；
- 触发器消耗层数；
- 敌方行动优先级、冷却和防连续使用。

原有固定整数规则保持兼容；没有表达式或动态变量的旧场景仍按原路径运行。

## 覆盖门禁

每次实时决策会收集：

- 当前可用动作；
- 玩家和敌人的全部 Buff；
- 当前敌人定义。

覆盖报告逐项计算权威、派生、近似、未支持和未知数量。训练模型处于 `active` 时，只有当前状态达到 100% 权威覆盖才允许接管；否则本次决策自动退回底模。影子评估仍可运行，用于发现差异但不会执行学习模型动作。

这项门禁避免了“总体覆盖率很高，但当前恰好遇到一个未知致命 Buff”仍然放行的问题。

## 异机数据闭环

游戏机器在自动战斗的“模拟评估”区域点击“导出规则”，会写出带游戏版本的运行时表快照。把快照与反编译目录带回开发机后运行：

```powershell
dotnet run --project tools/AuraCombatKnowledgeCompiler/AuraCombatKnowledgeCompiler.csproj -c Release -- `
  --scripts "开发参考资料/反编译文件夹v1.0.23816797/AllScripts/AllScripts.cs" `
  --tables "<table-export.json>" `
  --output "AuraToolsExp/Config/combat-knowledge.base-game.json" `
  --report "docs/AuraCombatAI/base-game-knowledge-report.json" `
  --game-build "1.0.23816797"
```

合并后会补齐卡费、标签、Buff 生命周期、敌人 HP/行动列表，以及 `Level` 表中的固定敌人组合。复杂闭包、随机分支或未映射 API 会留在报告中等待人工复核。
