# 训练与模型门禁

## 两类训练数据

### 在线选择样本

- 协议：`aura.combat-ai.sample.v9`
- 特征：11
- 选择轨迹：`aura.combat-ai.selection.v2`
- 文件：`auto-battle-training-v9.jsonl`

`Selection.ExecutedCandidateId` 是真实执行动作的唯一来源，`Selection.PolicyPreselectedCandidateId` 是策略预选。v2 额外保存 `ReceiptId`、`DecisionPurpose`、`DecisionAuthority`、`DecisionModelId`、`AuthorityKnown`、`FallbackKind`、`ObservationRevision`、`QueueMilliseconds` 和 `ComputeMilliseconds`。只有事务完成的样本可训练。人工覆盖且两个 ID 不同，才形成残差偏好对；技术兜底只作遥测，不是模型偏好标签。

样本顶层不重复存储候选 ID、来源或示范者。读取器接受当前 v9，或把同一特征语义的 v8 + selection v1 单向升级为 v9/v2；旧 policy 样本没有可靠权威来源时写成 `legacy-policy-unknown`，不得猜成规则或模型。v7/特征 6 及更早版本不迁移。

写入器对“待写对象 + 未结束会话”使用统一 32 MiB 预算，单会话上限 8 MiB / 2048 帧，并为终局控制回执预留 64 KiB。任意 I/O 故障会进入可见的 `Faulted` 状态、释放受影响队列并停止当前线程；下一次记录会在旧线程已退出后创建新 writer，首次成功批次清除故障诊断。生产者不会在 writer 已退出后继续无界堆积。`BattleFinalized` 将权威胜负写入最后一个已完成样本的 episode 视图，然后无论胜、负或放弃都释放该会话。

### 长期战斗轨迹

- 协议：`aura.combat-ai.episode.v8`
- 特征版本：30
- 编码：`partitioned-v4`
- 文件：`live-combat-episodes-v5.jsonl`

Episode 保存每个公开决策帧、合法候选、搜索访问量、风险、真实执行动作以及终局回填的长期回报、胜负、死亡、剩余生命和剩余回合。每帧还保存 `CombatObservationEnvelope`，供对象 Token Transformer 使用；它只来自玩家可见观测，不读取隐藏牌序或未公开随机结果。

在线选择样本同时记录每次决策的墙钟耗时、模拟/节点数、模型调用与缓存命中、裁剪前后候选数以及时间/模型预算停止原因。性能门禁必须使用这些分阶段字段，不能用整批训练吞吐代替单决策延迟。

## 特征编码

`partitioned-v4` 使用 2048 维状态塔和 1024 维动作塔。状态槽依次隔离为 64 核心、896 通用、256 玩家状态、384 牌堆/手牌/保留、256 弃牌/耗尽和 192 敌人槽；牌区内部继续分区，避免同一张牌在手牌、弃牌和耗尽语义之间碰撞。动作塔保留 1024 维，隐藏层固定 512。旧 `partitioned-v3` 只允许诊断读取，不得继续训练或冒充当前模型。

训练产物记录：

- `stateFeatureCollisionRate`
- `actionFeatureCollisionRate`

状态碰撞目标为 3%，硬上限为 5%；动作碰撞硬上限为 6%。碰撞率异常升高说明维度不足、特征泄漏或身份域膨胀，应阻止模型直接晋级。

## 策略价值网络

当前网络是共享状态塔、动作塔和多头输出的轻量 MLP：

- 策略 logit；
- 每个合法动作的 16 个回报分位数；
- 长期回报；
- 胜率；
- 死亡概率；
- 终局剩余生命比例；
- 剩余回合。

基础/影子路径中，运行时网络提供根先验和叶节点估值，仍受规则评分、风险统计和硬门禁约束。`trial/full` 中策略价值网络直接拥有合法候选选择权；规则评分只保留为诊断，不能覆盖正常模型提案。模型加载、推理异常或硬截止才触发技术兜底。

动作 Q 使用搜索边回报分布作为监督，只有搜索访问量达到 8 且至少有 4 个有效分位点的动作才参与 Huber 分位损失。未访问边以 `0.7 * 均值 + 0.3 * 下尾均值` 作为 FPU，取得真实模拟样本后立即由经验统计接管。玩家偏好适配器不得修改动作 Q。

最佳 epoch 确定后，仅使用验证集在有限候选温度中校准策略 logit；测试集仍保持隔离。校准温度写入模型并同时用于托管推理与离线指标。

## 数据切分

按 `JourneyRunId` 分组；没有旅程 ID 时按 Episode ID 分组。相同旅程的所有战斗只能进入一个集合。

当数据量足够时：

- 约 80% 训练；
- 约 10% 验证；
- 约 10% 测试。

分组先按稳定 FNV 哈希排序，再确定配额。少于 64 个运行组时保证至少有一个训练、验证和测试分组；达到 64 个运行组后，验证集和测试集各自至少保留 16 个运行组。验证集用于早停和选择最佳 epoch；测试集只在最佳模型确定后评估，不能参与调参。

## 帧级样本平衡

每轮 Replay 固定后先构造一个有界的教师/学生共享训练窗口，默认最多 10000 帧，并按
Episode、帧 ID 和稳定哈希确定性选择。Transformer 教师和 MLP 学生只能从这个共同窗口
切分训练/验证数据，禁止教师先消费整份 Replay、学生再从另一套分布抽样。结果必须报告
源帧、入选帧、丢弃帧、教师训练/验证帧及学生实际消费率。
只有一个合法动作的强制决策仍保留给 Dynamics、Outcome、Risk 和历史表征，但不计入
Transformer Policy 损失、准确率或均匀策略基线，避免用平凡动作虚高策略质量。

角色策略通过 `roleStrategy:training-quota:min|max:<strategy>` 声明训练配额；共享选择器只
识别 survival、finale、transform、growth、bank 等通用策略名，不识别角色 ID。配额先
限制过量层，再补齐稀缺层，无法满足时输出逐策略缺口并阻止正式晋级。奈奈当前声明
transform 最大 50%，growth/survival 各最小 15%，finale/bank 各最小 5%。这只是数据合同，
不得演变成角色专用在线动作规则。

不安全结束回合是高价值反例，但不能淹没普通动作。训练帧达到 64 条后，策略监督中的
`unsafe-end-turn` 占比默认限制在 20%；另允许最多 10% 的确定性风险辅助帧。辅助帧不计算
策略、动作 Q 或分位数梯度，只训练共享状态塔及价值、胜负、死亡、生命和回合头。
安全结束回合保留，剩余过量反例丢弃。结果分别记录策略反例、风险辅助反例和丢弃数量，
不能再用一个总占比掩盖两类样本的作用。

## 语义准入门禁

`semantic-admission-v5-actual-selected-transition` 在预检和每批自博弈后验证真正交给决策器与训练帧的权威 transition。抽样到多候选权威教师时，只有运行时能够从 `CombatBattleState` 精确重建后续脚本/触发器状态时，训练器才会执行不可变反事实分支；否则该候选教师安全降级，不会把缺失原生连续状态的分支当成语义非法。最终选中动作不再重复执行单步分支，而是在正式战斗会话实际执行完成后，从动作前后状态、因果事件和战役变量生成事实语义，再回写 Observation 与训练帧。动作成功应用与战斗胜负分开记录，因此“合法动作导致自身死亡/战斗失败”属于成功 transition，不会再误记为 `action-transition invalid`。结构化 Effects 仍额外检查“声明是否与执行矛盾”；只有原生脚本、且静态 Effects 为空的动作明确归类为 `realized-only` 覆盖，不再把“没有静态声明”误判成“声明了零效果”。事实轨迹缺失、状态守恒失败或决策输入与实际执行结果不一致会隔离整批 episode 并立即停止训练：

- `SelectedInvalidActions`；
- `SelectedUnexplainedMismatchActions`；
- `SelectedSourceProjectionInvalidActions`；
- `SelectedSourceProjectionUnexplainedMismatchActions`。

被选中的决策输入 transition 必须零无效、零未解释偏差；全部审计动作的无效率不得超过 1%，有效动作的未解释偏差率不得超过 5%。`CounterfactualBranchUnavailableActions` 只报告无法精确重建原生连续状态的候选分支及来源，不进入语义失败分母；最终选中动作仍由实际执行审计覆盖。声明覆盖缺口由 `CombatSemanticCoverageAudit` 独立报告，不能通过伪造零值进入门禁分母。已实现数值已经经过力量、感知、护盾、治疗倍率等结算，审计不得再次应用这些修正。交互父动作只声明“打开选择”，选择完成后的抽牌、焚毁或检索属于后续阶段，不得冒充父动作即时事实。

被隔离的 episode 只计入 `GeneratedReplayEpisodes` / `DiscardedSemanticEpisodes`，不得进入 replay、检查点或模型。Worker 此时正常完成进程，但分别报告 `TrainingSucceeded=false`、`ModelAccepted=false`，避免把“进程成功退出”误读为“模型训练成功”。

## 优化器

训练使用确定性 AdamW：

- `beta1 = 0.9`
- `beta2 = 0.999`
- `epsilon = 1e-8`
- 权重使用解耦衰减，偏置不衰减；
- 全局梯度范数上限为 1；
- 非有限梯度或更新立即失败；
- 学习率随 epoch 平滑衰减；
- minibatch 顺序由固定种子和 epoch 决定。

检查点保存模型、最佳模型、Top-K 候选、早停状态以及 AdamW 一阶/二阶矩和 step。恢复训练应与不中断训练得到逐元素相同的权重。

## 指标与门禁

至少观察：

- 训练/验证/测试分组数；
- 策略准确率和交叉熵；
- 关键决策准确率；
- 价值 MAE；
- 胜负和死亡 Brier；
- 生命 MAE 和回合 Huber；
- 动作 Q 分位 Pinball/Huber 与 MAE；
- 验证与测试综合损失；
- 梯度裁剪次数和最大梯度范数；
- 状态与动作碰撞率。
- 对象 Token 覆盖率与关键对象截断数；
- 世界模型下一状态 MSE、Outcome MAE、死亡 Brier 与 Terminal 准确率；
- 模型调用预算耗尽率、模型缓存命中和候选保留率；
- 不安全结束回合原始/保留/丢弃数量；
- 共享训练窗口的源帧/入选帧/消费率、逐策略配额与缺口；
- 同一固定验证集上的训练前基线、训练后指标和多头综合改进；
- Transformer 固定锚点规模、教师代次、更新接受/回滚和数据漂移；
- 语义拒绝战役和隔离 episode 数；
- Worker 完成、训练成功、模型接受三种独立状态。

模型晋级还必须通过：

- 当前模型协议、特征版本、编码和维度校验；
- 所有权重有限；
- 同种子普通/高级竞技场；
- 权威覆盖和终局一致性；
- 最大允许胜率回归；
- 竞技场至少 8 个候选/Champion 胜负不一致对，并通过 Advanced 绝对胜率线；
- 同一验证集上的 Value MAE、胜负 Brier、死亡 Brier 和综合分不超过 0.05 回归；
- 角色策略训练配额已经满足；
- 当前模型 ID 与评估摘要一致。

测试集分数只能报告，不能成为本轮模型选择条件。
