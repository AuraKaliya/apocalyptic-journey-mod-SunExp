# 训练与模型门禁

## 两类训练数据

### 在线选择样本

- 协议：`aura.combat-ai.sample.v7`
- 特征：10
- 选择轨迹：`aura.combat-ai.selection.v1`
- 文件：`auto-battle-training-v7.jsonl`

`Selection.ExecutedCandidateId` 是真实执行动作的唯一来源，`Selection.PolicyPreselectedCandidateId` 是策略预选。只有事务完成的样本可训练。人工覆盖且两个 ID 不同，才形成残差偏好对。

样本顶层不重复存储候选 ID、来源或示范者。读取器只接受当前协议。

### 长期战斗轨迹

- 协议：`aura.combat-ai.episode.v5`
- 特征：26
- 编码：`partitioned-v3`
- 文件：`live-combat-episodes-v5.jsonl`

Episode 保存每个公开决策帧、合法候选、搜索访问量、风险、真实执行动作以及终局回填的长期回报、胜负、死亡、剩余生命和剩余回合。每帧还保存 `CombatObservationEnvelope`，供对象 Token Transformer 使用；它只来自玩家可见观测，不读取隐藏牌序或未公开随机结果。

在线选择样本同时记录每次决策的墙钟耗时、模拟/节点数、模型调用与缓存命中、裁剪前后候选数以及时间/模型预算停止原因。性能门禁必须使用这些分阶段字段，不能用整批训练吞吐代替单决策延迟。

## 特征编码

`partitioned-v3` 为核心连续特征提供固定槽位，例如生命、护盾、能量、敌方总生命、预期伤害、费用、规则分和主要动作语义。卡牌 ID、状态 ID、敌人 ID 等稀疏身份在各自分区做有符号哈希。

训练产物记录：

- `stateFeatureCollisionRate`
- `actionFeatureCollisionRate`

碰撞率异常升高说明维度不足、特征泄漏或身份域膨胀，应阻止模型直接晋级。

## 策略价值网络

当前网络是共享状态塔、动作塔和多头输出的轻量 MLP：

- 策略 logit；
- 每个合法动作的 16 个回报分位数；
- 长期回报；
- 胜率；
- 死亡概率；
- 终局剩余生命比例；
- 剩余回合。

运行时网络不直接选择动作。它提供根先验和叶节点估值，仍受规则评分、风险统计和硬门禁约束。

动作 Q 使用搜索边回报分布作为监督，只有搜索访问量达到 8 且至少有 4 个有效分位点的动作才参与 Huber 分位损失。未访问边以 `0.7 * 均值 + 0.3 * 下尾均值` 作为 FPU，取得真实模拟样本后立即由经验统计接管。玩家偏好适配器不得修改动作 Q。

最佳 epoch 确定后，仅使用验证集在有限候选温度中校准策略 logit；测试集仍保持隔离。校准温度写入模型并同时用于托管推理与离线指标。

## 数据切分

按 `JourneyRunId` 分组；没有旅程 ID 时按 Episode ID 分组。相同旅程的所有战斗只能进入一个集合。

当数据量足够时：

- 约 80% 训练；
- 约 10% 验证；
- 约 10% 测试。

分组先按稳定 FNV 哈希排序，再确定配额。少于 64 个运行组时保证至少有一个训练、验证和测试分组；达到 64 个运行组后，验证集和测试集各自至少保留 16 个运行组。验证集用于早停和选择最佳 epoch；测试集只在最佳模型确定后评估，不能参与调参。

## 帧级样本平衡

不安全结束回合是高价值反例，但不能淹没普通动作。训练帧达到 64 条后，编码器按稳定哈希确定性抽样，将 `unsafe-end-turn` 的占比限制在 35%；安全结束回合保留，其他动作不下采样。不安全结束回合的专项权重为基准权重的 0.75 倍，结果记录 `TrainingFrameCount` 和 `DroppedUnsafeEndTurnFrames`。

## 语义准入门禁

`semantic-admission-v1` 在预检和每批自博弈后检查权威语义审计。以下任一计数大于零时，该批全部 episode 隔离且模型训练立即停止：

- `SelectedInvalidActions`；
- `SelectedUnexplainedMismatchActions`。

门禁检查的是教师精确分支写回训练观测的“已实现语义”，不是未经执行的静态卡牌摘要。静态规则投影仍与同一权威分支对比，并保留在来源、类型和复现样例指标中，用于发现内容编译缺口；但它不会冒充模型实际接收的语义。已实现数值已经经过力量、感知、护盾、治疗倍率等结算，审计不得再次应用这些修正。

被隔离的 episode 只计入 `GeneratedReplayEpisodes` / `DiscardedSemanticEpisodes`，不得进入 replay、检查点或模型。Worker 此时正常完成进程，但分别报告 `TrainingSucceeded=false`、`ModelAccepted=false`，避免把“进程成功退出”误读为“模型训练成功”。

## 优化器

训练使用确定性 AdamW：

- `beta1 = 0.9`
- `beta2 = 0.999`
- `epsilon = 1e-8`
- 权重使用解耦衰减，偏置不衰减；
- 全局梯度范数上限为 1；
- 非有限梯度或更新立即失败；
- 学习率随 epoch 平滑衰减；
- minibatch 顺序由固定种子和 epoch 决定。

检查点保存模型、最佳模型、Top-K 候选、早停状态以及 AdamW 一阶/二阶矩和 step。恢复训练应与不中断训练得到逐元素相同的权重。

## 指标与门禁

至少观察：

- 训练/验证/测试分组数；
- 策略准确率和交叉熵；
- 关键决策准确率；
- 价值 MAE；
- 胜负和死亡 Brier；
- 生命 MAE 和回合 Huber；
- 动作 Q 分位 Pinball/Huber 与 MAE；
- 验证与测试综合损失；
- 梯度裁剪次数和最大梯度范数；
- 状态与动作碰撞率。
- 对象 Token 覆盖率与关键对象截断数；
- 世界模型下一状态 MSE、Outcome MAE、死亡 Brier 与 Terminal 准确率；
- 模型调用预算耗尽率、模型缓存命中和候选保留率；
- 不安全结束回合原始/保留/丢弃数量；
- 语义拒绝战役和隔离 episode 数；
- Worker 完成、训练成功、模型接受三种独立状态。

模型晋级还必须通过：

- 当前模型协议、特征版本、编码和维度校验；
- 所有权重有限；
- 同种子普通/高级竞技场；
- 权威覆盖和终局一致性；
- 最大允许胜率回归；
- 当前模型 ID 与评估摘要一致。

测试集分数只能报告，不能成为本轮模型选择条件。
