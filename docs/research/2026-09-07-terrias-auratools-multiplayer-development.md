## 生命周期与恢复边界

- 房间代数只管理连接和异步回调；冒险 ID 随存档续玩；战斗 ID 只对应当前原生初始化。原有本地生命周期计数不再决定是否属于同场战斗。
- 身份写盘失败会回滚分配，后续重试重新持久化；切换到未带共享身份的存档会清除旧冒险关联。稳定身份不会在每次查询时重写存档。
- 战斗握手使用原生定向 Query 回包，查询绑定最初的 PlayerManager。替换初始化、清理、换房、成功及超时均释放该对象上的查询。握手 15 秒未完成会终止此次初始化并提示返回大厅重试。
- 日耀提交自动重试最多 8 次，结果未知的记录保留；再次进入整备可继续确认。持久主键包含冒险和玩家，旧房间回执不会完成新冒险的角色整备。
- 余烬值与版本共用一次原生存档提交，磁盘错误回滚；本地已确认值、正在提交的请求与最新期望值分别保存。冲突恢复权威状态并提示，不把拒绝伪装成成功。
- DPT 每位报告者最多缓冲 4096 条，结算等待最终序号及连续确认，收尾等待上限为 8 秒。缓冲溢出、不可恢复缺口或未完成提交会在界面与归档中标记不完整；后续完整权威记录可修复已有不完整行。
- 原生存档写入沿用当前 SaveInfo 序列化和加密参数，通过共享原子文件写入器提交，备份由既有每文档最多 12 份规则管理。

## 兼容与旧路径清理

- Terrias 的 Partner 协议升级为 24，DPT 在线协议升级为 5（历史读取最低 3），冒险档案 schema 升至 3；协议能力在产品清单中同步声明。
- 仅客机启用工具、房主不支持新身份协议时，不向房主发送新类型身份请求，原生战斗继续。无法得到 v5 可靠确认的 DPT 会明确暂停提交并报告不完整；这不等于兼容节点已获得完整统计。
- Shared 原生 Query 适配成为唯一实现，原工具公开类仅保留兼容转发。音频复用已有拥有者请求／事件类型，避免向旧客机广播其无法识别的新类型。
- DPT 独立冒险 ID 写入口已移除；共享层仅在旧 ID 有唯一、可验证来源时接纳。无法确认关联的历史视角档案保留，不按时间猜测，不改写已封存回放。
- 日耀旧存档已保存的整备 token 单向建立权威收据；读取旧记录不会重放角色提交。余烬保留按玩家归属的旧值，无归属旧值仅允许在房主单人场景接纳。
- 旧静态 Solar pending、目标对象身份绑定及本地跨机战斗计数路径已移除。日耀、余烬和手部附着归 Application／Contracts，相关分层例外由 49 收紧到 43。
- 公共 API 差异逐项核对后接纳：Core 新增 166 条反射记录，原有公开成员删除数为 0；新增内容对应身份、准入、定向查询、持久收据及载荷工具。旧六参数发送者构造器保留，两个正式消费者已基于新共享程序集编译。差异保存在 `artifacts/multiplayer-audit/2026-09-07/public-api-delta.json`。
