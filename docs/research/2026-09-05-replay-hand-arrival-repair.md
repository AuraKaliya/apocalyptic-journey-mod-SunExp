# 战斗回放获得卡牌与手牌重排修复

输入：`AuraTools-20260905-200232.log`，其中两场录制均 Ready，但手牌初始为空，
首次四张手牌分别到 6.94 s、5.33 s 才成批写入。卡牌表现只有 Hand/Discard/Burn，
没有获得和入手轨迹，部分已操作卡牌没有对应入手状态。

## 修复边界

- 抽取/生成请求、实际创建、移动落位分别处理。请求只更新已有合并状态屏障，
  不伪造可见卡；空牌库、满手牌或排队未完成时没有入手动画。
- 观察原生 DrawEffect 前的真实视图，早于 DrawScript 中的嵌套抽牌/自动使用。
  实际创建与布局完成调用返回时立即提交当前手牌状态，不等待下一次出牌。
- 布局开始前观察参与重排的已有手牌，复用已在移动/拖动的视图所有权。
  入手与布局轨迹等待原生 tween 和实际归位，不添加猜测的路径或固定延迟。
- 新卡移动期间静态副本隐藏，落位后交还静态手牌；移除显示端的任意 20 张截断。
- 新卡的已初始化名称、费用、说明和附魔快照用于移动视图。嵌套创建只定稿
  当前完成调用的配置对象，后续创建不会修改先前视图的历史卡面快照。
- 已完成或已销毁的原生卡牌从可见手牌和计数排除。入手阶段被自动消耗的牌
  保留出生/退出轨迹，但不在动画结束后重新出现。
- 终局新增 `[MatchRecords:hand]` 汇总，包含 arrivals、layoutViews 和契约标识。

## 记录兼容与完整性

新 UI 描述声明 `observed-arrival-and-layout.v1`，记录要求
`observed-hand-arrival-and-layout.v1`。即便某次录制漏掉全部入手轨迹，声明仍在，
不会因“没有观察到 Draw”而跳过覆盖检查。

检查每次进入手牌的独立出生证据、重新抽回同一卡牌的新证据、操作前的出现
证据，以及卡面快照身份。允许已经观察到出生但在入手脚本中直接消耗的牌。
旧文档缺省字段不进入 canonical JSON，继续读取，不改写原文件或伪造入手动画。
