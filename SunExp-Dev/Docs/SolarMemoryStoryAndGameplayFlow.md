# SunExp 日耀回忆剧情与当前玩法流程

本文整理当前仓库中 `日耀回忆 / Solar Memory` 的剧情主线与已实现玩法流程。它描述的是当前实现状态，而不是旧设计草案。

## 一、模式定位

日耀回忆是乌娜的专属回忆玩法，入口标题为：

- 名称：`日耀回忆`
- 描述：`乌娜的专属回忆`
- 副标题：`Boss连战`

它不是普通地图事件，而是一个独立模式入口。玩家在模式选择界面点击日耀回忆后，会创建一个普通模式类型的专用存档，但存档内写入 `SunExp_SolarMemoryMode = 1`，后续地图、整备、固定事件、固定 Boss、结算都由 Solar Memory 运行时接管。

## 二、剧情主线

日耀回忆讲的是乌娜成为“曜日魔女”之前，白曜圣庭、第二日轮与“被污染的光”之间的旧日回忆。

### 0. 整备后开场独白

整备完成并首次继续回忆时，会播放乌娜独白：

1. 乌娜曾以为第二日轮升起，是预言中“新生”的时刻。
2. 现在回看，那时特瑞厄斯仍在灾厄的绝望中。
3. 对人民而言，白曜的归来只是溺水者攀住了无根浮木。
4. 玩家选择“继续回忆”，正式进入地图回忆段。

### 1. 黑日之后

黑日之灾以后，特瑞厄斯失去了真正的黎明。腐坏的天幕压在王都与边境上方，旧时代的太阳已经在历法中死去。幸存者只能在未被遮蔽的星空下祈祷、劳作、为明天继续活着。

剧情功能：奠定“没有太阳的国家仍然向明天前进”的基调。

### 2. 第二日轮

白曜圣庭制造了第二日轮。这个悬挂在天幕之下的人造太阳重新划分昼夜，照亮圣庭辖区，也给特瑞厄斯的人们带来生的希望。很多孩子甚至不再知道真正的太阳曾从地平线上升起。

剧情功能：让第二日轮先作为“救赎系统”出现，而不是一开始就是灾厄。

### 3. 圣女的日常

乌娜曾是白曜圣庭的圣女。她穿过圣庭长廊，为病人念祷、为孩子赐福，是白曜垂怜人间的代行者。那时人们相信白曜的光辉会永远照耀下去，乌娜自己也相信只要光仍在，特瑞厄斯就值得继续。

剧情功能：展示过去的乌娜不是魔女，而是相信秩序、祈愿与救赎的圣女。

### 4. 被污染的光

异常从颜色消失开始。街区失色，一个普通人的存在被抹除，母亲记得自己有孩子，却记不起他的名字。乌娜触碰墙面时感到灼痛，意识到那不是黑暗或瘟疫，而是光本身出了问题：第二日轮被污染了。

剧情功能：反转第二日轮的性质。灾厄不是黑暗，而是披着光辉外形的污染。

### 5. 心哀与挣扎

乌娜向圣庭呈报污染证据，但大主教和圣庭选择沉默。他们封锁街区、修改记录、烧毁卷册，并把事实称作边境回声。乌娜看着卷册中的名字一点点消失，只剩焚烧后的灰烬。

剧情功能：把冲突从“发现污染”推进到“圣庭选择维持秩序假象”。所谓明天已经成了灾厄抵达的道路。

### 6. 圣轮之上

乌娜独自走向第二日轮核心圣座。曜日冠冕悬浮在圣座上，金光之下是层层污秽低语。她戴上冠冕，将白曜、灾厄、无数祈祷与被遗忘的痕迹一并收入体内。第二日轮刺破天幕，王都看见了一次真正白昼，随后太阳坠落，乌娜的名字也被烧净。

剧情功能：解释乌娜如何从白曜圣女走向曜日魔女，也解释“日耀回忆”的核心情绪：她不是为了毁灭太阳，而是把已成灾厄通道的太阳与祈愿一同背负下来。

## 三、Boss 与终局剧情

当前日耀回忆包含三个专属剧情 Boss：

1. `白曜镜阵`
   第二层固定首领。它代表仍按旧日钟律校准第二日轮的三千面环日镜，是“灾厄系统仍在正常运转”的第一层显形。

2. `无慈第二日轮`
   第三层固定主终局 Boss。它仍在完整执行照亮、净化、抹去名字的职责。击败它后进入终局分支判断。

3. `白曜圣女·乌娜`
   隐藏剧情首领。她代表过去那个仍相信白曜、净化与秩序的圣女乌娜。当前触发条件不是名字资源，而是卡组中拥有关键卡 `炽冕崩落`。若满足条件，击败无慈第二日轮后会播放圣女前置独白，并追加乌娜战；若不满足条件，则播放第二日轮终局独白后结算。

终局对白分支：

- 无 `炽冕崩落`：乌娜感叹“他们说，白曜不会有任何问题”，随后问“为什么会变成这个样子”，然后结算。
- 有 `炽冕崩落`：白曜圣女独白“我曾听过无数祈祷”，指出祈祷如今都在光里燃烧；若这轮太阳已无法给予众生、照亮之处都会成为灾厄道路，那么她将献上最后的祷告。随后进入白曜圣女战。
- 击败白曜圣女后：洛奈尔与未知存在相关的收束对白出现，提到预言、新生与“这一簇星火”，然后结算。

## 四、当前玩法流程

### 1. 模式入口

日耀回忆通过自定义模式入口注册，不占用原生 `StoryMode` 等模式槽。点击入口后：

1. 创建专用 `SaveInfo`。
2. 存档类型仍使用 `Normal`，以复用原生普通地图流程。
3. 写入日耀回忆标记与整备状态。
4. 发布 Aura Journey 活跃模式 `SunExp.SolarMemory`。
5. 打开原生 `GameEntryUI` 继续进入角色与地图流程。

新存档初始化的关键状态包括：

- `SunExp_SolarMemoryMode = 1`
- 已选择卡包列表
- 本源点数 `50`
- 整备阶段 `DeckSelection`
- 初始牌组、本源、祝福、整备完成标记均为未完成
- 事后开场对白未看

### 2. 整备阶段

整备是正式推进地图前的固定前置流程，状态机为：

```text
DeckSelection -> OriginAllocation -> BlessingSelection -> Complete
```

当前三个步骤：

1. 初始牌组选择
   从本次日耀回忆启用的卡包中选择 11 张初始牌。事件牌会被过滤，选择结果只替换本局初始牌组，不写入奖励候选池。

2. 本源加点
   默认给予 50 点本源点数，但会受当前角色本源上限约束。必须分配完可分配点数后才能进入下一步。

3. 祝福选择
   使用自定义祝福选择器，按阶层固定配额选择：
   - 4 级祝福：2 个
   - 3 级祝福：3 个
   - 2 级祝福：5 个
   - 1 级祝福：5 个

整备完成后会提交最终角色状态；提交成功才写入 `SunExp_SolarMemorySetupFinished = 1` 并关闭整备 UI。

### 3. 事件节点推进

日耀回忆的六个剧情事件全部是 `Sub_` 事件，不进入普通事件池。地图上显示的是专属 Map 行，运行时会把节点 `NodeId` 改写成真实 EventList ID。

每个剧情事件当前有两个选项：

1. `继续回忆`
   若整备未完成，则恢复整备流程；若整备完成，则首次触发整备后开场独白，之后结束事件并继续地图。

2. `查看卡牌`
   打开当前日耀牌组；若初始牌组尚未完成，则回到整备流程。

### 4. 地图结构

当前日耀回忆复用原生 `NormalMapManager` 与 `MapTree`，但在原生生成后覆盖当前层的节点段。运行层级按 `manager.Level / 6` 计算，共三层：

- 第一层：特瑞厄斯
- 第二层：白曜圣庭
- 第三层：圣轮

当前固定内容大致为：

| 层 | 固定剧情/首领 |
| --- | --- |
| 第一层 | 开端事件 `黑日之后`；末端事件 `第二日轮` |
| 第二层 | 开端事件 `圣女的日常`；中段事件 `被污染的光`；固定首领 `白曜镜阵` |
| 第三层 | 开端事件 `心哀与挣扎`；中段事件 `圣轮之上`；固定首领 `无慈第二日轮`；隐藏首领槽/追加战 `白曜圣女·乌娜` |

除固定剧情事件和固定剧情 Boss 外，其他 Boss 节点从扩展首领池抽取。扩展池会读取所有可用的 Fight 首领 Map 行，不再严格限制为当前原生层级，并排除日耀回忆三个固定剧情 Boss。

### 5. 终局与结算

当前终局路线：

1. 正常推进到第三层。
2. 击败 `无慈第二日轮`。
3. 若卡组有 `炽冕崩落`：
   - 播放白曜圣女前置对白。
   - 设置乌娜战 pending 状态。
   - 运行时创建固定 `白曜圣女·乌娜` 战斗节点并进入战斗。
   - 击败后播放收束对白并结算。
4. 若卡组没有 `炽冕崩落`：
   - 播放第二日轮终局对白。
   - 直接结算。

结算 UI 当前直接打开原生 `GameExitUI`，并关闭地图与事件 UI。

### 6. 异常与同步处理

日耀回忆有额外运行时保护：

- 地图生成后覆盖当前层固定节点。
- 地图选择 UI 展示前再次锁定固定槽位。
- `MapManager` 同步数组前修正 `maps[]` 与 `mapData[]`。
- 固定或恢复节点会补 deterministic `NodeDice`。
- 战斗逃跑、失败、地图切换时会清理整备与祝福等临时 UI，并清除待进入乌娜战的 pending 状态。
- 多人模式下，整备选择保持玩家作用域，最终只提交一次 prepared role。

## 五、当前实现与旧设计的差异

仓库中曾有“名字资源 / 三结局 / 终局事件门”的设计设想，但当前实现已经收束为更直接的路线：

- 终局不再打开旧的 `Sub_solar_finale_*` 事件链。
- 结算直接走 `GameExitUI`。
- 隐藏 Boss `白曜圣女·乌娜` 当前由关键卡 `炽冕崩落` 触发，不由 `SavedNames / BurnedNames / NamelessNames` 判定。
- 整备入口不再依赖旧 `Sub_solar_memory_start` 事件，而是由模式入口和整备状态机恢复。

因此，当前可理解为：

> 日耀回忆 = 乌娜旧日剧情回放 + 三层固定叙事节点 + 扩展 Boss 连战 + 第二日轮终局 + 关键卡触发白曜圣女隐藏战。
