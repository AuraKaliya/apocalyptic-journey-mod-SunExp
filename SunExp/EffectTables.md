# 日耀聚能：卡牌与遗物效果表

> 来源：`Data/Card/sunexp.csv`、`Text/Card/sunexp.csv`、`Data/Relic/sunexp.csv`、`Text/Relic/sunexp.csv`。稀有度与费用保留配置中的原始数值。

## 术语

| 术语 | 说明 |
| --- | --- |
| 日耀 | 行动时获得超凡；圣冕显化期间按日耀阶段获得额外收益。 |
| 聚炎 | 无上限聚能，回合开始会带来自身灼烧压力。 |
| 日耀场 | 回合开始时让全体获得灼烧。 |
| 避灼光幕 | 清除自身灼烧，并在下回合开始再次清除。 |
| 圣冕显化 | 持续窗口；日耀阶段向下包括，用于放大收益并控制爆发反噬。 |
| 灼烧 | 游戏原生灼烧状态。 |
