# 日耀：烬冠天幕：卡牌与遗物效果表

> 来源：`Data/Card/sunexp.csv`、`Text/Card/sunexp.csv`、`Data/Relic/sunexp.csv`、`Text/Relic/sunexp.csv`。稀有度与费用保留配置中的原始数值。

## 术语

| 术语 | 说明 |
| --- | --- |
| 日耀 | 行动时获得超凡；授冕时用于确立圣冕等阶。 |
| 聚炎 | 无上限聚能，回合开始会带来自身灼烧压力。 |
| 炽灼天幕 | 回合开始时让全体获得灼烧。 |
| 烬衣 | 清除自身灼烧，并在下回合开始再次清除。 |
| 圣冕显化 | 持续窗口；期间日耀系数翻倍，触发时按圣冕等阶获得额外收益，结束时消耗等阶2倍的日耀。 |
| 圣冕等阶 | 获得圣冕显化时，根据当前日耀1/4/8/12/15确立，最高5阶。 |
| 灼烧 | 游戏原生灼烧状态。 |
