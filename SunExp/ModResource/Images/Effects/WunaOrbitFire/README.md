Wuna orbit fire resources:

- Primary runtime assets:
  - WunaOrbitTrailMask.png: generated flowing ribbon mask used by the runtime long-stream orbit ribbons.
  - WunaOrbitTrailNoise.png: generated tileable noise for alpha erosion and flame flow breakup.
