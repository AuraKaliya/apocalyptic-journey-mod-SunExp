Wuna orbit fire resources:

- Primary runtime assets:
  - WunaOrbitTrailMask.png: generated hand-painted ribbon mask used by the runtime long-stream orbit ribbons.
  - WunaOrbitTrailNoise.png: generated stretched noise for alpha erosion and flame flow breakup.
  - Flame02_16x4.png: converted from the Unity VFX Image Sequences TGA to PNG; kept as a reference/fallback atlas, but no longer used by the Wuna orbit runtime because it reads as petal-like shards in motion.
