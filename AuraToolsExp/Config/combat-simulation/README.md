# AuraToolsExp 标准模拟评估包

此目录随 MOD 发布。普通玩家不需要从开发仓库复制知识包，也不需要先点击“导出规则”。

当前内置包：

- `witch-world-simulation-v2.campaign.json`：正式的固定七层情景模拟定义。
- `witch-base-evaluation-v2.ruleset.json`：覆盖本体表内 290 张卡与 55 个敌人的可执行规则投影；已排除同环境中的 Terrias、Saya 等外部内容。
- v1 文件仅为旧配置兼容保留；新用户默认选择 v2。

七层流程：

- 第 1～6 层固定为 `2 普通 + 1 精英 + 2 普通 + 1 首领`，第 7 层单独进行最终首领战，共 37 场。
- 第 1～2 层从本体 `Level=0/-1` 池抽取，第 3～4 层从 `1/-1` 池抽取，第 5～6 层从 `2/-1` 池抽取；允许有放回重复。
- 最终首领等概率抽取勇者卡洛琳（完全天使）、永夜化身、魔王、神圣审判机关。
- 每场胜利提供两轮三选一卡牌、一件遗物和一个正面祝福；卡牌可跳过，遗物上限 6，祝福必拿且无上限。
- 每层使用固定属性基础值，再叠加此前保留下来的永久加成，并按本体上限裁切；前六层结束最大生命与当前生命同时增加 40。

难度与验证：

- 普通难度无难度词条；高级难度加载本体完整难度词条集合。
- 普通与高级难度分别写入独立结果与验证标记，不要求同时通过。
- 配置中的近似规则允许流程继续运行，但不会被计入权威覆盖率；覆盖不足时不会发放正式验证标记。
- 冻结的是评估版本、开局卡组和世界种子。底模与候选模型共享同一敌人、奖励和随机流。
- 正式模拟评估数据只作为晋级证据，不回流训练；训练数据来自游戏内真实战斗及完整旅程。

高级用户仍可把自定义 `*.ruleset.json`、`*.scenario.json`、`*.journey.json` 或 `*.campaign.json` 放到 AuraToolsExp 日志目录下的 `combat-simulation-input`。同版本文件同时存在时，用户输入目录优先。
