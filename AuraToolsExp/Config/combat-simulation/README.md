# AuraToolsExp 标准模拟评估包

此目录随 MOD 发布。普通玩家不需要从开发仓库复制知识包，也不需要先点击“导出规则”。

当前内置包：

- `witch-world-simulation-v2.campaign.json`：正式的固定七层情景模拟定义。
- `witch-base-evaluation-v2.ruleset.json`：当前包含 297 张可执行卡牌规则、55 个本体敌人与 137 个战斗状态；已排除同环境中的 Terrias、Saya、Ronove 等外部内容。
- `witch-content-display-catalog-v1.json`：面向训练产物和 SimulationViewer 的冻结中文内容目录，
  覆盖卡牌、遗物、祝福、敌人、BUFF 与战役场景；每项保留来源哈希。
- 标准包只保留当前规则和战役定义，不提供过时配置的兼容入口。
- 规则可通过 `action-contract-v2` 分别声明游戏可调用性与 AI 候选资格，并以同一动作因果链中的卡牌实例迁移验证后置条件，不再依赖牌堆/手牌净数量变化。当前【神选】按反编译版本 `v1.0.24591395` 建模：抽牌堆为空或手牌已满时返回 `NoEffect`、不进入冷却，并在模型与搜索评分前排除。

权威建模进度：

- 正式奖励池范围为 277 张卡牌；加上 16 张诅咒牌与 4 张战斗生成牌后，规则包共包含 297 张可执行卡牌，当前均通过权威规则门禁。
- 17 张角色技能牌按 `SkillOnly` 单独登记，不进入普通奖励池；技能使用资格由角色协议与游戏内动作入口共同约束。
- 13 张本体诅咒牌已全部权威化：抽到、正常弃置、不可使用、保留、焚毁及“原罪”回填抽牌堆均按本体生命周期执行；焚毁不会错误触发弃置脚本。
- 本轮同时权威化了冥想、装点幸运、绝命、绯咏弦奏、血殁、唤灵：星陨、血契重锋、血契化盾、血契冥想与扭曲的祈愿；`SetHp` 按本体直接赋值处理，不伪装为治疗或受伤事件。
- 55 个本体敌人已经全部权威化：保留每回合 1～3 个意图、优先级、冷却、普通/满词条条件、开场状态、塞牌、召唤、复制状态、追加友方行动、削盾、治疗衰减，以及战中偷取和胜利返还金钱。
- 固定七层战役从本体 `normal` 模式的 100 金币开始，只维护战斗可见余额；扣款按实际可扣数钳制到 0，获得、消耗、偷取与胜利返还会跨战斗继承。商店购买和路线经济不进入战斗模拟。
- 当前 137 个本体战斗状态均通过权威规则门禁；工具仍会递归检查卡牌生成、状态引用与敌人召唤，任何缺失或降级项都会重新锁定正式训练。
- 最近两轮新增权威状态为树肤、血墙、渐入佳境、龙血、半天使、黑桃、庞然巨兽、同源同心、信徒、赎罪、慌乱、狩猎、双子与举世无双。黑桃严格按当前本体脚本在开战时施加 3 层血河；双子不附带说明文本所写但当前脚本没有执行的治疗；慌乱按当前脚本从第 4 次受击开始在第 4、7、10……次受击触发。
- 已权威化的状态覆盖行动前后、受伤、友方死亡、全场回合起止、战斗开始、洗牌、骰子判定、跨单位生命链接、状态内部计数、按当前手牌/标签/仪式层数求值、基础攻防与最大生命的脚本倍率、仪式回声与条件胜利；敌人身上的回合型状态与玩家状态现在共用同一全场回合事件语义。遗物与祝福的事件脚本尚未完成权威化。
- `buff_ritualbloodsacrifice` 现按卡牌实例持久追加燃尽标签，并按实际焚毁事件计数；`buff_ritualtimeprison` 按实际延迟效果执行次数计数，并在下回合开始按“仪式”标签从抽牌堆取回。`buff_timelock` 自身保存并回放任意延迟脚本的通用能力仍标为近似；任何正式构筑一旦递归依赖它，训练仍会被锁定。
- 工具会递归检查卡牌生成、状态引用和召唤敌人。任一依赖缺失或仍为近似时，底模训练保持锁定并直接报告各类剩余数量。
- “可执行”只表示可以用于开发调试，不等于已经达到正式底模训练的权威标准。

七层流程：

- 第 1～6 层固定为 `2 普通 + 1 精英 + 2 普通 + 1 首领`，第 7 层单独进行最终首领战，共 37 场。
- 第 1～2 层从本体 `Level=0/-1` 池抽取，第 3～4 层从 `1/-1` 池抽取，第 5～6 层从 `2/-1` 池抽取；允许有放回重复。
- 最终首领等概率抽取勇者卡洛琳（完全天使）、永夜化身、魔王、神圣审判机关。
- 每场胜利提供两轮三选一卡牌、一件遗物和一个普通正面祝福；卡牌可跳过，遗物上限 6，祝福必拿且无上限。本源专属祝福不会混入普通祝福奖励池。
- 每层使用固定属性基础值，再叠加此前保留下来的永久加成，并按本体上限裁切；本源达到 10／20／30／40 时会按 `RoleTable.VarsCheck` 自动、幂等地补齐对应专属祝福。前六层结束最大生命与当前生命同时增加 40。

难度与验证：

- 普通难度无难度词条；高级难度加载本体完整难度词条集合。
- 普通与高级难度分别写入独立结果与验证标记，不要求同时通过。
- 配置中的近似规则允许流程继续运行，但不会被计入权威覆盖率；覆盖不足时不会发放正式验证标记。
- 冻结的是评估版本、开局卡组和世界种子。底模与候选模型共享同一敌人、奖励和随机流。
- 玩家护盾固定跨回合保留，不再暴露可清除护盾的旧情景开关；抽牌堆不足时会在同一次抽牌请求中把弃牌堆洗回并继续抽取。
- `ritualcard_8` 刀与盾按本回合实际造成的伤害在回合结束时生成护盾，并将伤害连打或牌堆循环转化为可持续生存资源。
- 正式模拟评估数据只作为晋级证据，不回流训练；训练数据来自游戏内真实战斗及完整旅程。

高级用户仍可把自定义 `*.ruleset.json`、`*.scenario.json`、`*.journey.json` 或 `*.campaign.json` 放到 AuraToolsExp 日志目录下的 `combat-simulation-input`。同版本文件同时存在时，用户输入目录优先。

需要重新生成本体规则包时，可在 AuraToolsExp 设置的“战斗策略实验室（工具）”中点击“一键导出游戏数据集”。导出文件会写入配置目录下的 `combat-knowledge/table-exports`，旁边的“打开目录”按钮可直接定位结果。
