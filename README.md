# 日耀聚能

纯数据卡包 Mod。ModName: `SunExp`，CSV: `sunexp`。

## 核心玩法

- `日耀`: 每次行动获得 `5 * 日耀层数` 的超凡。
- `聚炎`: 无上限，回合开始时让自己获得等同层数的灼烧。
- `日耀场`: 每轮回合开始时让全体获得等同层数的灼烧。
- `太阳圣冕`: 打出后获得 2 回合 `圣冕显化`，此时日耀层数才会转换为阶段效果。
- `冕核爆闪`: 消耗全部聚炎和一半日耀，造成爆发伤害，并强制结束圣冕显化。
