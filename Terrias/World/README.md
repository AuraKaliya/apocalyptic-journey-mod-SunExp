# 特瑞厄斯世界设定集

本目录保存特瑞厄斯世界观的创作者侧档案。档案卡不采用强制模板，只记录理解某一对象所必需的事实、关联与尚未确定的问题。

当前为第一版基础设定，优先整理乌娜、洛奈尔、白曜圣庭与第二日轮所共同构成的世界主轴。已经确认的内容直接陈述；仍需讨论的部分明确保留为未知，不用推测替代定论。

## 使用约定

- 【特瑞厄斯】是世界的名称，不是国家名称。
- 世界中不存在传统意义上的国家；不得用国境解释【边境】。
- 【曜日冠冕】是该造物的唯一称呼。
- 设定事实、圣庭解释、民间认知和魔女档案记录可以彼此不同。涉及不同认知时，应在卡片中说明信息来源。
- 新设定应优先补入对应档案卡，再检查角色故事、事件文本和其他玩家可见内容是否需要同步。
