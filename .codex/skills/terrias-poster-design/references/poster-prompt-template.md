# Poster Prompt Template

Use this template as a starting point. Replace bracketed fields and delete
irrelevant sections.

```text
Use case: ads-marketing
Asset type: vertical MOD introduction poster, [topic] key visual

Primary request:
Create a polished vertical anime fantasy promotional poster for a game MOD
topic: [topic name]. Use the attached images only as [visual identity/style/scene]
references. Preserve [identity/style invariants], but redraw a new cinematic key
visual rather than copying the original pose or layout.

Input images:
Image 1: reference for [subject 1]. [Appearance and motif notes.]
Image 2: reference for [subject 2]. [Appearance and motif notes.]

Poster concept:
[One paragraph explaining the poster topic, series container, and whether the
title must remain reusable for future batches.]

Scene/backdrop:
[World-state, location, atmosphere, symbolic motifs.]

Subject and composition:
[Vertical composition. Subject placement. Negative space for text. Required
number of subjects. Foreground/background relationship.]

Style/medium:
High-end anime game promotional illustration, painterly fantasy key art,
refined brushwork, luminous but restrained magical effects, premium MOD poster
design, elegant composition, not a collage, not a UI screenshot.

Lighting/mood:
[Lighting split, emotional tone, contrast.]

Color palette:
[Dominant background and 2-4 accent colors. Avoid one-note palettes.]

Text to include exactly, with clean readable Chinese typography:
Top title, large:
[TITLE]

Small subtitle below title:
[SUBTITLE]

Main copy below subtitle:
[MAIN COPY]

[Optional label block 1:]
[LABEL LINE 1]
[LABEL LINE 2]
[LABEL LINE 3]

[Optional label block 2:]
[LABEL LINE 1]
[LABEL LINE 2]
[LABEL LINE 3]

Typography requirements:
All Chinese text must be accurate, legible, and exactly as written. Use elegant
Chinese title typography and clean readable body labels. Do not invent extra
slogans, do not add random English, do not add unreadable decorative glyphs, and
do not replace Chinese characters with symbols.

Constraints:
Keep the poster vertical and usable as a social-media MOD introduction poster.
Do not add additional characters unless explicitly requested. Do not add card
frames, UI panels, screenshots, watermarks, logos, QR codes, or fake platform
badges. Avoid dense tiny details around text.

Output goal:
A finished 2160x3840 vertical key visual poster with complete title/copy
integrated into the artwork.
```
